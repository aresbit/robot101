# 第 6 章 逆运动学

> 课程来源：EECS C106A 第 4 周 ｜ 关键词：数值 IK、雅可比法、解析 IK、可操作度、奇异位形 ｜ 预计阅读时长：~25 分钟

## 1. 导论

第 5 章解决了正运动学 (Forward Kinematics, FK) 问题：给定一组关节角，确定末端执行器的位姿。逆运动学 (Inverse Kinematics, IK) 是它的反问题：给定末端执行器的期望位姿 $$g_d \in SE(3)$$，求一组关节角 $$\theta$$，使正运动学映射满足 $$g_{st}(\theta) = g_d$$。

为什么这个问题如此重要？因为几乎所有"目标导向"的机器人任务都要把任务空间（笛卡尔空间）的意图翻译成关节空间的指令。轨迹规划在笛卡尔空间画一条路径，要逐点调用 IK 才能得到可执行的关节轨迹；视觉伺服（第 7 章）把相机观测到的目标位姿交给 IK 换算成运动命令；遥操作、仿真、离线编程同理。可以说，FK 是前向建模，IK 是反向求解，二者共同构成操纵 (manipulation) 的几何基础，也是"让机器人按人的意图动起来"的第一步。

多解性不是一个需要消除的"麻烦"，反而是工程师要善用的自由度。例如一个五自由度臂去抓桌上的杯子，肘上/肘下两种位形都能把末端送到同一位置，我们通常希望选"离当前关节位形最近"的那一组解——既符合人类操作员的直觉（胳膊小范围调整比大幅翻折自然），也能减少运动规划的时间和能耗。因此实践中 IK 的输出往往不是一个角而是"一组候选解 + 一个择优规则"。同时，IK 的失败方式也很值得注意：解不存在时（目标超出工作空间），再好的算法也只会给出近似或失败提示，控制层必须优雅处理。

IK 在数学上与 FK 有本质区别。FK 是单值映射，结果唯一确定；IK 则是"多对一"，同一个末端位姿可能对应多个关节配置，也可能一个都不对应。正如 MLS 第 3 章指出的，IK 求解传统上分为两大流派：**闭式/解析解** (closed-form/analytic) 与**数值解** (numerical)。绝大多数工业机械臂在设计时就刻意保证存在解析解（典型的是满足 Pieper 准则：三个腕关节轴交于一点），因为解析解快速、确定、适合实时控制。而数值法通用性强，不依赖特殊结构，能处理冗余或任意构型的机械臂，代价是迭代计算与初值敏感性。本章将两者都讲透，并以雅可比迭代（牛顿-拉夫森）作为数值法的主角——这正是 EECS C106A 第 4 周的重点。

与前后的关系：本章反复使用的雅可比矩阵 (Jacobian) 要到第 9 章才被系统推导与研究；这里我们先借助平面二连杆臂的解析雅可比，把数值 IK 的核心思想讲清楚，并把奇异位形与可操作度这两个贯穿全书的概念引入进来。

## 2. 关键概念与记号

- **配置空间 (Configuration Space)**：所有关节角的集合，记为 $$Q \subset \mathbb{R}^n$$，其中 $$n$$ 是关节数（自由度）。
- **任务空间 (Task space)**：末端执行器可到达位姿的集合，本质上是 SE(3)；只关心位置时为 $$\mathbb{R}^3$$（平面臂为 $$\mathbb{R}^2$$）。
- **正运动学映射**：$$g_{st} : Q \to SE(3)$$，脚标 $$s/t$$ 表示"从空间系 (space) 到工具系 (tool)"。
- **逆运动学问题**：给定 $$g_d \in SE(3)$$，求 $$\theta \in Q$$ 使 $$g_{st}(\theta) = g_d$$。
- **解的存在性**：$$g_d$$ 必须在机械臂的工作空间 (workspace) 之内才可能有解；工作空间之外的位姿无解，任何算法都无法强行解出。
- **解的个数**：由于三角函数方程的非线性，IK 通常有多解。平面二连杆一般有 0 或 2 组解（肘上/肘下）；对一般的六自由度空间机械臂，解析解最多可达 16 个（MLS 引 Lee & Liang 的结论）。
- **解析解与数值解**：前者用几何/代数技巧直接写出闭式公式；后者用迭代逐步逼近，例如牛顿-拉夫森、阻尼最小二乘。
- **雅可比 (Jacobian)**：$$J(\theta) = \partial f / \partial \theta$$，把关节速度映射到末端速度：$$\dot{x} = J(\theta)\dot{\theta}$$。
- **奇异位形 (Singularity)**：满足 $$\mathrm{rank}(J) < \min(m,n)$$ 的位形。此时 $$J$$ 不可逆，存在某些末端运动方向根本无法实现，而反向计算会把关节速度放大到无穷。
- **可操作度 (Manipulability)**：度量雅可比在给定配置下"各向同性"程度，常用 $$w = \sqrt{\det(J J^{\mathsf T})}$$（方阵时即 $$\lvert \det J \rvert$$）。

值得再强调一次关节空间与任务空间的差异。关节空间是"机器的语言"：电机只能驱动关节角，所以最终一切命令都落在关节上；任务空间是"人的语言"：我们只关心末端在世界里的位置和姿态。IK 就是这两种语言之间的翻译器。正因为翻译是"一对多"的，机械臂才有冗余度和灵活性；而 FK 反过来把关节语言翻译回任务语言，是验证任何 IK 结果的标尺——本章所有代码都用正运动学回代来验收。

几何直觉很关键。把平面二连杆完全伸直时，肘关节"锁死"，末端只能沿杆长方向径向运动，无法横向移动——这就是奇异位形。折叠起来时两个关节都能高效发力，末端可以任意方向移动，可操作度就高。奇异附近数值 IK 会遇到病态（雅可比接近奇异、求逆放大误差），这正是为什么要引入阻尼最小二乘。

## 3. 算法与公式

### 3.1 平面二连杆臂的解析 IK

沿用第 5 章的正运动学（令 $$\theta_{12} = \theta_1 + \theta_2$$）：

$$x = L_1 \cos\theta_1 + L_2 \cos\theta_{12}, \qquad y = L_1 \sin\theta_1 + L_2 \sin\theta_{12}.$$

反解的关键是极坐标技巧：令 $$r^2 = x^2 + y^2$$，由余弦定理直接得到肘关节角：

$$\theta_2 = \pm \cos^{-1}\!\left(\frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2}\right),$$

正负号分别对应**肘上 (elbow-up)** 与**肘下 (elbow-down)** 两组解。随后确定肩关节角：

$$\theta_1 = \mathrm{atan2}(y, x) - \mathrm{atan2}\!\left(L_2 \sin\theta_2,\; L_1 + L_2 \cos\theta_2\right).$$

存在性检查：若 $$r > L_1 + L_2$$（末端够不到）或 $$r < \lvert L_1 - L_2 \rvert$$（两臂无法收缩到这个半径），则无解。数值实现时要注意把余弦定理中的参数夹紧到 $$[-1,1]$$，避免浮点舍入造成 $$\arccos$$ 定义域错误。

### 3.2 Paden–Kahan 子问题（MLS）

MLS 第 3 章给出另一条解析路线：利用乘积指数公式把通用 IK 分解成一组规范几何子问题——绕单轴旋转、绕两轴先后旋转、旋转到与第三点共线等。每个子问题都是"绕给定轴转多少度使某点到达目标"的封闭解，几何意义清晰且数值稳定，适合至少部分关节轴相交的常见机械臂结构（如肘部机械臂）。局限是并非所有机械臂都能归约到这组规范子问题。

### 3.3 数值 IK：雅可比法（牛顿-拉夫森）

把问题写成求根：$$f(\theta) = x_d$$。在当前猜测 $$\theta_k$$ 处做一阶泰勒展开：

$$x_d - f(\theta_k) \approx J(\theta_k)\,(\theta - \theta_k).$$

令残差 $$\Delta x = x_d - f(\theta_k)$$，解线性方程组得到增量，即牛顿迭代：

$$\theta_{k+1} = \theta_k + J^{-1}(\theta_k)\,\Delta x.$$

循环执行：计算正运动学 → 求残差 → 组装雅可比 → 解增量 → 更新关节角，直到残差范数足够小。

当雅可比接近奇异时，$$J^{-1}$$ 会把数值误差放大。此时改用**阻尼最小二乘 (Damped Least Squares, DLS)**：

$$\theta_{k+1} = \theta_k + J^{\mathsf T}\!\left(J J^{\mathsf T} + \lambda^2 I\right)^{-1}\Delta x,$$

其中 $$\lambda > 0$$ 是阻尼系数。$$J J^{\mathsf T} + \lambda^2 I$$ 恒为正定矩阵，正则化了近奇异时的病态，代价是收敛速度略有下降。DLS 是工业实现里非常常用的稳健版本，也是 C106A 数值 IK 实验的标配。

对冗余机械臂（关节数多于任务维数，雅可比"横"于方形：$$J \in \mathbb{R}^{p \times n}$$，$$n > p$$），上述公式中的伪逆自然推广为 $$J^{\dagger} = J^{\mathsf T}(J J^{\mathsf T})^{-1}$$，最小范数速度解为 $$\dot{\theta} = J^{\dagger} V$$。冗余带来的零空间运动（自运动流形, self-motion manifold）可用来避障或优化代价函数（MLS 第 3 章第 5 节；MLS 明确指出此时 IK 是病态/欠定的）。

初值选择直接决定数值法收敛到哪个解。牛顿法本质是局部收敛：不同初始猜测会收敛到不同的分支，这正是数值法"天然覆盖多解"的体现，但也带来初值敏感性问题。工程上的常见策略包括：以上一控制周期求得的关节角作为当前初值（相邻时刻目标通常只差一点点，迭代一两步即收敛，适合在线控制）；或用解析解/粗网格搜索给出一个"足够接近"的初值再交给牛顿法精化。近奇异时残差对关节角变化极其敏感，此时应放大阻尼系数 $$\lambda$$ 或用雅可比转置法先走一步稳健的下降方向，再切回牛顿法加速收敛。

**收敛判据**：

1. 残差范数 $$\lVert x_d - f(\theta_k) \rVert_2 < \varepsilon$$（主判据）；
2. 迭代增量范数 $$\lVert \Delta \theta \rVert_2 < \varepsilon_\theta$$（防止停滞）；
3. 超过最大迭代次数仍未满足 → 判失败，常见原因是目标不可达或初始猜测过差。

伪代码：

```
输入: 目标位姿 x_d, 初始猜测 theta_0
for k = 0..max_iter:
    Delta_x = x_d - FK(theta_k)
    if ||Delta_x||_2 < eps: return theta_k        # 收敛
    J = dFK/dtheta(theta_k)
    theta_{k+1} = theta_k + J^{-1} Delta_x        # 或 DLS 版本
return FAIL
```

### 3.4 奇异位形与可操作度

平面二连杆的解析雅可比为（记 $$s_1=\sin\theta_1$$，$$s_{12}=\sin\theta_{12}$$ 等）：

$$J(\theta) = \begin{bmatrix} -L_1 s_1 - L_2 s_{12} & -L_2 s_{12} \\ L_1 c_1 + L_2 c_{12} & L_2 c_{12} \end{bmatrix}, \qquad \det J = L_1 L_2 \sin\theta_2.$$

可见 $$\theta_2 = 0$$（完全伸直）或 $$\theta_2 = \pm\pi$$（完全折叠）时 $$\det J = 0$$，机械臂进入奇异位形。MLS 第 4 章给出了三种常见空间奇异的几何判据：两转动轴共线、三转动轴平行共面、四转动轴交于一点，均可直接从几何构造读出。

MLS 给出的可操作度度量（奇异值记 $$\sigma_i$$）：

- $$\mu_1 = \sigma_{\min}(J)$$：单位关节速度所能产生的最小末端速度，奇异时为零；
- $$\mu_2 = \sigma_{\min} / \sigma_{\max}$$：条件数倒数，衡量各向同性程度；
- $$\mu_3 = \det J$$（或 $$\sqrt{\det(J J^{\mathsf T})}$$）：速度椭球体积，奇异时为零。

这些度量在奇异附近趋近零，正好提示数值 IK 应切换到 DLS。可操作度是连接本章与后续运动规划/控制的重要桥梁。

## 4. C 语言实现

### 4.1 平面二连杆解析 IK（肘上/肘下两解）

```c
/*
 * 第 6 章 逆运动学 —— 示例 1: 平面两连杆机械臂解析逆运动学
 * 编译: gcc -std=c11 -Wall -Wextra ik_analytic.c -lm -o ik_analytic
 * 公式:
 *   theta2 = +/- acos((x^2+y^2-L1^2-L2^2)/(2 L1 L2))
 *   theta1 = atan2(y,x) - atan2(L2 sin theta2, L1 + L2 cos theta2)
 */
#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* 正运动学: 由关节角回算末端位置, 用于校验 */
static void fk(double L1, double L2, double t1, double t2,
               double *px, double *py)
{
    *px = L1 * cos(t1) + L2 * cos(t1 + t2);
    *py = L1 * sin(t1) + L2 * sin(t1 + t2);
}

/* 解析逆运动学: 已知末端位置 (x,y), 求全部关节解。
 * 返回解的个数 (0 或 2), 肘上/肘下两支各存一份。 */
int ik_analytic(double x, double y, double L1, double L2,
                double *t1_up,  double *t2_up,
                double *t1_dn,  double *t2_dn)
{
    double r2 = x * x + y * y;
    double r  = sqrt(r2);
    if (r > L1 + L2 || r < fabs(L1 - L2))
        return 0;                       /* 超出工作空间: 无解 */

    /* 余弦定理: 把舍入误差夹回 [-1,1] 防止 acos 域错误 */
    double c2 = (r2 - L1 * L1 - L2 * L2) / (2.0 * L1 * L2);
    if (c2 < -1.0) c2 = -1.0;
    if (c2 >  1.0) c2 =  1.0;

    double alpha = atan2(y, x);

    /* 肘上: theta2 >= 0 */
    *t2_up =  acos(c2);
    *t1_up =  alpha - atan2(L2 * sin(*t2_up),
                            L1 + L2 * cos(*t2_up));

    /* 肘下: theta2 <= 0 */
    *t2_dn = -acos(c2);
    *t1_dn =  alpha - atan2(L2 * sin(*t2_dn),
                            L1 + L2 * cos(*t2_dn));
    return 2;
}

int main(void)
{
    double L1 = 1.0, L2 = 0.8;
    double x = 1.2, y = 0.5;

    double u1, u2, d1, d2;
    int n = ik_analytic(x, y, L1, L2, &u1, &u2, &d1, &d2);
    if (n == 0) {
        printf("目标 (%.2f, %.2f) 在工作空间之外, 无解\n", x, y);
        return 1;
    }

    printf("目标点: (%.3f, %.3f), 连杆: L1=%.2f L2=%.2f\n", x, y, L1, L2);
    printf("得到 %d 组解:\n", n);

    printf("  肘上: theta1=%.4f  theta2=%.4f\n", u1, u2);
    double fx, fy;
    fk(L1, L2, u1, u2, &fx, &fy);
    printf("    正运动学校验: x=%.4f y=%.4f\n", fx, fy);

    printf("  肘下: theta1=%.4f  theta2=%.4f\n", d1, d2);
    fk(L1, L2, d1, d2, &fx, &fy);
    printf("    正运动学校验: x=%.4f y=%.4f\n", fx, fy);

    return 0;
}
```

### 4.2 数值 IK：雅可比法（牛顿-拉夫森 + 阻尼最小二乘回退）

```c
/*
 * 第 6 章 逆运动学 —— 示例 2: 数值逆运动学 (雅可比法 / 牛顿-拉夫森)
 * 编译: gcc -std=c11 -Wall -Wextra ik_numerical.c -lm -o ik_numerical
 * 核心迭代:
 *   theta_{k+1} = theta_k + J^{-1} Delta x                     (牛顿法)
 *   近奇异时回退阻尼最小二乘 (DLS):
 *   theta_{k+1} = theta_k + J^T (J J^T + lambda^2 I)^{-1} Delta x
 */
#include <stdio.h>
#include <math.h>

/* 正运动学: 求末端位置 */
static void fk(double L1, double L2, double t1, double t2,
               double *px, double *py)
{
    *px = L1 * cos(t1) + L2 * cos(t1 + t2);
    *py = L1 * sin(t1) + L2 * sin(t1 + t2);
}

/* 解析雅可比 2x2: J[i][j] = d f_i / d theta_j */
static void jac(double L1, double L2, double t1, double t2, double J[2][2])
{
    double s1 = sin(t1),     c1 = cos(t1);
    double s12 = sin(t1+t2), c12 = cos(t1+t2);
    J[0][0] = -L1*s1 - L2*s12;   J[0][1] = -L2*s12;
    J[1][0] =  L1*c1 + L2*c12;   J[1][1] =  L2*c12;
}

/* 2x2 矩阵求逆; 行列式绝对值小于阈值返回 0 (奇异) */
static int inv2x2(const double A[2][2], double thr, double Ai[2][2])
{
    double det = A[0][0]*A[1][1] - A[0][1]*A[1][0];
    if (fabs(det) < thr) return 0;
    double id = 1.0 / det;
    Ai[0][0] =  A[1][1]*id;   Ai[0][1] = -A[0][1]*id;
    Ai[1][0] = -A[1][0]*id;   Ai[1][1] =  A[0][0]*id;
    return 1;
}

/*
 * 数值逆运动学: 给定末端目标 (xd,yd), 返回收敛的关节角。
 * 返回 1 收敛; 0 达到最大迭代仍未收敛 (可能目标不可达)。
 * 初始猜测 theta0 由调用者给出。
 */
int ik_numerical(double L1, double L2, double xd, double yd,
                 double *th1, double *th2,
                 int max_iter, double tol, int *iters)
{
    double t1 = *th1, t2 = *th2;
    double lam = 0.2;               /* 阻尼系数 lambda */

    for (int k = 0; k < max_iter; ++k) {
        double px, py;
        fk(L1, L2, t1, t2, &px, &py);

        /* 收敛判据 1: 残差范数 ||Delta x||_2 < tol */
        double ex = xd - px, ey = yd - py;
        double err = sqrt(ex*ex + ey*ey);
        if (err < tol) { *th1 = t1; *th2 = t2; *iters = k + 1; return 1; }

        double J[2][2], Ji[2][2];
        jac(L1, L2, t1, t2, J);

        if (inv2x2(J, 1e-4, Ji)) {
            /* 牛顿法: Delta theta = J^{-1} Delta x */
            t1 += Ji[0][0]*ex + Ji[0][1]*ey;
            t2 += Ji[1][0]*ex + Ji[1][1]*ey;
        } else {
            /* 阻尼最小二乘: delta = J^T (J J^T + lam^2 I)^{-1} Delta x */
            double A[2][2], Ai[2][2];
            A[0][0] = J[0][0]*J[0][0] + J[0][1]*J[0][1] + lam*lam;
            A[0][1] = J[0][0]*J[1][0] + J[0][1]*J[1][1];
            A[1][0] = A[0][1];
            A[1][1] = J[1][0]*J[1][0] + J[1][1]*J[1][1] + lam*lam;
            if (!inv2x2(A, 1e-12, Ai)) return 0;  /* 完全奇异 */

            double q0 = Ai[0][0]*ex + Ai[0][1]*ey;
            double q1 = Ai[1][0]*ex + Ai[1][1]*ey;
            t1 += J[0][0]*q0 + J[1][0]*q1;   /* delta = J^T q */
            t2 += J[0][1]*q0 + J[1][1]*q1;
        }
    }
    return 0;
}

int main(void)
{
    double L1 = 1.0, L2 = 0.8;
    double targets[][2] = {
        { 1.2,  0.5 },     /* 常规目标 */
        { 1.79, 0.0  }      /* 近奇异目标 (接近完全伸直) */
    };
    int nt = (int)(sizeof(targets) / sizeof(targets[0]));

    for (int i = 0; i < nt; ++i) {
        double xd = targets[i][0], yd = targets[i][1];
        double th1 = 0.4, th2 = 0.8;    /* 初始猜测 */
        int iters = 0;

        printf("目标 (%.3f, %.3f), 初始猜测 (%.3f, %.3f)\n",
               xd, yd, th1, th2);
        if (ik_numerical(L1, L2, xd, yd, &th1, &th2, 200, 1e-6, &iters)) {
            double px, py;
            fk(L1, L2, th1, th2, &px, &py);
            printf("  收敛: theta=(%.4f, %.4f)  %d 次迭代\n", th1, th2, iters);
            printf("  正运动学校验: 末端=(%.6f, %.6f)\n", px, py);
        } else {
            printf("  未收敛 (目标不可达或初始猜测过差)\n");
        }
    }
    return 0;
}
```

## 5. 教材/论文精读

**MLS 第 3 章 (Inverse Kinematics)**。MLS 开篇就把 IK 定义为"给定工具系期望位形 $$g_d$$，求解 $$g_{st}(\theta) = g_d$$"，并立刻用平面二连杆臂展示了核心手法：极坐标 + 余弦定理把问题拆成"先求肘角、再求肩角"的两个子问题，每个子问题独立判有无解、产生多解时全部保留继续求解。这是解析 IK 的范式：把耦合的非线性方程组分解为若干可独立求解的几何子问题。第 3.2-3.3 节的 Paden–Kahan 子问题把这一思想系统化——用乘积指数公式把通用 IK 归约到"绕轴旋转"的基本子问题，几何清晰、数值稳定。第 3.4 节则展示更一般的情况：对任意（轴不相交的）六自由度机械臂，可采用代数消元（dialytical elimination）把三角方程组化成关于单变量的高次多项式，其根对应全部解。MLS 给出的结论是：任何开链六自由度空间机构最多 16 个解，其中典型肘部机械臂可达 8 个。

**MLS 第 4 章 (The Manipulator Jacobian / 可操作度)**。数值 IK 的立足点正是雅可比，MLS 第 4 章用旋量（twist）给出了雅可比的乘积指数表达式 $$J^s_{st}(\theta) = [\xi_1\ \ \xi_2' \cdots \xi_n']$$，并系统研究了奇异位形的几何判据（两轴共线、三轴平行共面、四轴共点）。第 4.4 节的可操作度给出了 $$\sigma_{\min}$$、条件数倒数、$$\det J$$ 三类度量，把它们与速度椭球、末端运动的各向异性直接挂钩。对冗余机械臂，MLS 第 3.5 节指出 IK 病态（有无穷多解），并给出最小范数速度解 $$\dot{\theta} = J^{\dagger} V$$（伪逆法），零空间运动构成自运动流形，可用来避障或优化。这些内容正是本章数值 IK 方法的理论根据，也是后续第 9 章对雅可比全面展开的伏笔。

**读后启示**。把两章合起来看，有一条清晰的脉络：IK 解的存在性由工作空间决定，解的个数由机械臂的几何结构与消元多项式的次数决定，解的数值质量则由雅可比的条件数决定。这三点恰好对应本章的三个主题——解析 IK 管"能不能解、有几组解"，数值 IK 管"怎么稳健地算出来"，可操作度管"算出来的解附近好不好动"。局限在于：MLS 的解析路线推导繁复，对轴不相交的通用情形依赖消元技巧且病态矩阵求行列式数值条件不佳；而纯迭代数值法又不保证收敛到全局最优解。EECS C106A 第 4 周的实验把这套理论落到实践：在仿真里让两连杆臂去够目标点，同时观察牛顿法与 DLS 在奇异附近的差别，正是对上述脉络的直接验证。

## 6. 实验/编程作业

对应 EECS C106A 第 4 周，建议：

1. **先验证解析解**：实现 4.1 节代码，对工作空间内外各取几个目标点，检查解的个数是否符合预期；对每组解用正运动学回代，确认误差在浮点精度内。
2. **再做数值解**：实现 4.2 节，观察不同初始猜测是否收敛到不同的解（这正体现 IK 的多解性）；画出迭代次数与残差范数的下降曲线。
3. **奇异位形实验**：把目标点设在接近完全伸直的位置（$$r \approx L_1 + L_2$$），比较纯牛顿法与 DLS 在近奇异处的行为差异；观察可操作度 $$\det J = L_1 L_2 \sin\theta_2$$ 随 $$\theta_2$$ 的变化。
4. **扩展到真实机械臂**：在真机/仿真上对 6-DOF 臂实现一次 IK 回调（如 ROS KDL/IKFast），比较解析法与数值法的运行时间与成功率，并注意关节限位与奇异回避。
5. **发散排查训练**：故意给出工作空间外的目标，观察数值法在最大迭代次数内的行为；再给出极端初始猜测，体会"局部收敛"的本质，并尝试用解析解作为初值来改善。这些调试经验比代码本身更值钱。

## 8. 小结

逆运动学把"末端想去的位姿"翻译成"各关节该转的角度"，是连接任务空间与关节空间的桥梁。它有三个本质特征：解可能不存在（超出工作空间）、解常常不唯一（肘上/肘下乃至 16 个解）、解还依赖机械臂结构与算法选择（解析 vs 数值）。解析 IK 快速确定，依赖特殊构型；数值 IK 通用稳健，靠雅可比迭代逼近，奇异附近需用阻尼最小二乘正则化。可操作度与奇异位形是评估"在某个位形好不好动"的关键工具。掌握这两条路线，就为后续的雅可比分析、轨迹规划与运动控制打下了基础。
