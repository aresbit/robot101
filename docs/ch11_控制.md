# 第 11 章 机器人控制

> 课程来源：EECS C106A 第 10 周 ｜ 关键词：PID 控制、轨迹跟踪、计算力矩控制、逆动力学控制、重力补偿、阻抗控制 ｜ 预计阅读时长：~40 分钟

## 1. 导论

第 10 章用拉格朗日力学导出了 n 关节机械臂的动力学方程
$$M(q)\ddot{q} + C(q,\dot{q})\dot{q} + G(q) = \tau$$
它回答了"给定关节力矩，机械臂如何运动"的正问题。控制工程关心的是它的逆问题：**给定期望轨迹 $$q_d(t)$$，应当施加多大的关节力矩 $$\tau$$，才能让机械臂在存在初始误差、传感噪声与建模误差的情况下仍然可靠地跟踪它**。这就是本章的主题——机器人控制。

最直接的想法是开环前馈：既然模型已知，就预先算出沿期望轨迹所需的力矩 $$\tau = M(q_d)\ddot{q}_d + C(q_d,\dot{q}_d)\dot{q}_d + G(q_d)$$。只要初始状态精确等于期望状态，由微分方程解的唯一性，机械臂将精确复现轨迹。但实际中我们几乎不可能精确知道初始状态，传感器噪声和模型误差也总会存在，一旦偏离，开环控制永不纠正。因此必须引入**反馈**：用实测的关节角 q 与角速度 $$\dot{q}$$ 修正力矩。这也是"位置控制与轨迹跟踪"（MLS 第 4 章第 5 节）的出发点。

本章沿着"对模型依赖程度递增"的主线展开三类控制器。**第一类是 PID 控制及其最廉价的模型利用形式——重力补偿**：比例项负责"拉回"位置误差，微分项负责阻尼振荡，积分项消除稳态误差，而重力补偿项抵消了最显著、随位形变化的恒定负载。它不需要质量矩阵与科里奥利矩阵，鲁棒且计算量小，是工业机器人最常用的基线。**第二类是计算力矩控制 (computed torque)，又称逆动力学控制 (inverse dynamics control) 或反馈线性化 (feedback linearization)**：利用精确模型把非线性系统对消成一组解耦的二阶线性系统，从而把任意线性控制综合手段搬到非线性机器人上，实现指数收敛的轨迹跟踪。**第三类是任务空间与阻抗控制 (impedance control)**：把控制目标从关节角转移到末端位形乃至与环境的交互力，让机械臂在与人和环境接触时表现出"弹簧-阻尼"式的柔顺行为。

从全书结构看，第 9 章的雅可比提供了关节空间与任务空间之间的桥梁，第 10 章的动力学给出了被控对象，本章在其上闭合反馈回路，第 12 章的运动规划则负责生成期望轨迹。控制与规划共同构成"让机械臂真正动起来"的最后两块拼图。

## 2. 关键概念与记号

**标准动力学方程。** 本章一律采用第 10 章的标准形式
$$M(q)\ddot{q} + C(q,\dot{q})\dot{q} + G(q) = \tau$$
其中 $$q \in \mathbb{R}^{n}$$ 为关节角，$$M(q)$$ 为对称正定的质量矩阵 (mass matrix)，$$C(q,\dot{q})\dot{q}$$ 为科里奥利与向心项，$$G(q)$$ 为重力项。与 MLS 记号不同，这里把重力单独提出，把摩擦等未建模效应并入扰动项。

**三条结构性质。** 这是所有基于模型的控制器证明稳定性的公共依据：(1) $$M(q)$$ 对称正定；(2) $$\dot{M} - 2C$$ 是反对称矩阵，即科里奥利项满足 $$\dot{M} = C + C^{T}$$；(3) 对固定的 q, $$\dot{q}$$，$$C(q,\dot{q})\dot{q}$$ 关于 $$\dot{q}$$ 二次齐次。性质 (2) 意味着科里奥利项在系统能量平衡中"不做功"，它使李雅普诺夫函数的时间导数变得干净——这是第 10 章 Lemma 4.2 的核心结论，控制律的稳定性证明几乎全部建立在这三条之上。

**误差记号。** 定义位置误差
$$e = q_d - q,\qquad \dot{e} = \dot{q}_d - \dot{q}$$
**定点调节 (setpoint regulation)** 指期望位形恒定（$$\dot{q}_d = \ddot{q}_d = 0$$），**轨迹跟踪 (trajectory tracking)** 指期望状态随时间变化。

**反馈线性化 (feedback linearization)。** 用全状态反馈把非线性系统精确地变换为线性系统，再用线性控制理论设计。计算力矩控制是它的典型实例，其价值在于"一次对消、终生线性"：对消之后误差动力学与机械臂本身无关。

**重力补偿 (gravity compensation)。** 控制器中显式加入 $$G(q)$$ 项以抵消重力负载，从而避免"机械臂下坠"造成的稳态误差。

**柔顺/阻抗控制 (compliant / impedance control)。** 不再强制跟踪位置，而是规定位置误差与接触力之间的动态关系（机械阻抗）。它是本章唯一面向"交互"的控制族。

## 3. 算法与公式

### 3.1 PID 控制与重力补偿

最朴素的控制器是关节空间 PID：
$$\tau = K_p\,(q_d - q) - K_d\,\dot{q} + K_i \int_0^t (q_d - q)\,dt$$
其中 $$K_p, K_d, K_i$$ 均为正定对角增益矩阵。比例项提供"弹簧"刚度，微分项提供"阻尼"，积分项消除由重力、摩擦造成的稳态误差；但积分项会带来积分饱和 (windup)，饱和时输出被钳制而积分继续累积，需要额外的抗饱和保护。

对操作臂而言，一个廉价而有效的改进是**重力补偿的 PD 控制**（本章采用的形式）：
$$\tau = K_p\,(q_d - q) - K_d\,\dot{q} + G(q)$$
注意这里的微分项阻尼的是**实测速度**而非误差速度：对定点调节两者等价，对轨迹跟踪后者更自然。把上式代入动力学方程，重力项被精确对消，闭环成为
$$M(q)\ddot{q} + C(q,\dot{q})\dot{q} + K_d\,\dot{q} + K_p\,(q - q_d) = 0$$
取机械臂动能与"势能弹簧"之和作为李雅普诺夫函数
$$V = \tfrac{1}{2}\,\dot{q}^{T} M(q)\dot{q} + \tfrac{1}{2}\,(q - q_d)^{T} K_p\,(q - q_d)$$
沿闭环轨迹求导，利用反对称性质 $$\dot{M} - 2C$$ 得
$$\dot{V} = -\dot{q}^{T} K_d\,\dot{q} \le 0$$
再由拉萨尔不变集原理，最大不变集仅含 $$q = q_d$$，故定点全局渐近稳定（MLS Proposition 4.9）。需要强调两点：**纯 PD 控制没有前馈项，对非平凡轨迹无法实现零误差跟踪**，它能保证的是"停机位置"的渐近稳定；而重力补偿项把稳态偏置消除，使机械臂可以在任意位形停稳，不需要积分器来扛重力。

### 3.2 计算力矩控制（反馈线性化）

把前馈与反馈结合，得到计算力矩控制律：
$$\tau = M(q)\bigl(\ddot{q}_d + K_p\,e + K_d\,\dot{e}\bigr) + C(q,\dot{q})\dot{q} + G(q)$$
代入动力学方程，由于 $$M(q)$$ 正定可逆，全部非线性项被对消，得到与机械臂完全解耦的线性误差动力学
$$\ddot{e} + K_d\,\dot{e} + K_p\,e = 0$$
这相当于对每一对共轭特征根配置二阶系统：取 $$K_p = \omega_n^{2} I$$、$$K_d = 2\zeta\omega_n I$$，即可独立设定每个关节的自然频率与阻尼比。MLS Proposition 4.8 证明：当 $$K_p, K_d$$ 正定对称时，轨迹跟踪**指数收敛**。这是反馈线性化最优雅的成果——误差行为不依赖机器人的任何参数。

该控制律可拆成两块：
$$\tau = \underbrace{M(q)\ddot{q}_d + C(q,\dot{q})\dot{q} + G(q)}_{\tau_{ff}} \;+\; \underbrace{M(q)\bigl(K_p\,e + K_d\,\dot{e}\bigr)}_{\tau_{fb}}$$
前馈项 $$\tau_{ff}$$ 是沿名义轨迹驱动系统所需的力矩（即逆动力学 (inverse dynamics) 计算），反馈项 $$\tau_{fb}$$ 在偏差出现时施加修正。当模型精确且初始状态恰好等于期望状态时，反馈项恒为零，系统沿标称轨迹滑行；一旦出现初始误差、扰动或模型失配，反馈项将其指数消除。实现上的代价是：每个控制周期都要实时计算 $$M, C, G$$，且建模误差会直接进入误差动力学成为扰动源。好在机械臂的质量矩阵有界，反馈线性化所需的力矩始终有界，实践中性能良好（MLS §4.5）。

### 3.3 轨迹生成：五次多项式平滑插值

计算力矩与逆动力学控制都需要 $$q_d, \dot{q}_d, \ddot{q}_d$$ 连续。由运动规划或人工给定的路径通常只给出关键位形，需要在关节空间平滑插值。五次多项式可同时满足两端的位置、速度、加速度六个边界条件：
$$s(t) = 10\Bigl(\tfrac{t}{T}\Bigr)^{3} - 15\Bigl(\tfrac{t}{T}\Bigr)^{4} + 6\Bigl(\tfrac{t}{T}\Bigr)^{5}$$
它满足 $$s(0)=0,\ s(T)=1,\ \dot{s}(0)=\dot{s}(T)=0,\ \ddot{s}(0)=\ddot{s}(T)=0$$。于是
$$q_d(t) = q_0 + s(t)\,(q_1 - q_0),\qquad \dot{q}_d = \dot{s}\,(q_1 - q_0),\qquad \ddot{q}_d = \ddot{s}\,(q_1 - q_0)$$
式中 $$q_0, q_1$$ 为起止位形，$$T$$ 为运动时长。与三次多项式相比，五次多项式避免了起止时刻的加速度跳变，因而力矩指令连续、速度曲线更平滑，激起的机械振动更小。第 12 章的运动规划器输出关键点序列后，正是用这样的插值把它们连成可执行的平滑轨迹。

### 3.4 任务空间与阻抗控制

关节空间控制器在非奇异时总能完成任务，但许多任务（擦拭、装配、与人协作）需要在**末端/任务空间**表达控制目标。把末端位形 x 当作新坐标，利用雅可比改写动力学可得到有效参数（effective inertia）$$\tilde{M} = J^{-T} M J^{-1}$$ 等，于是计算力矩可直接搬到任务空间：
$$F = \tilde{M}(q)\bigl(\ddot{x}_d + K_p\,e_x + K_d\,\dot{e}_x\bigr) + \tilde{C}\dot{x} + \tilde{N}, \qquad \tau = J^{T} F$$
其中 $$e_x = x_d - x$$ 为任务空间误差。好处是增益有了任务空间的物理含义（直接在末端方向定义刚度与阻尼），且无需逐时刻解逆运动学；代价是接近奇异位形时 $$\tilde{M}$$ 急剧增大，说明该方向"推不动"，需要切换或阻尼策略。MLS 证明有效参数仍满足正定与反对称结构性质（Lemma 4.11），因此稳定性论证与关节空间逐字相同。

当机械臂要与环境接触（打磨、拧螺丝、与人握手）时，单纯的位置跟踪会造成过大的接触力。**阻抗控制**不强迫跟踪，而是把机械臂端部塑造成一个"质量-弹簧-阻尼"系统，规定位置误差与接触力满足
$$F_{ext} = M_d\,(\ddot{x} - \ddot{x}_d) + B_d\,(\dot{x} - \dot{x}_d) + K_d\,(x - x_d)$$
通过调节目标阻抗 $$M_d, B_d, K_d$$ 权衡跟踪精度与柔顺性：阻抗选得"软"，机械臂在接触时让开、接触力被限制；选得"硬"，机械臂精准但接触力大。Hogan 的框架把位置控制与力控制统一为阻抗的两个极限，是现代柔顺控制与人机安全的基础。

### 3.5 伪代码：计算力矩控制回路

```
每个控制周期（周期 h）：
  1. 读取编码器：实测关节角 q 与角速度 qd
  2. 由轨迹生成器计算 q_d(t), qd_d(t), qdd_d(t)
  3. e = q_d - q;   edot = qd_d - qd
  4. 用第 10 章例程计算 M(q), C(q,qd), G(q)
  5. tau = M(q) * (qdd_d + Kp*e + Kd*edot) + C(q,qd)*qd + G(q)
  6. 下发力矩给电机，等待下一个周期
```

## 4. C 语言实现

本节给出两段可独立编译的 C11 代码，均以内联的 2 连杆平面臂动力学（第 10 章模型）为被控对象做闭环数值仿真。所有线性代数都用手写 2 维向量与 2x2 解析求逆，不依赖外部库。

### 4.1 代码块 A：PD + 重力补偿（定点调节）

```c
/*
 * 代码块 A：关节空间 PD + 重力补偿 —— 2 连杆平面臂定点调节闭环仿真
 *
 * 编译：gcc -std=c11 -Wall -Wextra -O2 -o ch11_a ch11_a.c -lm
 *
 * 控制律：  tau = Kp*(q_des - q) - Kd*qd + G(q)
 * 被控对象：第 10 章拉格朗日方程  M(q) qdd + C(q,qd) qd + G(q) = tau
 * 积分器：  半隐式欧拉 (symplectic Euler)
 */
#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* 2 维向量，代表 2 连杆臂的关节角 / 关节速度 */
typedef struct { double x, y; } Vec2;

static Vec2 v2(double x, double y)     { Vec2 v = {x, y}; return v; }
static Vec2 v2_add(Vec2 a, Vec2 b)     { return v2(a.x + b.x, a.y + b.y); }
static Vec2 v2_sub(Vec2 a, Vec2 b)     { return v2(a.x - b.x, a.y - b.y); }
static Vec2 v2_scale(Vec2 a, double s) { return v2(s * a.x, s * a.y); }
static double v2_norm(Vec2 a)          { return sqrt(a.x*a.x + a.y*a.y); }

/* 机械臂参数（SI 单位） */
typedef struct { double l1, l2, m1, m2, g; } Arm;

/* M(q)：对称质量矩阵 */
static void mass_matrix(const Arm *a, Vec2 q, double M[2][2]) {
    double c2 = cos(q.y);
    M[0][0] = (a->m1 + a->m2) * a->l1 * a->l1 + a->m2 * a->l2 * a->l2
            + 2.0 * a->m2 * a->l1 * a->l2 * c2;
    M[0][1] = M[1][0] = a->m2 * a->l2 * a->l2 + a->m2 * a->l1 * a->l2 * c2;
    M[1][1] = a->m2 * a->l2 * a->l2;
}

/* C(q,qd) qd：科里奥利 / 向心项 */
static Vec2 coriolis(const Arm *a, Vec2 q, Vec2 qd) {
    double h = -a->m2 * a->l1 * a->l2 * sin(q.y);
    return v2(h * (qd.y * (2.0 * qd.x + qd.y)), -h * qd.x * qd.x);
}

/* G(q)：重力项 */
static Vec2 gravity(const Arm *a, Vec2 q) {
    double c1 = cos(q.x), c12 = cos(q.x + q.y);
    return v2(a->g * (a->m1 * a->l1 * c1 + a->m2 * (a->l1 * c1 + a->l2 * c12)),
              a->g * a->m2 * a->l2 * c12);
}

/*
 * 关节空间 PD + 重力补偿：
 *   tau = Kp*(q_des - q) - Kd*qd + G(q)
 * 说明：本变体阻尼实测速度 qd（对定点调节足够）。
 *       若要跟踪轨迹并阻尼误差速度，可把 qd 换成 (qd_des - qd)。
 */
static void pd_gravity_control(const Arm *a, Vec2 q, Vec2 qd, Vec2 qd_des,
                               Vec2 q_des, double Kp, double Kd, Vec2 *tau) {
    (void)qd_des;                       /* 该公式只阻尼实测速度 */
    *tau = v2_add(v2_add(v2_scale(v2_sub(q_des, q), Kp),
                         v2_scale(qd, -Kd)),
                  gravity(a, q));
}

/* 正动力学：qdd = M^{-1} (tau - C qd - G)，2x2 解析求逆 */
static Vec2 forward_dynamics(const Arm *a, Vec2 q, Vec2 qd, Vec2 tau) {
    double M[2][2];
    mass_matrix(a, q, M);
    Vec2 b = v2_sub(v2_sub(tau, coriolis(a, q, qd)), gravity(a, q));
    double det = M[0][0] * M[1][1] - M[0][1] * M[1][0];
    return v2((M[1][1] * b.x - M[0][1] * b.y) / det,
              (-M[0][1] * b.x + M[0][0] * b.y) / det);
}

int main(void) {
    Arm arm = {1.0, 0.8, 2.0, 1.0, 9.81};
    const double Kp = 80.0, Kd = 20.0;   /* 对角增益：wn≈8.9 rad/s, zeta≈1.1 */
    Vec2 q = v2(0.10, 0.20), qd = v2(0.0, 0.0);   /* 初始位形 */
    Vec2 q_des  = v2(0.50, 0.80);                 /* 期望停机位形 */
    Vec2 qd_des = v2(0.0, 0.0);
    const double dt = 1e-3, T = 5.0;
    int n = (int)(T / dt);

    printf("  t(s)      q1       q2     |e|\n");
    for (int i = 0; i <= n; i++) {
        if (i % 500 == 0)
            printf("%6.3f  %7.4f %7.4f  %7.4f\n",
                   i * dt, q.x, q.y, v2_norm(v2_sub(q_des, q)));
        Vec2 tau;
        pd_gravity_control(&arm, q, qd, qd_des, q_des, Kp, Kd, &tau);
        Vec2 qdd = forward_dynamics(&arm, q, qd, tau);
        qd = v2_add(qd, v2_scale(qdd, dt));   /* 半隐式欧拉：先更新速度 */
        q  = v2_add(q,  v2_scale(qd, dt));    /* 再用新速度更新位置 */
    }
    return 0;
}
```

运行 5 秒仿真，每隔 0.5 秒打印位置与误差范数，可观察到误差从 $$\lVert e \rVert = 0.72$$ 单调衰减到约 $$10^{-4}$$ 量级——这正是"重力补偿的 PD 使定点渐近稳定"的实验验证。读者可以删掉公式中的 $$G(q)$$ 项重跑，看到机械臂停在重力让位的位置，体会重力补偿的直观作用。

### 4.2 代码块 B：计算力矩控制 + 五次多项式轨迹（轨迹跟踪）

```c
/*
 * 代码块 B：计算力矩控制（反馈线性化）+ 五次多项式轨迹跟踪
 *
 * 编译：gcc -std=c11 -Wall -Wextra -O2 -o ch11_b ch11_b.c -lm
 *
 * 控制律：  tau = M(q)*(qdd_des + Kp*e + Kd*edot) + C(q,qd) qd + G(q)
 *          e = q_des - q,  edot = qd_des - qd
 * 期望轨迹：五次多项式 s(u)=10u^3-15u^4+6u^5, u=t/T，两端位置/速度/加速度连续
 * 积分器：  经典四阶 Runge-Kutta (RK4)
 */
#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct { double x, y; } Vec2;

static Vec2 v2(double x, double y)     { Vec2 v = {x, y}; return v; }
static Vec2 v2_add(Vec2 a, Vec2 b)     { return v2(a.x + b.x, a.y + b.y); }
static Vec2 v2_sub(Vec2 a, Vec2 b)     { return v2(a.x - b.x, a.y - b.y); }
static Vec2 v2_scale(Vec2 a, double s) { return v2(s * a.x, s * a.y); }
static double v2_norm(Vec2 a)          { return sqrt(a.x*a.x + a.y*a.y); }

typedef struct { double l1, l2, m1, m2, g; } Arm;

static void mass_matrix(const Arm *a, Vec2 q, double M[2][2]) {
    double c2 = cos(q.y);
    M[0][0] = (a->m1 + a->m2) * a->l1 * a->l1 + a->m2 * a->l2 * a->l2
            + 2.0 * a->m2 * a->l1 * a->l2 * c2;
    M[0][1] = M[1][0] = a->m2 * a->l2 * a->l2 + a->m2 * a->l1 * a->l2 * c2;
    M[1][1] = a->m2 * a->l2 * a->l2;
}

static Vec2 coriolis(const Arm *a, Vec2 q, Vec2 qd) {
    double h = -a->m2 * a->l1 * a->l2 * sin(q.y);
    return v2(h * (qd.y * (2.0 * qd.x + qd.y)), -h * qd.x * qd.x);
}

static Vec2 gravity(const Arm *a, Vec2 q) {
    double c1 = cos(q.x), c12 = cos(q.x + q.y);
    return v2(a->g * (a->m1 * a->l1 * c1 + a->m2 * (a->l1 * c1 + a->l2 * c12)),
              a->g * a->m2 * a->l2 * c12);
}

/* 五次多项式插值基函数：s(0)=0, s(1)=1，两端一阶二阶导为零 */
static double quintic(double u) {
    return 10.0*u*u*u - 15.0*u*u*u*u + 6.0*u*u*u*u*u;
}
static double quintic_dot(double u)  { return 30.0*u*u - 60.0*u*u*u + 30.0*u*u*u*u; }
static double quintic_ddot(double u) { return 60.0*u - 180.0*u*u + 120.0*u*u*u; }

/* 关节空间轨迹：q0 -> q1，时长 T */
typedef struct { Vec2 q0, q1; double T; } Traj;

static double clamp01(double u) { return u < 0.0 ? 0.0 : (u > 1.0 ? 1.0 : u); }

static Vec2 traj_pos(const Traj *tr, double t) {
    double s = quintic(clamp01(t / tr->T));
    return v2_add(tr->q0, v2_scale(v2_sub(tr->q1, tr->q0), s));
}
static Vec2 traj_vel(const Traj *tr, double t) {
    return v2_scale(v2_sub(tr->q1, tr->q0), quintic_dot(clamp01(t / tr->T)) / tr->T);
}
static Vec2 traj_acc(const Traj *tr, double t) {
    return v2_scale(v2_sub(tr->q1, tr->q0),
                    quintic_ddot(clamp01(t / tr->T)) / (tr->T * tr->T));
}

/* 计算力矩控制律（反馈线性化），返回关节力矩 Vec2 */
static Vec2 computed_torque(const Arm *a, Vec2 q, Vec2 qd,
                            Vec2 q_des, Vec2 qd_des, Vec2 qdd_des,
                            double Kp, double Kd) {
    double M[2][2];
    mass_matrix(a, q, M);
    Vec2 e    = v2_sub(q_des, q);
    Vec2 edot = v2_sub(qd_des, qd);
    Vec2 v    = v2_add(qdd_des, v2_add(v2_scale(e, Kp), v2_scale(edot, Kd)));
    /* M(q) * v */
    Vec2 mv = v2(M[0][0]*v.x + M[0][1]*v.y,
                 M[0][1]*v.x + M[1][1]*v.y);
    return v2_add(v2_add(mv, coriolis(a, q, qd)), gravity(a, q));
}

/* 正动力学：qdd = M^{-1}(tau - C qd - G) */
static Vec2 forward_dynamics(const Arm *a, Vec2 q, Vec2 qd, Vec2 tau) {
    double M[2][2];
    mass_matrix(a, q, M);
    Vec2 b = v2_sub(v2_sub(tau, coriolis(a, q, qd)), gravity(a, q));
    double det = M[0][0] * M[1][1] - M[0][1] * M[1][0];
    return v2((M[1][1] * b.x - M[0][1] * b.y) / det,
              (-M[0][1] * b.x + M[0][0] * b.y) / det);
}

/* 系统状态向量：{q1, q2, qd1, qd2} */
static void deriv(const Arm *a, const Traj *tr, double Kp, double Kd,
                  double t, const double s[4], double ds[4]) {
    Vec2 q  = v2(s[0], s[1]);
    Vec2 qd = v2(s[2], s[3]);
    Vec2 tau = computed_torque(a, q, qd, traj_pos(tr, t),
                               traj_vel(tr, t), traj_acc(tr, t), Kp, Kd);
    Vec2 qdd = forward_dynamics(a, q, qd, tau);
    ds[0] = qd.x;  ds[1] = qd.y;  ds[2] = qdd.x;  ds[3] = qdd.y;
}

/* 经典 RK4 单步 */
static void rk4_step(const Arm *a, const Traj *tr, double Kp, double Kd,
                     double t, double s[4], double dt) {
    double k1[4], k2[4], k3[4], k4[4], tmp[4], y[4];
    int i;
    deriv(a, tr, Kp, Kd, t,          s, k1);
    for (i = 0; i < 4; i++) tmp[i] = s[i] + 0.5*dt*k1[i];
    deriv(a, tr, Kp, Kd, t + 0.5*dt, tmp, k2);
    for (i = 0; i < 4; i++) tmp[i] = s[i] + 0.5*dt*k2[i];
    deriv(a, tr, Kp, Kd, t + 0.5*dt, tmp, k3);
    for (i = 0; i < 4; i++) tmp[i] = s[i] + dt*k3[i];
    deriv(a, tr, Kp, Kd, t + dt,     tmp, k4);
    for (i = 0; i < 4; i++)
        y[i] = s[i] + dt/6.0 * (k1[i] + 2.0*k2[i] + 2.0*k3[i] + k4[i]);
    for (i = 0; i < 4; i++) s[i] = y[i];
}

int main(void) {
    Arm arm = {1.0, 0.8, 2.0, 1.0, 9.81};
    Traj traj = { v2(0.10, 0.20), v2(0.55, 0.85), 3.0 };
    const double Kp = 64.0, Kd = 16.0;   /* e'' + Kd e' + Kp e = 0：临界阻尼 */
    const double dt = 1e-3;
    /* 故意偏离轨迹起点 0.02/0.05 rad，观察误差指数收敛 */
    double s[4] = { 0.08, 0.15, 0.0, 0.0 };
    int n = (int)(traj.T / dt);

    printf("  t(s)     e1       e2      |e|\n");
    for (int i = 0; i <= n; i++) {
        double t = i * dt;
        if (i % 500 == 0) {
            Vec2 q = v2(s[0], s[1]);
            Vec2 e = v2_sub(traj_pos(&traj, t), q);
            printf("%6.3f  %8.5f %8.5f  %8.5f\n", t, e.x, e.y, v2_norm(e));
        }
        rk4_step(&arm, &traj, Kp, Kd, t, s, dt);
    }
    return 0;
}
```

主程序给初始状态一个 $$0.02$$/$$0.05$$ rad 的偏差，跟踪误差从 $$\lVert e \rVert = 0.054$$ 按二阶系统特征根指数收敛到数值零，且两个关节误差互不耦合——这正是"误差动力学 $$\ddot{e} + K_d\dot{e} + K_p e = 0$$ 与机械臂无关"的直接体现。把控制器与模型的参数错开（例如控制器用 $$m_2 = 1.2$$ 而机械臂真实 $$m_2 = 1.0$$），可以直观看到建模误差如何破坏零误差跟踪，为第 14 章自适应控制留下伏笔。

## 5. 教材/论文精读

### 5.1 MLS 第 4 章：从开环到反馈线性化（MLS §4.5，pp. 189-199）

MLS 第 4 章第 5 节（Position Control and Trajectory Tracking）是本主题最凝练的表述。它先给出开环控制的致命缺陷——初始误差永不纠正，然后依次构造出两条控制律：计算力矩 (4.49) 与（增强）PD (4.51)/(4.53)。核心方法论是**把非线性机器人动力学当作一个结构已知、可用反馈"抹平"的对象**：借助质量矩阵正定与 $$\dot{M} - 2C$$ 反对称这两条结构性质，李雅普诺夫论证干净利落——计算力矩把误差动力学对消成 $$\ddot{e} + K_v \dot{e} + K_p e = 0$$（Proposition 4.8），PD 定点调节用系统总能量做李雅普诺夫函数再配拉萨尔原理（Proposition 4.9），PD 轨迹跟踪则用"扭曲等能面"的技巧证明指数稳定（Proposition 4.10）。两点启示：其一，**模型对消 + 线性综合**是机器人控制的第一性方法，几乎不需要启发式试探；其二，MLS 明确告诫，实际跟踪精度受制于对摩擦与重力的建模误差，纯 PD 无法精确跟踪非平凡轨迹——这两点直接指引了后来自适应控制与学习型控制的发展方向。

### 5.2 MLS 第 4 章末与第 6 章：任务空间与约束系统的控制（MLS §5.4 与第 6 章）

MLS §5.4 把控制器搬到任务空间，定义有效惯量 $$\tilde{M} = J^{-T} M J^{-1}$$，并证明其仍满足对称正定与反对称结构性质（Lemma 4.11），从而任务空间计算力矩 $$F = \tilde{M}(\ddot{x}_d - K_v\dot{e}_x - K_p e_x) + \tilde{C}\dot{x} + \tilde{N},\ \tau = J^{T}F$$ 的稳定性证明与关节空间逐字相同。两个重要的工程观察：任务空间增益有直接的物理含义，且无需在线解逆运动学；代价是接近奇异位形时有效惯量发散，"某个方向推不动"。MLS 第 6 章处理约束系统（抓手接触、协调操作），把接触约束写进动力学得到广义模型，把控制分解为"跟踪 + 内力调节"两部分：跟踪部分用计算力矩式的虚拟力 $$F = GJ^{-T}\tau$$ 的右逆实现，内力自由度用于把接触力保持在各接触点的摩擦锥内。MLS 还提醒了一个深刻的实现细节：对刚性机器人，力是瞬时传递的，直接对力做纯比例反馈会形成代数环 (algebraic loop)，必须在力环中引入积分器并警惕积分饱和——这一忠告对今天的力控与阻抗实现依然成立。

### 5.3 Hogan 阻抗控制论文

Hogan（1985）把"机器人应当被控制成什么"这一问题翻转过来：与其同时分别控制位置与力（混合位力控制），不如规定端部在受力时表现的**动态阻抗**。他把机械臂看成多端口网络的一端，与环境通过力-速度对交换能量，目标阻抗 $$M_d\ddot{e} + B_d\dot{e} + K_d e = F_{ext}$$ 给出了一个与具体任务无关的统一框架，位置控制与力控制都是阻抗的极限情形（刚性位置控制 = 无穷刚度，纯力控制 = 零阻抗）。这一思想奠定了现代柔顺控制与人机安全的基础，其局限在于仅靠阻抗难以同时实现高精度跟踪与低接触力抑制，后续研究发展为基于模型的任务空间阻抗与学习型阻抗调节。

## 6. 实验/编程作业

1. **PD 增益整定**：在仿真中分别增大 $$K_p$$（更硬、更易振荡）与 $$K_d$$（阻尼更强、响应更慢）观察二阶响应；用线性化式 $$M(q_0)\ddot{e} + K_d\dot{e} + K_p e = 0$$ 选增益，或用 $$K_p = \omega_n^{2}, K_d = 2\zeta\omega_n$$ 直接配临界阻尼。
2. **重力补偿的必要性**：去掉 $$G(q)$$ 项重跑定点调节，观察机械臂"下沉"留下的稳态误差；对比加回重力补偿后误差归零。这是理解"为什么要重力补偿"的最小实验。
3. **计算力矩对模型误差的敏感度**：让控制器与被控对象使用不同的质量参数，观察跟踪误差不再归零；把误差大小与失配程度画成曲线，体会"反馈线性化以模型为代价"。
4. **五次多项式轨迹**：用 3.3 节 $$s(t)$$ 生成关节轨迹并跟踪，同时打印 $$\ddot{q}_d$$，验证起止时刻加速度连续、力矩无跳变。
5. **阻抗控制（选做）**：给末端加一个"墙面"约束，比较硬/软阻抗下接触力与穿透深度，直观理解柔顺性权衡。

工程建议：把 4.1/4.2 节代码作为起点，加入速度测量低通滤波、控制器摩擦前馈、把模型参数做成可读配置文件以便做"参数失配"实验。若把积分器换成半隐式欧拉并减小步长，可对比 RK4 与低阶积分器的数值稳定性差异。

## 8. 小结

本章解决了机器人控制的核心问题：给定动力学模型与期望轨迹，如何构造力矩让机械臂鲁棒地跟踪。我们建立了从最简 PID + 重力补偿，到基于模型的计算力矩（反馈线性化），再到任务空间与阻抗控制的三级谱系。重力补偿的 PD 用系统总能量做李雅普诺夫函数，借助 $$\dot{M} - 2C$$ 反对称性证明定点渐近稳定；计算力矩用结构性质把非线性系统对消成解耦的线性二阶系统，实现指数轨迹跟踪；任务空间与阻抗控制把控制目标延伸到末端位形与接触力，为柔顺交互铺路。三者的共同根基是第 10 章导出的三条动力学结构性质。局限同样清晰：基于模型的控制依赖模型精度，阻抗控制难以同时做到高精度与低接触力——这些正是第 12 章运动规划要去生成轨迹、第 14 章学习型控制要去补模型的方向。
