# 第 5 章 正运动学

> 课程来源：EECS C106A 第 3 周 ｜ 关键词：螺旋理论、乘积指数公式 (PoE)、DH 参数、运动学链、工作空间 ｜ 预计阅读时长：~35 分钟

## 1. 导论

机械臂的"正运动学 (Forward Kinematics, FK)"要回答的问题是：**给定每个关节的变量（角度或位移），末端执行器 (End effector) 相对基坐标系 (Base frame) 处于什么位姿？** 换句话说，正运动学是一张从关节空间映射到任务空间的函数表：输入是 n 个关节变量组成的向量，输出是末端工具坐标系相对基坐标系的齐次变换矩阵。第 4 章我们建立了 SO(3) 与 SE(3) 的全部工具——旋转矩阵、齐次变换、指数坐标、旋量 (Twist)——本章就用这些工具把"每根连杆连起来"这件事讲清楚。

为什么正运动学重要？它是机器人学的"地基计算"。逆运动学（第 6 章）要解它的反问题，速度与雅可比（第 9 章）要微分它，运动规划（第 12 章）要反复调用它来判断一个目标点是否可达。几乎所有上层算法最后都要落到一句 `g = fk(q)` 上。正运动学本身并不难——无非是若干个刚体变换的连乘——但**选择哪一种"连乘方式"决定了整条知识链的风格**。本章采用 MLS 教材的螺旋理论路线：把每个关节看成一个螺旋运动 (screw motion)，末端位姿就是各关节螺旋的指数映射按顺序相乘——这就是乘积指数公式 (Product of Exponentials, PoE)。与之相对的经典路线是 DH 参数 (Denavit-Hartenberg parameters) 法，本章也会介绍，并说明两者的关系与各自的取舍。

先看最简单的例子。两连杆平面臂，杆长 l1、l2，关节角 θ1、θ2，用初等平面几何就能直接写出末端坐标 x = l1cosθ1 + l2cos(θ1+θ2)、y = l1sinθ1 + l2sin(θ1+θ2)。正运动学的本质就是这样一张映射，但我们的目标不是为每一台机械臂手工推一套公式，而是找到一种**对任意 n 关节机械臂都通用的算法**：输入关节轴数据与关节变量，输出末端位姿矩阵。本章给出的答案——乘积指数公式——把"几何推导"变成了"矩阵连乘"，于是同一段代码可以依次处理 SCARA、六自由度肘形臂乃至任意开链结构。

## 2. 关键概念与记号

**运动学链 (kinematic chain) 与关节。** 一台典型机械臂由若干刚性连杆 (link) 串联而成，相邻连杆用关节 (joint) 相连。关节类型理论上属于 SE(3) 的六类低副 (lower pair)：转动 (revolute)、移动 (prismatic)、螺旋 (helical)、圆柱、球面与平面关节。实际商用机械臂几乎只用转动关节与移动关节两种。我们记第 i 个关节连接连杆 i−1 与连杆 i，连杆 0 是基座，连杆 n 固定着末端执行器。

**关节空间 (joint space) / 配置空间 (Configuration Space)。** 所有关节变量的取值构成关节空间 Q。转动关节的变量是角度，取值在一个圆周 S^1 上；移动关节的变量是位移，取值在实轴 R 上。一个含 p 个转动关节、r 个移动关节的开链机械臂有

$$Q = T^p 	imes \mathbb{R}^r$$

个自由度的配置空间，其中 T^p 是 p 维环面（p 个 S^1 的直积）。指定关节向量 θ 就指定了整个机械臂的构型。

**两个坐标系。** 我们只需要两个坐标系：固定于连杆 0 的**基坐标系 S**，以及固定在末端执行器上的**工具坐标系 T**。这正是 PoE 方法相对于 DH 的最大优势——不需要为每根连杆都人为规定一个局部坐标系。**参考位形 (reference configuration)** 定义为所有关节变量取 0 时机械臂的位形，记工具坐标系相对基坐标系的位姿为 g_st(0) ∈ SE(3)。

**旋量 (twist)。** 第 4 章引入的旋量是李代数 se(3) 的元素，写成六维坐标

$$\xi = egin{bmatrix} v \ \omega nd{bmatrix} \in \mathbb{R}^6, \qquad \hat{\xi} = egin{bmatrix} [\omega] & v \ 0 & 0 nd{bmatrix}$$

其中 ω 是角速度方向、v 是线速度。一个关节的运动正是沿某条固定螺旋轴 (screw axis) 的螺旋运动，因此**每个关节天然对应一个旋量**。对于单位旋量（转动关节取 ‖ω‖=1，移动关节取 ‖v‖=1），关节变量 θ 沿该旋量生成的刚体运动就是矩阵指数 $$e^{\hat{\xi}	heta}$$。

直观上，旋量就是一条"螺旋"：转动关节绕螺旋轴转，移动关节沿螺旋轴滑。螺旋的**螺距 (pitch)** 定义为单位角位移对应的轴向位移——转动关节螺距为 0，移动关节螺距为无穷大，一般的螺旋关节 (helical joint) 取介于两者之间的有限值。第 4 章的 Chasles 定理告诉我们：任何刚体运动都可分解为"绕某轴的转动 + 沿同轴的移动"，即可用一条螺旋轴与一个旋量完整描述——这正是本章"每个关节 = 一个旋量"的理论依据。对单位旋量，θ 就编码了沿螺旋运动的"量"（转动角度或平移距离），而旋量的坐标 (v, ω) 只依赖参考位形下的几何（轴的方向与轴上一点），与 θ 无关。

**DH 参数。** 经典教材给每根连杆 i 规定一个局部坐标系，用四个标量描述连杆 i−1 到连杆 i 的位姿变换：连杆扭转角 α_i、连杆长度 a_i、偏置 d_i 与关节角 φ_i。四个参数的精心选取让相邻变换矩阵只含这四格量，从而把 n 自由度机械臂压缩成 4n 个参数。
