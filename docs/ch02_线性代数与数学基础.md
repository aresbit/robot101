# 第 2 章 线性代数与数学基础

> 课程来源：EECS C106A 第 1 周 Homework 0 ｜ 关键词：向量空间、矩阵运算、特征值、SVD、叉积、反对称矩阵 ｜ 预计阅读时长：~30 分钟

## 1. 导论

机器人学的底层语言是线性代数。一个三关节机械臂的正运动学，不过是一串旋转矩阵与平移向量的乘积；末端执行器的速度分析，核心对象是一个矩阵——雅可比（Jacobian）；动力学方程是带质量矩阵的矩阵微分方程；而规划与控制几乎每一步都在解线性方程组或做矩阵分解。第 1 章建立了"机器人系统"的整体图景，从本章开始我们补齐数学工具箱。
