# 后记：从旋量到飞行的机器人

到这里，我们把加州大学伯克利分校 EECS C106A 的脉络从机器人学历史一路追到了 2024 年的 UAV 级联控制与学习型控制。

## 一条主线

- **第 I 部分**（Ch 1-4）回答"机器人身体怎么描述"。从线性代数 → 旋转 SO(3) → 齐次变换 SE(3) → 旋量/螺旋，我们用数学给刚体运动建立了一座坐标系大厦。
- **第 II 部分**（Ch 5-12）回答"机器人怎么动、怎么看、怎么控"。正/逆运动学 → 视觉 → 速度与雅可比 → 动力学 → 控制 → 运动规划，一条完整的"感知-规划-控制"闭环。
- **第 III 部分**（Ch 13-14）回答"机器人怎么落地"。轮式移动、环境感知、SLAM，以及 UAV/步行/自动驾驶等前沿。

## 三条叮嘱

**1. 数学不是障碍，是地图。**
机器人学的公式（旋转矩阵、四元数、雅可比、质量矩阵）看起来吓人，但每一条都对应一个物理直觉：四元数避免万向锁、雅可比连接关节速度与末端速度、质量矩阵是惯性在关节空间的投影。本书的 C 代码让你"看见"这些公式——写一遍 `quat_mul`、`exp_se3`、`dynamics_2link`，公式就从纸面走进了手指。

**2. 动手是唯一捷径。**
Berkeley C106A 的作业体系（ROS 发布订阅 → 正运动学 → 逆运动学 → 占用栅格）是一条刻意设计的动手路径。**不要只读书**——买一块便宜的机械臂仿真（或 ROS + Gazebo），把本书第 5、6、9、10 章的 C 代码接到真实/仿真机器人上跑。物理世界会教给你书本永远不会写的"最后一公里"。

**3. 机器人学是交叉学科的交汇点。**
本书覆盖了数学（旋量理论）、力学（拉格朗日）、控制（PID/计算力矩）、感知（视觉/里程计）、规划（RRT/A*）。真正优秀的机器人工程师是这些领域的"三脚猫"——每样都懂一点，但知道什么时候该找谁。

## 接下来读什么

- **Modern Robotics (Lynch & Park)**：免费开源，旋量理论讲得比 MLS 更现代、更易读。配套 Coursera 视频课。
- **《A Mathematical Introduction to Robotic Manipulation》 (MLS)**：本书的官方教材，第 2-6 章值得精读。
- **《Probabilistic Robotics》 (Thrun, Burgard, Fox)**：SLAM 与状态估计的圣经，承接第 13 章。
- **《Multiple View Geometry》 (Hartley & Zisserman)**：计算机视觉几何的权威参考，承接第 7-8 章。
- **ROS 2 + Gazebo**：把本书算法跑在仿真机器人上，是走向工程最直接的一步。

## 一个愿望

如果你按本书过了一遍 14 章，用 C 语言把旋转、正逆运动学、雅可比、PID、RRT 各写了一遍，那么你已经拥有了一个"机器人学家的最小工具箱"。

剩下的，是找到你在乎的那个机器人问题——可能是一台双臂协作臂、一台四旋翼、一台仿人机器人，甚至是一个软体机器人——把本书的工具用在它身上。

在机器人的身体里，去理解数学；在数学的尽头，去创造机器人。
