# 第 9 章 速度与雅可比

> 课程来源：EECS C106A 第 8 周 ｜ 关键词：空间速度、体速度、雅可比矩阵、角速度/线速度、奇异分析、可操作度 ｜ 预计阅读时长：~40 分钟

## 1. 导论

前几章的正运动学回答了"关节变量 → 末端位形"的映射：给定关节角向量 $$\theta$$，乘积指数公式 (PoE) 给出末端位形 $$g_{st}(\theta) \in SE(3)$$。但机器人真正运行起来时，控制回路与轨迹规划器关心的往往是**速度**：末端要以多大的角速度和线速度运动，各关节应当以怎样的转速驱动。本章引入贯穿后续动力学、控制、规划的核心工具——**雅可比矩阵 (Jacobian)**。

雅可比矩阵本质上是正运动学映射关于关节角的"导数"的几何化表达。其难点在于：$$g_{st}(\theta)$$ 是取值于 SE(3) 的矩阵值函数，普通偏导数 $$\partial g/\partial \theta_i$$ 不是这个流形上的自然对象；若强行在 SE(3) 上取局部坐标（比如欧拉角、位置向量），得到的表达式只在局部成立，而且会破坏刚体运动的几何结构。第 4 章建立的旋量 (twist) 与伴随映射 (adjoint) 恰好提供了正确语言：末端速度可以写成 SE(3) 上的左不变量（空间速度）或右不变量（体速度），而雅可比矩阵的每一列恰好就是对应关节的旋量被"搬运"到当前位形后的坐标。这是一个远比逐项求偏导优雅的构造。

雅可比矩阵还给出了关节空间与任务空间之间的"几何透视"。把关节速度空间中的单位球 $$\lVert \dot{\theta} \rVert = 1$$ 通过雅可比映射到末端速度空间，会得到一个以原点为中心的超椭球，其各半轴长度恰为雅可比的奇异值 $$\sigma_{1}, \dots, \sigma_{m}$$。椭球越接近球，机械臂在各方向上的速度能力越均衡；椭球越扁，某个方向上的运动能力就越差；当机械臂逼近奇异位形时，一个或多个半轴趋于零，椭球退化为低维——这正是奇异最直观的图像。本章引入的度量（可操作度、条件数）都可以从这个椭球出发理解。

本章的核心问题可以概括为一句话：**关节速度 $$(\dot{\theta})$$ 与末端速度 $$(V)$$ 之间只隔着一个线性矩阵 $$J(\theta)$$。** 由此派生出三件事。第一，逆速度/微分逆运动学：当雅可比可逆时，$$\dot{\theta} = J^{-1} V$$，把它当作常微分方程积分，就能在"不显式解 IK"的情况下跟踪末端轨迹；对冗余机械臂，还要加上零空间项来做自运动 (self-motion)。第二，奇异分析：雅可比在某位形降秩时，末端会在某些方向失去瞬时运动能力，且接近奇异时所需关节转速急剧放大，因此必须能识别奇异位形；可操作度 (manipulability) 就是衡量"离奇异有多远"的标量。第三，静力学对偶：由虚功原理，关节力矩与末端力旋量之间满足 $$\tau = J^{T} F$$，力与速度共享同一个雅可比——这一对偶关系被下一章动力学直接复用。

因此，本章是全书从"几何运动学"走向"动力学与控制"的桥梁：上一章（视觉对应与双视图几何）解决感知侧的问题，本章回到运动侧；本章建立的雅可比与静力学对偶，是第 10 章动力学方程、第 11 章控制（计算力矩、阻抗控制）的共同基石。

## 2. 关键概念与记号

**空间速度 (spatial velocity)。** 设末端位形 $$g_{st}(\theta(t)) \in SE(3)$$ 随时间演化，其空间速度定义为左不变量
$$V^{s} = \dot{g}_{st}\, g_{st}^{-1}$$
它把末端速度表达成"惯性系中、与某固定参考点瞬时重合的那个刚体点的速度"。注意空间速度的线部 $$v^{s}$$ **不是**末端质心的速度，而是空间原点处刚体上瞬时与之重合那一点的速度；真正末端某点 p 的速度要用 $$v^{s} + \omega^{s} \times p$$ 恢复。

**体速度 (body velocity)。** 右不变量
$$V^{b} = g_{st}^{-1}\, \dot{g}_{st}$$
在工具（末端）坐标系下表达同一运动。两者由伴随映射联系：$$V^{s} = Ad_{g_{st}} V^{b}$$。

**旋量坐标。** 把速度写成六维向量 $$V = (v,\ \omega) \in \mathbb{R}^{6}$$，$$\omega$$ 是角速度，$$v$$ 是线部。转动关节对应旋量满足 $$v = -\omega \times q$$，其中 $$q$$ 是转轴上任意一点；移动关节对应旋量角部为零。

**伴随映射 (adjoint map)。** $$Ad_{g}: se(3) \to se(3)$$ 把旋量在不同坐标系间变换，对 $$g = (R, p)$$ 有
$$Ad_{g}\,\xi = \bigl(R v + p \times R\omega,\ R\omega\bigr)$$
这是本章所有公式的"搬运工"。

**几何雅可比 vs 解析雅可比。** 用旋量直接构造的雅可比与任何局部参数化无关，称为几何雅可比 (geometric Jacobian)；对位置坐标与欧拉角求偏导得到的称为解析雅可比 (analytic Jacobian)。两者在"末端位置线速度"上一致，在姿态部分一般不同，混用时容易出错。本章以几何雅可比为主。

**奇异位形 (singularity) 与可操作度 (manipulability)。** 雅可比降秩的位形称为奇异位形；可操作度是对"接近奇异程度"的定量度量。

## 3. 算法与公式

### 3.1 空间雅可比与体雅可比

设正运动学用乘积指数公式写出 $$g_{st}(\theta) = e^{\hat{\xi}_{1}\theta_{1}} \cdots e^{\hat{\xi}_{n}\theta_{n}} g_{st}(0)$$，其中 $$\xi_i$$ 是第 i 个关节在**参考位形**下的单位旋量。对 $$\theta_i$$ 求导并化到旋量坐标，就得到空间雅可比：

$$J_s(\theta) = \left[ \xi_1 \; Ad_{g_{s1}} \xi_2 \; \cdots \; Ad_{g_{s(n-1)}} \xi_n \right]$$

其中 $$g_{s(i-1)} = e^{\hat{\xi}_{1}\theta_{1}} \cdots e^{\hat{\xi}_{i-1}\theta_{i-1}}$$ 是前 $$i-1$$ 个关节的累积位形。这个公式的几何意义是：**第 i 列恰是第 i 个关节的转轴被带到当前位形后的旋量**。由于第 i 列只依赖前 i-1 个关节角，而且每列都有清晰的几何含义，MLS 教材强调空间雅可比可以"目测"写出（例如 SCARA 机械臂），几乎不需要额外计算。

体雅可比把关节速度映射到工具坐标系下的体速度，其第 i 列把参考旋量沿着"从当前位形回卷"的路径变换回来。两者由伴随映射互相关联：

$$J_s(\theta) = Ad_{g_{st}(\theta)} J_b(\theta)$$

实际实现时，$$g_{s(i-1)}$$ 不必对每个 i 都从头连乘，只需在遍历关节时让一个 SE(3) 累积量依次右乘 $$e^{\hat{\xi}_{i}\theta_{i}}$$：每列先取伴随、再推进累积位形，这正是第 4 节代码的做法，整体复杂度为 $$O(n)$$ 次 SE(3) 乘法与伴随。

### 3.2 速度映射与微分逆运动学

末端 twist 与关节速度满足线性关系
$$V^{s} = J_s(\theta)\,\dot{\theta},\qquad V^{b} = J_b(\theta)\,\dot{\theta}$$
末端位置 p 处的线速度按 2 节恢复：$$\dot{p} = v^{s} + \omega^{s} \times p$$。若雅可比可逆，则
$$\dot{\theta}(t) = J(\theta)^{-1} V(t)$$
把它当作常微分方程从初始位形积分，即可得到跟踪给定末端速度路径的关节轨迹——这是"速度级 IK"，用于轨迹跟踪与冗余度求解。

对冗余机械臂（自由度多于任务所需），$$J$$ 不是方阵。用 Moore-Penrose 伪逆 $$J^{\dagger} = J^{T}(J J^{T})^{-1}$$ 取最小范数解，再叠加零空间项：
$$\dot{\theta} = J^{\dagger} V + \bigl(I - J^{\dagger} J\bigr) z$$
第二项不改变末端速度，只调整关节位形，构成沿**自运动流形 (self-motion manifold)** 的内部运动，可用于避障、避奇异、保持关节限位等次级目标。

### 3.3 奇异分析与可操作度

机械臂在奇异位形丢失至少一个运动方向上的自由度。对 6 自由度臂，雅可比不可逆，末端在某些方向无法瞬时运动；更麻烦的是，**接近奇异时维持相同末端速度所需的关节转速会急剧增大**，容易触达速度/力矩饱和。MLS 给出三类典型的几何奇异条件：两个共线转动关节（腕部对折）、三个平行共面转动轴（肘部伸直）、四个转动轴交于一点（肩部），均可通过观察机制几何直接判断。

可操作度 (manipulability，Yoshikawa 1985) 定义为：
$$w = \sqrt{\det(J J^T)}$$
当 $$w \to 0$$ 时逼近奇异。对 2×2 方阵雅可比，$$\det(J J^{T}) = (\det J)^{2}$$，故 $$w = \lvert \det J \rvert$$。更精细的度量是奇异值与条件数：$$\sigma_{\min}$$ 越小、条件数 $$\kappa = \sigma_{\max}/\sigma_{\min}$$ 越大，表示末端在"最弱方向"上的速度增益越差。需要提醒的是，可操作度依赖 $$\mathbb{R}^{6}$$ 上的欧氏度量，而伴随映射不保持该度量，因此它不是坐标不变的——把末端坐标系平移/旋转一下，可操作度的数值乃至极值点位置都会改变（MLS 附录 A.26），用作机械臂设计指标时须谨慎。

对 n 关节机械臂，若雅可比在任务空间中降秩为 r < m，则末端只能在 r 个方向上瞬时运动，其余 m−r 个方向被"锁死"；与此同时，关节空间里满足 $$J\dot{\theta} = 0$$ 的位移构成零空间，沿它的内部运动不改变末端速度。这两者从"失"与"存"两个侧面完整刻画了奇异位形处机械臂的运动自由度。

### 3.4 静力学对偶

由虚功原理，当机械臂处于静平衡时，关节力矩 $$\tau$$ 与末端力旋量 $$F = (f, m)$$ 之间满足
$$\tau = J^{T} F$$
即"末端能施加多大外力"与"末端能多快运动"由同一个雅可比矩阵决定——雅可比同时是速度映射与力映射。这一对偶在下一章（动力学）与第 11 章（阻抗/导纳控制）中反复出现。

## 4. C 语言实现

本节给出两段完整的 C11 程序。第一段 (a) 用旋量与伴随映射按公式 $$J_s(\theta) = [\xi_1 \ Ad_{g_{s1}} \xi_2]$$ 计算 2 关节平面臂的空间雅可比，并与解析雅可比交叉验证；第二段 (b) 在多个位形上采样，打印可操作度随 $$\theta_2$$ 的变化并定位奇异位形。

### 4.1 空间雅可比：旋量与伴随映射

```c
/*
 * 示例 (a): 2 关节平面臂的空间雅可比 (Spatial Jacobian)
 * 编译运行:  gcc -std=c11 -Wall -Wextra -o jac_s jac_s.c -lm && ./jac_s
 *
 * 核心公式 (MLS, Velocities, Statics, and Jacobians):
 *   J_s(theta) = [ xi_1   Ad_{g_{s1}} xi_2   ...   Ad_{g_{s(n-1)}} xi_n ]
 *   列 i = 第 i 关节旋量 xi_i 被 Ad_{g_{s(i-1)}} 变换到当前位形,
 *   其中 g_{s(i-1)} = exp(xi1_hat*theta1) ... exp(xi_{i-1}_hat*theta_{i-1})
 *   是前 i-1 个关节的累积位形 (SE(3))。
 */
#include <stdio.h>
#include <math.h>
#include <string.h>

#define MAX_N 6
#define L1 1.0
#define L2 1.0

/* se(3) 元素: (线部 v, 角部 w), 即 twist 坐标 */
typedef struct { double v[3]; double w[3]; } Twist;
/* SE(3) 齐次变换: 旋转 R 与平移 p */
typedef struct { double R[3][3]; double p[3]; } SE3;
/* 通用矩阵: 最多 6 行 x MAX_N 列 */
typedef struct { int m, n; double a[6][MAX_N]; } Mat;

/* 罗德里格斯公式: 绕单位轴 w 旋转 theta 得旋转矩阵 R */
static void rodrigues(const double w[3], double theta, double R[3][3])
{
    double c = cos(theta), s = sin(theta), vt = 1.0 - c;
    double wx = w[0], wy = w[1], wz = w[2];
    R[0][0] = c + wx*wx*vt;     R[0][1] = wx*wy*vt - wz*s;  R[0][2] = wx*wz*vt + wy*s;
    R[1][0] = wx*wy*vt + wz*s;  R[1][1] = c + wy*wy*vt;     R[1][2] = wy*wz*vt - wx*s;
    R[2][0] = wx*wz*vt - wy*s;  R[2][1] = wy*wz*vt + wx*s;  R[2][2] = c + wz*wz*vt;
}

/* SE(3) 乘法: out = a * b */
static void se3_mul(const SE3 *a, const SE3 *b, SE3 *out)
{
    int i, j;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            out->R[i][j] = a->R[i][0]*b->R[0][j] + a->R[i][1]*b->R[1][j]
                         + a->R[i][2]*b->R[2][j];
    for (i = 0; i < 3; i++)
        out->p[i] = a->R[i][0]*b->p[0] + a->R[i][1]*b->p[1]
                  + a->R[i][2]*b->p[2] + a->p[i];
}

/* 从转动旋量恢复轴上一个点: 轴点 q = w x v (w 为单位向量) */
static void axis_point(const Twist *xi, double q[3])
{
    q[0] =  xi->w[1]*xi->v[2] - xi->w[2]*xi->v[1];
    q[1] =  xi->w[2]*xi->v[0] - xi->w[0]*xi->v[2];
    q[2] =  xi->w[0]*xi->v[1] - xi->w[1]*xi->v[0];
}

/* 转动螺旋的指数映射: exp(xi_hat * theta), 即绕轴 (轴点 q, 方向 w) 旋转 theta */
static void exp_revolute(const Twist *xi, double theta, SE3 *out)
{
    double q[3], e[3];
    int i, j;
    axis_point(xi, q);
    rodrigues(xi->w, theta, out->R);
    for (i = 0; i < 3; i++) {
        e[i] = 0.0;
        for (j = 0; j < 3; j++) e[i] += out->R[i][j] * q[j];  /* e = R q */
        out->p[i] = q[i] - e[i];                              /* p = (I-R) q */
    }
}

/* 伴随作用 Ad_g(xi) = ( R v + p x (R w) , R w ) */
static void adjoint(const SE3 *g, const Twist *xi, Twist *out)
{
    double Rv[3], Rw[3], pxr[3];
    int i, j;
    for (i = 0; i < 3; i++) {
        Rv[i] = 0.0; Rw[i] = 0.0;
        for (j = 0; j < 3; j++) {
            Rv[i] += g->R[i][j] * xi->v[j];
            Rw[i] += g->R[i][j] * xi->w[j];
        }
    }
    pxr[0] = g->p[1]*Rw[2] - g->p[2]*Rw[1];
    pxr[1] = g->p[2]*Rw[0] - g->p[0]*Rw[2];
    pxr[2] = g->p[0]*Rw[1] - g->p[1]*Rw[0];
    for (i = 0; i < 3; i++) {
        out->v[i] = Rv[i] + pxr[i];
        out->w[i] = Rw[i];
    }
}

/* 空间雅可比: J_s(theta) 的第 i 列 = Ad_{g_{s(i-1)}} xi_i (6 x n) */
void spatial_jacobian(const Twist *screws, const double *theta, int n, Mat *J)
{
    SE3 g, ei, g2;
    int i, j;
    memset(&g, 0, sizeof(g));
    for (i = 0; i < 3; i++) g.R[i][i] = 1.0;   /* 从恒等位形出发 */

    J->m = 6;
    J->n = n;
    for (i = 0; i < n; i++) {
        Twist col;
        adjoint(&g, &screws[i], &col);
        for (j = 0; j < 3; j++) {
            J->a[j][i]     = col.v[j];
            J->a[3 + j][i] = col.w[j];
        }
        exp_revolute(&screws[i], theta[i], &ei);
        se3_mul(&g, &ei, &g2);                 /* 累积位形 g <- g * exp(xi_i*theta_i) */
        g = g2;
    }
}

/* 解析雅可比 (2x2, 末端线速度部分), 用于数值验证 */
static void analytic_jacobian(double t1, double t2, double J[2][2])
{
    double s1 = sin(t1), c1 = cos(t1);
    double s12 = sin(t1 + t2), c12 = cos(t1 + t2);
    J[0][0] = -L1*s1 - L2*s12;  J[0][1] = -L2*s12;
    J[1][0] =  L1*c1 + L2*c12;  J[1][1] =  L2*c12;
}

int main(void)
{
    /* 关节 1: 轴线过原点, 方向 z; 关节 2: 参考位形轴线过 (L1,0,0), 方向 z */
    Twist screws[2];
    screws[0].v[0] = 0.0; screws[0].v[1] = 0.0; screws[0].v[2] = 0.0;
    screws[0].w[0] = 0.0; screws[0].w[1] = 0.0; screws[0].w[2] = 1.0;
    screws[1].v[0] = 0.0; screws[1].v[1] = -L1; screws[1].v[2] = 0.0;  /* v = -w x q */
    screws[1].w[0] = 0.0; screws[1].w[1] = 0.0; screws[1].w[2] = 1.0;

    double theta[2] = {0.5, 0.8};
    double thetadot[2] = {0.3, -0.5};
    Mat Js;
    spatial_jacobian(screws, theta, 2, &Js);

    printf("空间雅可比 J_s(0.5, 0.8)  (6 x 2):\n");
    for (int i = 0; i < 6; i++)
        printf("  [ %8.4f   %8.4f ]\n", Js.a[i][0], Js.a[i][1]);

    /* 末端线速度: pdot = v^s + w^s x p (p 为末端位置, 空间坐标) */
    double t1 = theta[0], t2 = theta[1];
    double p[3] = {L1*cos(t1) + L2*cos(t1 + t2),
                   L1*sin(t1) + L2*sin(t1 + t2), 0.0};
    double vs[3] = {0, 0, 0}, ws[3] = {0, 0, 0};
    for (int j = 0; j < 2; j++)
        for (int i = 0; i < 3; i++) {
            vs[i] += Js.a[i][j]     * thetadot[j];
            ws[i] += Js.a[3 + i][j] * thetadot[j];
        }
    double pdot[3];
    pdot[0] = vs[0] + ws[1]*p[2] - ws[2]*p[1];
    pdot[1] = vs[1] + ws[2]*p[0] - ws[0]*p[2];
    pdot[2] = vs[2] + ws[0]*p[1] - ws[1]*p[0];

    double Ja[2][2];
    analytic_jacobian(t1, t2, Ja);
    double pdota[2];
    pdota[0] = Ja[0][0]*thetadot[0] + Ja[0][1]*thetadot[1];
    pdota[1] = Ja[1][0]*thetadot[0] + Ja[1][1]*thetadot[1];

    printf("\n验证: 空间雅可比末端线速度 vs 解析雅可比\n");
    printf("  pdot (twist)   = ( %7.4f, %7.4f )\n", pdot[0], pdot[1]);
    printf("  pdot (analytic)= ( %7.4f, %7.4f )\n", pdota[0], pdota[1]);
    printf("  差值            = ( % .3e, % .3e )\n",
           pdot[0] - pdota[0], pdot[1] - pdota[1]);
    return 0;
}
```

运行结果中，空间雅可比在参考位形之外由伴随映射逐步累积而来，其给出的末端线速度与解析雅可比一致到机器精度（差值约为 $$10^{-17}$$），这验证了公式与实现的正确性。代码把矩阵抽象为 `Mat` 结构（最多 6 行、MAX_N 列），`spatial_jacobian` 的签名即本章建议的形式，可直接推广到 n 关节。

### 4.2 可操作度与奇异分析

```c
/*
 * 示例 (b): 2 关节平面臂的可操作度与奇异分析
 * 编译运行:  gcc -std=c11 -Wall -Wextra -o manip manip.c -lm && ./manip
 *
 * 可操作度 (Manipulability, Yoshikawa 1985): w = sqrt(det(J J^T)).
 * 对 2x2 平面臂解析雅可比, det(J J^T) = (det J)^2, 故 w = |det J|
 * = L1*L2*|sin(theta2)|。当 theta2 -> 0 或 pi (臂伸直/折叠) 时 w -> 0,
 * 机械臂处于奇异位形, 最小奇异值 sigma_min = 0, 条件数趋于无穷。
 */
#include <stdio.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

#define L1 1.0
#define L2 1.0

/* 平面 2R 臂解析雅可比 (2x2, 末端线速度) */
static void analytic_jacobian(double t1, double t2, double J[2][2])
{
    double s1 = sin(t1), c1 = cos(t1);
    double s12 = sin(t1 + t2), c12 = cos(t1 + t2);
    J[0][0] = -L1*s1 - L2*s12;  J[0][1] = -L2*s12;
    J[1][0] =  L1*c1 + L2*c12;  J[1][1] =  L2*c12;
}

/* 2x2 对称矩阵 M = J J^T 的特征值 (解析求根) */
static void eigs_sym2(const double M[2][2], double *lam_max, double *lam_min)
{
    double tr = M[0][0] + M[1][1];
    double det = M[0][0]*M[1][1] - M[0][1]*M[1][0];
    double d = sqrt(tr*tr - 4.0*det);
    *lam_max = (tr + d) / 2.0;
    *lam_min = (tr - d) / 2.0;
}

int main(void)
{
    printf(" theta2    |det J|    w=sqrt(det(JJ^T))   sigma_min    cond(J)\n");
    printf("-----------------------------------------------------------------\n");
    for (double t2 = 0.0; t2 <= M_PI + 1e-12; t2 += M_PI / 16.0) {
        double J[2][2], JJ[2][2];
        analytic_jacobian(0.35, t2, J);           /* 固定 theta1, 扫描 theta2 */

        /* JJ = J * J^T */
        for (int i = 0; i < 2; i++)
            for (int j = 0; j < 2; j++)
                JJ[i][j] = J[i][0]*J[j][0] + J[i][1]*J[j][1];

        double det = J[0][0]*J[1][1] - J[0][1]*J[1][0];
        double w = sqrt(fabs(det * det));         /* sqrt(det(JJ^T)) = |det J| */
        double lamax, lamin;
        eigs_sym2(JJ, &lamax, &lamin);
        double smax = sqrt(lamax), smin = sqrt(fabs(lamin));
        double cond = (smin > 1e-12) ? smax / smin : HUGE_VAL;

        printf("%6.3f   %8.4f    %8.4f       %8.4f    %9.3f\n",
               t2, det, w, smin, cond);
    }
    printf("\n结果分析: 当 theta2 = 0 与 pi 时行列式为 0 (臂完全伸直或折叠),\n");
    printf("最小奇异值 sigma_min = 0, 条件数趋近无穷 —— 该位形不可求逆;\n");
    printf("可操作度 w = sqrt(det(JJ^T)) = L1*L2*|sin(theta2)| 同时归零,\n");
    printf("此时末端在某个方向失去运动自由度, 微小的末端速度需要极大关节转速。\n");
    return 0;
}
```

程序扫描 $$\theta_2$$ 从 0 到 π 的 17 个采样点，对每个位形计算行列式、可操作度、最小奇异值与条件数。输出清晰地显示：在 $$\theta_2 = 0$$ 与 $$\theta_2 = \pi$$（臂完全伸直/完全折叠）处 $$w = 0$$、$$\sigma_{\min} = 0$$、条件数趋于无穷——这正是奇异位形；在 $$\theta_2 = \pi/2$$ 附近可操作度最大（单位臂长下 $$w = 1$$），运动能力最好。奇异值仅需对 2×2 矩阵解析求特征根，不依赖任何外部线性代数库，符合全书"手写矩阵运算"的数值风格。

## 5. 教材/论文精读

**MLS 的雅可比构造法。** 本课程把本章主题对应到 MLS 教材的 "Velocities, Statics, and Jacobians"（课程阅读清单记为 MLS 第 5 章；印刷版正文位于第 3 章第 4 节）。MLS 的核心思想是：不要对 SE(3) 取局部坐标求偏导，而用李代数的伴随作用把雅可比写成显式的列向量形式 $$J_s = [\xi_1,\ Ad_{g_{s1}}\xi_2,\ \dots]$$。第 i 列只依赖前 i-1 个关节角，且几何意义就是"第 i 个关节轴被搬运到当前位形"。这带来两个直接好处：其一，对大多数机械臂，雅可比可"目测"直接写出，无需数值微分；其二，它为后续的奇异几何分类、冗余求解提供了统一框架。MLS 用 SCARA 与 Stanford 臂两个例子演示了这一方法的威力。

**奇异位形的几何分类。** MLS 对 6 自由度臂给出三类典型的奇异条件：两个共线转动关节、三个平行共面转动轴、四个转动轴交于一点。证明的思路很有启发性——要么用初等列变换消去某列为零，要么更换坐标系（伴随映射不改变秩）再观察线性相关。这告诉我们：奇异是机制几何的固有属性，可以通过观察关节轴的空间关系直接判定，而不必每次都做数值秩判断。工程上更值得警惕的是奇异"附近"：此时行列式很小但非零，雅可比仍然可逆，条件数却已很大，维持末端速度需要天文数字的关节转速，实际中先于奇异发生的是速度/力矩饱和。

**可操作度的坐标依赖陷阱。** MLS 附录 (A.26) 给出了一个常被忽视的警告：可操作度、最小奇异值、条件数这些量依赖 $$\mathbb{R}^{6} \cong se(3)$$ 上选取的欧氏度量，而伴随映射并不保持该度量。把末端工具坐标系平移或旋转一下，同一个位形算出的可操作度会改变，甚至"可操作度极值点的位置"都会移动。因此基于最小奇异值最大化的机械臂设计优化问题在数学上是 ill-posed。启示是：在工程中使用这些指标做横向对比时，务必固定末端坐标系与长度单位；若目标只是"相对地避开奇异"，条件数仍是实用而稳定的近似指标。Yoshikawa (1985) 提出可操作度的原始论文同样建立在这一度量选择之上，阅读时应对这一前提保持清醒。

## 6. 实验/编程作业

对应 EECS C106A 第 8 周，建议按以下递进完成：首先，把第 5 章写好的 PoE 正运动学与本节的 `spatial_jacobian` 接起来，输出 6×n 空间雅可比，并用中心差分（$$\partial g/\partial \theta_i \approx (g(\theta + h e_i) - g(\theta - h e_i))/(2h)$$）数值验证雅可比列。其次，实现一个速度级 IK：给定期望末端速度 V，用 $$\dot{\theta} = J^{\dagger} V$$ 加上零空间项做轨迹跟踪，观察冗余关节的自运动。再次，复现示例 (b) 的可操作度扫描，把工作空间内的 $$w$$ 画成热图，标注奇异位形。最后，做一个"奇异规避"实验：当条件数超过阈值时，把零空间梯度选为增大可操作度的方向，观察机械臂如何"绕开"奇异。调试时可先只用末端线速度部分的 2 行雅可比（平面臂），再扩展到完整 6 维。实现时注意两个工程细节：一是中心差分验证雅可比时步长取 $$h \approx 10^{-6}$$ 量级，太大带来截断误差，太小则被浮点舍入淹没；二是速度级 IK 在奇异附近数值会发散，务必监控条件数，并采用阻尼最小二乘保护：$$\dot{\theta} = (J^{T}J + \lambda I)^{-1}J^{T} V$$（Levenberg–Marquardt 思想），其中 $$\lambda$$ 越小越精确、越大越稳健。

## 8. 小结

本章把"关节速度—末端速度"的关系归结为一个位形相关的线性矩阵——雅可比。利用旋量与伴随映射，空间雅可比可以显式写出且几何含义清晰；通过它我们能做速度级逆运动学、冗余求解与奇异分析。可操作度与条件数提供了度量"离奇异多远"的定量工具，但须注意其对坐标系度量的依赖。最后，静力学对偶 $$\tau = J^{T} F$$ 表明力与速度共享同一个雅可比，这为下一章的动力学与后续的控制方法铺平了道路。
