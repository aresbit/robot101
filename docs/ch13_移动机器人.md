# 第 13 章 移动机器人与环境感知

> 课程来源：EECS C106A 第 7-8 周（Lab 4/6）｜ 关键词：轮式机器人、里程计、占用栅格、SLAM 基础、TurtleBot、ROS ｜ 预计阅读时长：~45 分钟

## 1. 导论

前十二章讨论的机械臂，基座都假定被固定在工作台或机座上，末端在可达工作空间内完成精确运动。但机器人的真正价值往往在"走出车间"时体现：扫地机在客厅里巡游，AGV 在仓库里搬运，无人车在街道上行驶。这类系统被称为**移动机器人 (mobile robot)**，它与机械臂有两个本质区别。第一，基座不再固定，机器人的位形由它在平面上的位置与朝向描述，运动由轮子与地面的接触产生，这带来全新的运动学结构（非完整约束）。第二，环境通常未知且动态，机器人不能靠离线建模的精确几何来规划，而必须用传感器（轮式编码器、激光雷达、相机）在运行中"感知"世界——定位（我在哪）、建图（周围长什么样）、以及二者的耦合（SLAM）。

本章是全书从"分析刚性运动"转向"在不确定性下行动"的一章。运动规划（第 12 章）假设给定一张地图，本章回答这张地图从哪来、以及机器人如何在地图中持续跟踪自己的位置。第 14 章在此基础上讨论学习与更前沿的感知。我们把内容组织为三层：底层是差速轮式机器人的运动学与里程计（运动侧），中层是占用栅格与栅格更新（感知侧），上层是概率定位与 SLAM 的框架（贝叶斯视角）。所有实现都面向 ROS + TurtleBot 这一主流学生机器人平台，且可在纯 C11 中复现。

## 2. 关键概念与记号

**位形与配置空间。** 平面移动机器人的位形为 $$q = (x, y, \theta) \in \mathbb{R}^{2} \times S^{1}$$，其中 $$(x, y)$$ 是世界系下的位置，$$\theta$$ 是朝向角。与机械臂的关节空间不同，这里的配置空间不是欧氏空间而是流形，绕一圈回到原朝向意味着 $$\theta$$ 走了 $$2\pi$$。

**非完整约束 (nonholonomic constraint)。** 差速机器人的左右轮只能纯滚动、不能侧滑，于是机器人不能瞬时侧移，只能在朝向方向上平移或绕瞬时转动中心旋转。纯滚动条件写作
$$\dot{x}\sin\theta - \dot{y}\cos\theta = 0$$
这个速度约束不可积：它不能化为某个位形函数 $$h(x, y, \theta) = 0$$。不可积性正是"能停到任意位置却需要倒车入库"的数学根源，也是第 12 章非完整运动规划的对象。

**里程计 (odometry)。** 用轮式编码器测得的左右轮转速，通过运动学推算位形随时间的变化，称为里程计，也叫航位推算 (dead reckoning)。它便宜、高频，但误差（滑移、轮胎打滑）随时间无界累积，故只能作为短时估计。因此里程计通常只用来驱动贝叶斯滤波的预测步，真正的修正必须依赖能"回望"环境的传感器——2D 激光雷达测距直观、对光照不敏感，是入门移动机器人最常用的选择。

**占用栅格 (occupancy grid)。** 把地图离散成等间距格子，每个格子 $$m_i$$ 存一个取值于 $$[0,1]$$ 的占据概率。占用栅格是本章建图的核心数据结构：栅格地图天然适合激光雷达这类测距传感器，也便于后续规划算法直接查询。

**log-odds 与逆传感器模型。** 概率估计用 log-odds 表示加法更方便。占用栅格更新每次扫描只做一次加法，比乘除稳定高效，这是工程上大量使用的技巧。

**贝叶斯滤波 (Bayes filter)。** 定位问题的统一框架：用一个信念分布 $$bel(x_t)$$ 表示对当前位形的置信度，用运动模型做预测、用传感器模型做修正。粒子滤波与卡尔曼滤波都是它的特例。

**ROS 生态。** ROS（机器人操作系统）提供进程间通信（话题 topic、服务 service）、坐标树 tf、可视化 RViz 等基础设施。TurtleBot 是最常见的 ROS 入门移动机器人，差速底盘 + 2D 激光雷达的组合贯穿本课程 Lab 4/6。

## 3. 算法与公式

### 3.1 差速轮式机器人运动学

设轮半径为 $$r$$，左右轮角速度为 $$\omega_L, \omega_R$$，机器人中心到单侧轮的横向距离（半轮距）为 $$\ell$$。纯滚动下，中心线速度与角速度由左右轮平均与差分决定：
$$v = \frac{r}{2}\bigl(\omega_L + \omega_R\bigr), \qquad \omega = \frac{r}{2\ell}\bigl(\omega_R - \omega_L\bigr)$$
实际控制中常需**逆运动学**：给定期望 $$(v, \omega)$$，解出左右轮指令：
$$\omega_L = \frac{v - \ell\,\omega}{r}, \qquad \omega_R = \frac{v + \ell\,\omega}{r}$$
注意符号约定：$$\omega > 0$$ 为逆时针（左转），要求右轮更快（$$\omega_R - \omega_L > 0$$），与上式一致。特别地，令 $$v=0$$ 即原地旋转，令 $$\omega=0$$ 即直线行驶。

### 3.2 里程计积分

把机器人当成"速度控制"的质点，其运动方程为单轮车模型 (unicycle model)：
$$\dot{x} = v\cos\theta, \qquad \dot{y} = v\sin\theta, \qquad \dot{\theta} = \omega$$
给定一个时间步 $$\Delta t$$ 内的恒定 $$(v, \omega)$$，用**中点法**积分（比一阶欧拉更贴近圆弧）：
$$\theta_{k+\frac{1}{2}} = \theta_k + \tfrac12\,\omega\,\Delta t$$
$$x_{k+1} = x_k + v\cos\bigl(\theta_{k+\frac{1}{2}}\bigr)\Delta t, \qquad y_{k+1} = y_k + v\sin\bigl(\theta_{k+\frac{1}{2}}\bigr)\Delta t, \qquad \theta_{k+1} = \theta_k + \omega\,\Delta t$$
每收到一帧编码器读数就执行一次更新，累计出轨迹。第 4 节的 `odometry_update` 即此式。

### 3.3 占用栅格与贝叶斯更新

记第 $$i$$ 个格子的 log-odds 为 $$\ell_t(m_i) = \log\frac{p(m_i \mid z_{1:t})}{1 - p(m_i \mid z_{1:t})}$$。假设各格子独立且每次测量独立，则栅格更新退化为逐格加法：
$$\ell_t(m_i) = \ell_{t-1}(m_i) + \log\frac{p(m_i \mid z_t)}{1 - p(m_i \mid z_t)} - \ell_0$$
其中 $$\ell_0 = \log\frac{p(m_i)}{1 - p(m_i)}$$ 是先验（通常取 $$p(m_i)=0.5$$ 使 $$\ell_0 = 0$$）。这里的 $$p(m_i \mid z_t)$$ 来自**逆传感器模型 (inverse sensor model)**：对一束打到距离 $$d$$ 处的激光，射线穿过的格子赋一个小自由概率（如 0.4，对应更新量 $$\log\frac{0.4}{0.6}\approx -0.4$$），命中端点格子赋一个大占据概率（如 0.7，对应 $$+0.85$$），更远的格子不更新。需要概率时用 sigmoid 反变换：
$$p(m_i \mid z_{1:t}) = \frac{1}{1 + e^{-\ell_t(m_i)}}$$
把 log-odds 与阈值比较即可得"自由 / 未知 / 占据"三态。规划器常用的**最近自由格**查询，就是从机器人所在格沿半径扩散、找到第一个 log-odds 低于自由阈值的格子，作为局部避障的目标点。

### 3.4 概率定位与 SLAM 框架

定位本质是贝叶斯滤波。给定上一时刻信念、控制 $$u_{t-1}$$ 与观测 $$z_t$$，先做预测（运动模型）再做修正（传感器模型）：
$$\overline{bel}(x_t) = \int p(x_t \mid x_{t-1}, u_{t-1})\, bel(x_{t-1})\, dx_{t-1}$$
$$bel(x_t) = \eta\, p(z_t \mid x_t)\, \overline{bel}(x_t)$$
粒子滤波用一组加权样本近似信念，适用于非高斯、多模态情况，是 2D 定位的主流（MCL）。SLAM 把定位与建图同时求解：已知地图可定位、已知位形可建图，两者互相依赖，于是用联合后验 $$p(x_{1:t}, m \mid z_{1:t}, u_{1:t})$$ 建模，常见解法有 EKF-SLAM、Rao-Blackwellized 粒子滤波（gmapping）、图优化 SLAM（Cartographer）。图优化把每个时刻的位形当作节点、把观测当作约束，用最小二乘优化整张位姿图；一旦回环被识别，一条闭环约束就能把累积误差压缩回全局一致，这是现代建图系统（如 Cartographer）能保持地图一致性的关键。本章只建立框架，具体实现见延伸阅读。

## 4. C 语言实现

**代码块 A：差速运动学与里程计。** 演示逆运动学解算左右轮转速，以及用中点法对 unicycle 模型积分。

```c
/* ch13_blockA.c — 差速轮式机器人运动学与里程计
 * 编译: gcc -std=c11 -Wall -Wextra ch13_blockA.c -lm -o blockA
 */
#include <stdio.h>
#include <math.h>

/* 平面位形: 世界坐标 (x, y) 与朝向角 theta(弧度) */
typedef struct {
    double x, y, theta;
} Pose;

/*
 * differential_drive: 由期望机器人速度 v 与角速度 w 反解左右轮角速度。
 *   r : 轮半径 (m)
 *   l : 半轮距, 机器人中心到单侧轮的横向距离 (m)
 * 解 (v = r(wL+wR)/2,  w = r(wR-wL)/(2l)) 得:
 *   wL = (v - l*w)/r,  wR = (v + l*w)/r
 */
void differential_drive(const double v, const double w,
                        double *vl, double *vr,
                        double r, double l)
{
    *vl = (v - l * w) / r;
    *vr = (v + l * w) / r;
}

/*
 * odometry_update: 里程计积分 (中点法)。
 *   x += v*cos(theta_mid)*dt,  y += v*sin(theta_mid)*dt,  theta += w*dt
 * 返回更新后的位形。
 */
Pose odometry_update(Pose p, double v, double w, double dt)
{
    double th_mid = p.theta + 0.5 * w * dt;   /* 用区间中点朝向估计弧段方向 */
    p.x     += v * cos(th_mid) * dt;
    p.y     += v * sin(th_mid) * dt;
    p.theta += w * dt;
    return p;
}

int main(void)
{
    /* TurtleBot 常用参数: 轮半径 0.035 m, 半轮距 0.08 m */
    const double r = 0.035, l = 0.08;
    double vl, vr;

    /* 场景 1: 前进同时旋转 -> 圆弧运动 */
    differential_drive(0.2, 0.5, &vl, &vr, r, l);
    printf("前进+旋转: vl = %7.4f rad/s, vr = %7.4f rad/s\n", vl, vr);

    /* 场景 2: 原地旋转 (v = 0) */
    differential_drive(0.0, 1.0, &vl, &vr, r, l);
    printf("原地旋转: vl = %7.4f rad/s, vr = %7.4f rad/s\n", vl, vr);

    /* 场景 3: 由编码器测得左右轮角速度, 反推 v, w 并做里程计积分 */
    double wL = 10.0, wR = 12.0;              /* rad/s */
    double v  = r * (wL + wR) / 2.0;
    double w  = r * (wR - wL) / (2.0 * l);
    Pose pose = {0.0, 0.0, 0.0};
    printf("里程计积分: v = %.3f m/s, w = %.3f rad/s\n", v, w);
    for (double t = 0.0; t <= 2.0 + 1e-9; t += 0.1) {
        printf("t = %4.1f s   x = %7.3f   y = %7.3f   theta = %7.3f rad\n",
               t, pose.x, pose.y, pose.theta);
        pose = odometry_update(pose, v, w, 0.1);
    }
    return 0;
}
```

**代码块 B：占用栅格与激光栅格更新。** 用 Bresenham 画线把一条激光射线化为栅格单元序列：中间格子标记为自由、端点格子标记为占据，全部以 log-odds 加法累积；随后从机器人格向外找最近自由格，作为局部规划目标。

```c
/* ch13_blockB.c — 占用栅格与激光扫描栅格更新
 * 编译: gcc -std=c11 -Wall -Wextra ch13_blockB.c -lm -o blockB
 */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

#define L_FREE    -0.6   /* 射线中间格的单次自由更新量 (log-odds) */
#define L_OCC      0.9   /* 命中格的单次占据更新量 (log-odds)    */
#define TH_FREE   -0.3   /* log-odds 低于此阈值判为"自由"        */
#define TH_OCC     0.3   /* log-odds 高于此阈值判为"占据"        */

/* 占用栅格: cells[j*w + i] 存格 (i, j) 的 log-odds 占据值 */
typedef struct {
    int w, h;                    /* 宽, 高 (格) */
    double res;                  /* 每格边长 (m) */
    double origin_x, origin_y;   /* 格 (0,0) 中心的世界坐标 */
    double *cells;               /* w*h 个 double, 动态数组 */
} GridMap;

GridMap *grid_new(int w, int h, double res, double ox, double oy)
{
    GridMap *g = malloc(sizeof(GridMap));
    g->w = w; g->h = h; g->res = res;
    g->origin_x = ox; g->origin_y = oy;
    g->cells = calloc((size_t)w * h, sizeof(double));
    return g;
}

void grid_free(GridMap *g) { free(g->cells); free(g); }

/* Bresenham 画线: 列出 (x0,y0)->(x1,y1) 之间所有整数格点, 写入 out_x/out_y,
 * 返回格点总数 (不超过 out_cap)。*/
int bresenham_line(int x0, int y0, int x1, int y1,
                   int *out_x, int *out_y, int out_cap)
{
    int n = 0;
    int dx = abs(x1 - x0), sx = x0 < x1 ? 1 : -1;
    int dy = -abs(y1 - y0), sy = y0 < y1 ? 1 : -1;
    int err = dx + dy;
    for (;;) {
        if (n < out_cap) { out_x[n] = x0; out_y[n] = y0; }
        n++;
        if (x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if (e2 >= dy) { err += dy; x0 += sx; }
        if (e2 <= dx) { err += dx; y0 += sy; }
    }
    return n;
}

/* 激光一束射线: 从格 (gx,gy) 沿朝向 theta 射到距离 dist。
 * 射线经过的格子标记为自由, 端点命中格标记为占据 (log-odds 加法)。*/
void ray_update(GridMap *g, int gx, int gy, double theta, double dist)
{
    double ex = g->origin_x + (gx + 0.5) * g->res;   /* 机器人世界坐标 */
    double ey = g->origin_y + (gy + 0.5) * g->res;
    int x1 = (int)floor((ex + dist * cos(theta) - g->origin_x) / g->res);
    int y1 = (int)floor((ey + dist * sin(theta) - g->origin_y) / g->res);

    int cap = (abs(x1 - gx) + abs(y1 - gy) + 1) * 2 + 8;
    int *xs = malloc(sizeof(int) * (size_t)cap);
    int *ys = malloc(sizeof(int) * (size_t)cap);
    int n = bresenham_line(gx, gy, x1, y1, xs, ys, cap);

    for (int k = 0; k < n - 1; k++) {          /* 中间格 -> 自由 */
        if (xs[k] >= 0 && xs[k] < g->w && ys[k] >= 0 && ys[k] < g->h)
            g->cells[ys[k] * g->w + xs[k]] += L_FREE;
    }
    if (n > 0) {                                /* 端点格 -> 占据 */
        int i = xs[n-1], j = ys[n-1];
        if (i >= 0 && i < g->w && j >= 0 && j < g->h)
            g->cells[j * g->w + i] += L_OCC;
    }
    free(xs); free(ys);
}

/* 从 (gx,gy) 沿环形半径扩散, 找最近 log-odds 低于 TH_FREE 的"自由"格。
 * 找到返回 1 并写回 *fx,*fy, 否则返回 0。*/
int nearest_free(const GridMap *g, int gx, int gy, int *fx, int *fy, int max_r)
{
    for (int r = 1; r <= max_r; r++) {
        for (int dy = -r; dy <= r; dy++) {
            for (int dx = -r; dx <= r; dx++) {
                if (abs(dx) != r && abs(dy) != r) continue;  /* 只扫正方形边 */
                int i = gx + dx, j = gy + dy;
                if (i < 0 || i >= g->w || j < 0 || j >= g->h) continue;
                if (g->cells[j * g->w + i] < TH_FREE) { *fx = i; *fy = j; return 1; }
            }
        }
    }
    return 0;
}

int main(void)
{
    /* 30x30 栅格, 分辨率 0.05 m/格, 机器人初始在栅格中心 (15,15) */
    GridMap *g = grid_new(30, 30, 0.05, -0.75, -0.75);

    /* 模拟 8 条激光射线从中心向各方向扫 0.5 m, 形成一个"环形墙" */
    const double angles[8] = {0, M_PI/4, M_PI/2, 3*M_PI/4, M_PI,
                              5*M_PI/4, 3*M_PI/2, 7*M_PI/4};
    for (int k = 0; k < 8; k++)
        ray_update(g, 15, 15, angles[k], 0.5);

    /* 中心被 8 条射线当"中间格"扫过, log-odds 显著为负 (自由) */
    printf("中心格 (15,15)  log-odds = %6.2f\n", g->cells[15 * g->w + 15]);
    /* 正 x 方向端点命中格 (25,15), log-odds 为正 (占据) */
    printf("命中格 (25,15)  log-odds = %6.2f\n", g->cells[15 * g->w + 25]);

    int fx, fy;
    if (nearest_free(g, 15, 15, &fx, &fy, 10))
        printf("最近自由格: (%d, %d)  log-odds = %6.2f\n",
               fx, fy, g->cells[fy * g->w + fx]);
    else
        printf("未找到自由格\n");

    grid_free(g);
    return 0;
}
```

两段代码均可直接编译运行：`blockA` 输出三段运动学/里程计结果，`blockB` 验证"扫描一次后中心为自由、环形墙为占据、最近自由格可被查出"的完整栅格建图闭环。

## 5. 教材/论文精读

**MLS 第 7 章（非完整行为）。** Murray/Li/Sastry 教材正文几乎不涉及轮式底盘，但第 7 章以"纯滚动不可滑移"的 Pfaffian 约束给出了差速机器人的数学基础：$$\omega(q)\dot{q}=0$$ 形式的速度约束何时可积、何时非完整，以及滚动圆盘模型（式 6.10-6.14）如何导出 $$\dot{x}=\rho\cos\theta\,\dot{\phi},\ \dot{y}=\rho\sin\theta\,\dot{\phi}$$ 这类"约束给出的一阶系统"。阅读本章能让你理解：第 12 章的路径规划为何对移动机器人更棘手——配置空间 3 维而瞬时运动只允许 2 个自由度，规划必须尊重约束。我们尤其推荐读者自己推导那个滚动圆盘例：它只有两个自由度却需要三个配置变量，运动约束把不可达方向"锁死"，却又保证任意位形都可以被到达——这一对看似矛盾的性质正是非完整系统的精髓。这是把本书"刚性运动"数学迁移到移动机器人的关键桥梁。

**Thrun, Burgard, Fox《Probabilistic Robotics》(2005)。** 移动机器人感知与状态估计的经典专著。核心思想是把一切估计问题统一为贝叶斯滤波：运动模型预测 + 传感器模型修正。书中的占用栅格建图（第 9 章）正是本章 log-odds 更新的完整版——它强调加性更新源于格子独立 + 测量独立的假设，并给出了从栅格概率恢复 log-odds 的工程推导；粒子滤波（第 8 章）则给出定位的通用解法。启示：不要把所有精度押在传感器本身，而是押在"不确定性如何被显式建模与融合"。局限：格子独立假设与计算代价使高分辨率栅格建图昂贵，这是后验依赖近似推断（如子图 + 回环检测）的原因。

**Fox, Burgard, Thrun《The Dynamic Window Approach to Collision Avoidance》(1997)。** 移动机器人局部避障的经典方法。其思想是在 (v, ω) 速度空间上取一个"动态窗口"（当前可达速度的子集），对窗口内每个候选速度评分：朝向得分（朝目标走得多好）、间隙得分（与最近障碍的距离）、速度得分（走得快不快），三者加权取最大。该方法计算量小、可实时运行，是 TurtleBot 上 `base_local_planner` 的理论鼻祖。启示：把"规划"分解为全局慢速规划 + 局部快速反应，是工程上务实的分层结构。

**Grisetti, Stachniss, Burgard《Improved Techniques for Grid Mapping With Rao-Blackwellized Particle Filters》(2007)。** 这是开源 gmapping 算法的出处，也是课程 Lab 6 建图的直接依据。核心是 Rao-Blackwellized 粒子滤波：每个粒子携带一条机器人轨迹假设，轨迹确定后建图变为条件独立、可解析更新；配合提议分布改进与自适应重采样，使粒子数需求大幅下降。启示：SLAM 的难点不在"公式"，而在"如何让估计保持一致性"——回环一旦出现，粒子退化与误差积累就会暴露。局限：无回环检测、对长廊退化，后继被图优化方法（Cartographer、ORB-SLAM）取代。

## 6. 实验/编程作业

对应 EECS C106A 第 7-8 周 Lab 4/6。实践建议：

- **Lab 4（差速运动学与里程计）**：先在本章 `blockA` 基础上加"里程计误差模型"，即给左右轮角速度叠加高斯噪声再积分，观察轨迹如何漂移；再把 `odometry_update` 换成真实编码器读数驱动，在 RViz 里用 tf 发布 `odom` 到 `base_link` 的变换，对比 Gazebo 真实位形与里程计位形，量化漂移量。
- **Lab 6（建图）**：用 `blockB` 的 `ray_update` 构建一个占位实现，把一帧激光扫描灌进栅格，观察 log-odds 累加效果；随后接真实驱动，跑 `gmapping` 或 `Cartographer` 在线建图，理解粒子滤波如何把带噪声的位形和激光同时写成一致地图。进阶：在代码里加"只更新机器人所在格周围 5 格范围"的裁剪，体会视场角与性能折衷。
- **调试技巧**：栅格坐标与世界坐标互转（`floor((x - ox)/res)`）是高频 bug 源，建议封装 `world_to_grid` / `grid_to_world` 两个函数并做单元测试；Bresenham 的 `err` 符号初始化最易写错，先用 (0,0) 到 (3,5) 的小样例手算核对再上真数据。此外 `L_FREE` 与 `L_OCC` 两个参数对应逆传感器模型的置信度，应针对雷达精度标定，避免单帧噪声把地图反复写成错误状态。

## 8. 小结

本章把移动机器人的问题拆成运动与感知两条线：差速轮式运动学（含非完整约束）给出机器人的运动能力，里程计用积分给出短时位形估计；占用栅格把激光扫描写成逐格 log-odds 加法，得到可查询的地图；贝叶斯滤波与粒子滤波把"定位 + 建图"统一为概率推断，构成 SLAM 的基础。三者环环相扣：运动模型喂给滤波器，滤波器校正里程计漂移，栅格地图又反过来约束粒子分布。理解这些之后，再去看第 14 章的学习与自适应控制，你会发现"不确定性"是移动机器人从教科书走向真实世界时必须永远带着的伴侣。
