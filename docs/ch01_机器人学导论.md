# 第 1 章 机器人学导论

> 课程来源：EECS C106A 第 1 周 ｜ 关键词：机器人历史、机器人分类、操作臂基础、现代机器人应用 ｜ 预计阅读时长：~40 分钟

## 1. 导论

这是全书的开篇背景章。第 2 章到第 4 章我们会扎进严格的数学（线性代数、SO(3)、SE(3)），第 5 章开始讲运动学、动力学与控制；在那之前，我们需要先回答三个更朴素的问题：**机器人是什么？机器人有哪些种类？机器人能干什么？** 本章正是为此而写——它不引入任何新算法，而是为整本书建立一套共同的词汇与心智模型。

很多初学者第一次翻开机器人学教材，直接撞上旋转矩阵、旋量和雅可比，立刻被劝退。一个常见误区是"数学是障碍，先把数学扫清再说"。经验恰恰相反：真正支撑机器人学的是**几何直觉**——一个机械臂的每个关节都对应一类约束运动，末端执行器的位置姿态由整条运动链（kinematic chain）叠加而成。本章先用最平实的语言把这些直觉讲清楚，让读者在进入第 2-4 章的抽象数学之前，已经"看得见"一台机器人在空间里如何运动。

与前后章的关系：前言（preface）说明了本书的来龙去脉与课程来源；本章则正式开启第 I 部分「刚体运动与数学基础」。第 2 章《线性代数与数学基础》将为我们提供描述机器人所需的第一件工具——向量、矩阵与线性变换；本章末尾我们只预告它们"为何需要"，具体内容留到后续章节。

## 2. 关键概念与记号

**机器人 (robot)**。这个词来自 1921 年捷克剧作家卡雷尔·恰佩克（Karel Čapek）的戏剧《罗梭的万能机器人》（R.U.R.）。捷克语 "robota" 本义是"苦役、强制劳动"。剧中的机器人被描绘成不知疲倦地工作、最终却反过来消灭人类的机器。可见"机器人"一词从诞生起就同时携带了"劳动力替代"与"失控恐惧"两种文化基因——直到今天，公众对机器人的想象仍受这两条线索支配。

学术上，我们采用更工程化的定义：**机器人是一台可编程的机电装置，能够通过感知、计算与执行三个环节，在真实物理世界中完成运动任务**。三个关键词缺一不可：**可编程**（区别于专用机床）、**感知-计算-执行闭环**（区别于纯粹的开环机构）、**真实物理世界**（区别于软件代理）。这一定义覆盖了工业机械臂、仓储搬运车、无人机、手术机器人与仿人机器人。

**操作臂 (manipulator)**。最常见的机器人形态：一条由**连杆 (link)** 通过**关节 (joint)** 串联而成的开放运动链（open kinematic chain），一端固定（基座），一端装**末端执行器 (end effector)** 抓取或加工物体。每个关节由一个**执行器 (actuator)** 驱动。几乎所有工业机器人都属于这一类。

**关节类型**。连接连杆的机构被称为**低副 (lower pair)**，共六类，恰好对应特殊欧氏群 SE(3) 的子群：转动（revolute）、移动（prismatic）、螺旋（helical）、圆柱（cylindrical）、球（spherical）与平面（planar）。其中转动与移动关节占了绝大多数，分别由一个角度变量和一个位移变量描述；球关节可视为三个轴线交于一点的转动关节复合，常用于机器人的"手腕"。这一点是理解第 5 章运动学的基础——因为每条运动链的正运动学，本质上就是把各关节子群的作用逐一复合。

**自由度 (degree of freedom, DOF)**。系统独立运动变量的个数。一台自由刚体在三维空间中恰有 6 个自由度（3 个平移 + 3 个旋转）；对一条由 $$n$$ 个关节串联而成的开放链，自由度就等于关节数（每个关节恰好提供一个变量）。对更一般的闭链机构，需要用到后面提到的格吕布勒公式。

**配置空间 (configuration space, C-space)**。所有可能的关节变量取值构成的集合。例如一台 6 自由度机械臂，其配置空间是 6 维的"关节角空间"。第 12 章的运动规划正是在这个空间里找路径，所以这个记号贯穿全书。

**坐标系**。为了描述运动，我们需要给空间"上刻度"：固定在机器人基座上的**基坐标系 (base frame)**，以及固定在末端执行器上的**工具坐标系 (tool frame)**。机器人学的大部分数学，都是在回答同一个问题：给定各关节变量，工具坐标系相对基坐标系到底在哪里？这将在第 3-5 章用旋转矩阵、齐次变换与乘积指数公式严格回答。

**机器人的分类**。按形态与运动方式，大致分三大类：

1. **固定基座操作臂 (manipulator / robotic arm)**。按关节布置又细分为：**关节型 (articulated)**（形似人臂，最通用，如 PUMA）、**SCARA**（Selective Compliant Assembly Robot Arm，水平柔顺、用于装配）、**直角坐标/龙门型 (Cartesian/gantry)**、**圆柱型 (cylindrical)**、**球坐标型 (spherical)**，以及**并联机构 (parallel)**（如 Delta、Stewart 平台，刚性好、速度快）。
2. **移动机器人 (mobile robot)**。包括**轮式**（差速、全向、阿克曼转向）、**腿式**（双足、四足、六足）、**空中**（无人机/UAV）、**水下**（ROV/AUV）。移动机器人通常与操作臂结合成"移动操作臂"。
3. **仿人机器人 (humanoid)**。外形与运动方式模仿人类，双足行走、双臂操作、全身协调控制，是机器人学"圣杯"级的综合问题。

另外还有软体机器人、手术机器人、群体机器人等交叉形态。本书主线聚焦固定基座操作臂，第 13-14 章扩展到移动机器人与环境感知、前沿方向。

**现代机器人应用**。工业制造（焊接、喷涂、装配、搬运、贴片）、医疗（手术、康复、假肢）、物流仓储（自主移动机器人 AMR）、农业（采摘、植保）、勘探（核、深海、地下、太空）、交通（自动驾驶）、服务（清洁、配送、教育）、救灾与危险环境作业。一句话概括：**凡是"脏、累、险、繁"的重复性运动任务，都可能是机器人的用武之地。**

## 3. 算法与公式

本章是背景章，公式不多，但以下几个将作为全书的"路标"，建议先记住它们的模样。

**自由度数公式**。对开放运动链操作臂，设转动关节数 $$p$$、移动关节数 $$r$$，则总自由度为：

$$n = p + r$$

对一般闭链机构（含并联），用**格吕布勒公式 (Grübler formula)** 估算自由度。设 $$N$$ 为连杆总数（含机架），$$J$$ 为关节总数，第 $$i$$ 个关节提供 $$f_i$$ 个自由度，则：

$$\text{dof} = 6(N - 1) - \sum_{i=1}^{J}(6 - f_i)$$

直觉：把 $$N-1$$ 个活动连杆的 $$6(N-1)$$ 个自由度全放开，再逐个扣除关节引入的约束 $$(6 - f_i)$$。

**配置空间**。含 $$p$$ 个转动关节、$$r$$ 个移动关节的机械臂，其配置空间是环面与实数空间的乘积：

$$Q = T^p \times \mathbb{R}^r$$

其中 $$T^p = \underbrace{S^1 \times \cdots \times S^1}_{p \text{ 个}}$$ 是 $$p$$ 维环面——每个转动关节的角度取值为一个圆周 $$S^1$$。这是第 5 章正运动学的出发点。

**刚性运动的数学预告**。机械臂末端（工具坐标系）相对基座的位置姿态，是三维刚性运动群 SE(3) 中的一个元素，可写作齐次变换矩阵：

$$T = \begin{bmatrix} R & p \\ 0 & 1 \end{bmatrix} \in SE(3), \quad R \in SO(3),\; p \in \mathbb{R}^3$$

其中 $$R$$ 是旋转矩阵（第 3 章），$$p$$ 是平移向量。整本书的数学主线——旋量理论（screw theory）与乘积指数公式（PoE）——就是把这个 $$T$$ 用关节变量的指数映射显式算出来（第 4-5 章）。现在看不懂完全正常，第 2-4 章会逐层拆解。

## 4. C 语言实现

写机器人算法的第一步，往往是把"机器人模型"用数据结构表达出来。下面这段代码示范如何用 C 语言为一台串联操作臂建立**参数表（DH 参数表）**。它不求解运动学，只负责把"这台机器人长什么样"变成机器可读、可打印、可复用的形式——这是所有后续 FK、IK、动力学、控制代码的地基。第 5 章会在同样的数据结构上真正算出末端位姿。

```c
/* ch01_robot_table.c
 * 机器人参数表：用 C 语言表达一台串联操作臂的模型
 *
 * 编译: gcc -std=c11 -Wall -Wextra -o robot_table robot_table.c -lm
 *
 * 说明：经典 DH 参数 (glossary: DH 参数) 用四个量描述相邻连杆间的变换——
 *   theta —— 绕前一坐标系 z 轴的旋转角（转动关节的变量）
 *   d     —— 沿前一坐标系 z 轴的平移  （移动关节的变量）
 *   a     —— 沿 x 轴的连杆长度
 *   alpha —— 绕 x 轴的连杆扭转角
 * 一台 n 关节的开放运动链（open chain）就是一张 n 行的参数表。
 */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI                      /* -std=c11 下 glibc 不自动提供 M_PI */
#define M_PI 3.14159265358979323846
#endif

/* 关节类型：转动 (revolute) / 移动 (prismatic) */
enum JointType { REVOLUTE, PRISMATIC };

/* 单个关节：类型 + DH 参数（theta/d 中恰好一个是运动变量，另一个是常量） */
struct Joint {
    enum JointType type;
    double theta;    /* 弧度 */
    double d;        /* 米   */
    double a;        /* 米   */
    double alpha;    /* 弧度 */
};

/* 串联操作臂：连杆 + 关节组成开放运动链 */
struct RobotArm {
    int n_joints;           /* 关节数 = 自由度数 */
    struct Joint *joints;   /* 动态数组，长度 n_joints */
    char name[64];
};

/* 打印整台操作臂的参数表 */
void robot_print(const struct RobotArm *arm)
{
    printf("机器人: %s  | 关节数: %d  | DOF: %d\n",
           arm->name, arm->n_joints, arm->n_joints);
    printf("序号  类型   theta(rad)     d(m)     a(m)   alpha(rad)\n");
    for (int i = 0; i < arm->n_joints; ++i) {
        const struct Joint *j = &arm->joints[i];
        printf("%2d    %s   %10.4f  %7.4f  %7.4f  %10.4f\n",
               i + 1,
               j->type == REVOLUTE ? "R" : "P",
               j->theta, j->d, j->a, j->alpha);
    }
}

/* 计数移动关节个数 */
int count_prismatic(const struct RobotArm *arm)
{
    int n = 0;
    for (int i = 0; i < arm->n_joints; ++i)
        if (arm->joints[i].type == PRISMATIC)
            ++n;
    return n;
}

/* 判断末 3 个关节是否构成"球形手腕"：
 * 三个转动关节，且其 a 参数接近 0（轴线近似交于一点）。
 * 球形手腕使得第 6 章的解析逆运动学可解，是重要的结构性质。 */
int is_spherical_wrist(const struct RobotArm *arm)
{
    if (arm->n_joints < 3)
        return 0;
    const struct Joint *x = &arm->joints[arm->n_joints - 3];
    const struct Joint *y = &arm->joints[arm->n_joints - 2];
    const struct Joint *z = &arm->joints[arm->n_joints - 1];
    return x->type == REVOLUTE && y->type == REVOLUTE && z->type == REVOLUTE
        && fabs(x->a) < 1e-9 && fabs(y->a) < 1e-9;
}

int main(void)
{
    const double rad = M_PI / 180.0;      /* 角度转弧度 */

    /* 构造一台 6 自由度关节型（articulated）操作臂，
     * 几何排布类似经典 PUMA，数值仅为教学示意。 */
    struct RobotArm arm = {
        .n_joints = 6,
        .name = "示例六自由度关节型臂"
    };
    arm.joints = malloc((size_t)arm.n_joints * sizeof(struct Joint));
    if (!arm.joints) {
        fprintf(stderr, "内存分配失败\n");
        return 1;
    }

    arm.joints[0] = (struct Joint){ REVOLUTE, 0.0,        0.325, 0.0,   -90.0 * rad };
    arm.joints[1] = (struct Joint){ REVOLUTE, -90.0 * rad, 0.0,  0.400,   0.0       };
    arm.joints[2] = (struct Joint){ REVOLUTE, 0.0,        0.0,   0.0,    90.0 * rad };
    arm.joints[3] = (struct Joint){ REVOLUTE, 0.0,        0.350, 0.0,   -90.0 * rad };
    arm.joints[4] = (struct Joint){ REVOLUTE, 0.0,        0.0,   0.0,    90.0 * rad };
    arm.joints[5] = (struct Joint){ REVOLUTE, 0.0,        0.065, 0.0,    0.0       };

    robot_print(&arm);
    printf("移动关节数: %d\n", count_prismatic(&arm));
    printf("是否球形手腕: %s\n", is_spherical_wrist(&arm) ? "是" : "否");

    free(arm.joints);
    return 0;
}
```

关键设计点：(1) 用 `enum` 区分转动/移动关节，避免魔法数；(2) 用 `struct` 把"类型 + 参数"聚合成一个整体，与物理上"一个关节一个结构体"一一对应；(3) 关节数组用 `malloc`/`free` 动态管理，可自由构造任意关节数的机械臂（比如加一段改成 7 自由度冗余臂）；(4) `is_spherical_wrist` 示范了**从结构数据判断机构性质**——这正是后面解析逆运动学与奇异分析的前奏。整段代码只用标准库，不依赖任何外部线性代数库，符合本书"手写一切"的原则。

## 5. 教材/论文精读

本教材以 Murray/Li/Sastry《A Mathematical Introduction to Robotic Manipulation》(MLS) 为官方教材。此处精读 MLS 第 1 章开头的前三段（Introduction 段落 1-3），它们虽无公式，却奠定了全书的立场。

**段落 1**：开篇即点明，过去二十年里人们对机器人的观念"从科幻电影走向现实"——机械臂如今在流水线上焊接、喷涂汽车车身，往印刷电路板插元件，在核、深海与地下环境检修结构，甚至在农业中摘橙子收葡萄。作者紧接着给出全书最重要的方法论忠告：**我们对机器人进展的急躁，很大程度源于低估了自身生物运动控制系统的强大与精妙**。这段话值得反复读：它暗示了机器人学的真正瓶颈从来不只是机械与电机，而是"控制"——而控制需要数学。这正是本书把重头戏放在刚性运动数学、动力学与控制上的原因。任何试图绕过数学直接"调参跑通"的学习者，最终都会回到这段话面前。

**段落 2**：追溯 "robot" 一词的来源——1921 年恰佩克的戏剧 R.U.R.，剧中机器人被描绘成与人相似、不知疲倦、最终反噬人类的机器。作者指出，科幻塑造了公众对机器人的预期（像人、有智能、甚至有性格），因此今天的真实机器人"显得原始"。这段给我们一个清醒的视角：**评价机器人学进展，标准应当是"能在物理世界中完成多少实际任务"，而不是"多像人"**。这也解释了为什么本书主线是操作臂（它们普遍非人形、却真正在产线上干活）。

**段落 3**：进入工程史。二战后的 Argonne 与 Oak Ridge 国家实验室为处理放射性物质研制主从式（master-slave）遥控机械手，这是遥操作（teleoperation）的起点；与之并行的是数控机床（CNC）的发展。1954 年 George Devol 提出"可编程的关节式搬运装置"，Joseph Engelberger 买下专利并于 1956 年创立 Unimation，1961 年第一台机器人在通用汽车工厂上岗。MLS 特别强调 Unimation 臂的创新在于**开放运动链**结构：悬臂梁式的多自由度设计让机械臂能触及比自身占地大得多的工作空间，但也带来控制难题——链底的误差会沿链逐级放大，且悬臂刚度难以保证。这段话是理解全书结构的一把钥匙：**"开放链 + 大工作空间"的工程取舍，正是第 5 章运动学、第 9 章雅可比与第 10-11 章动力学/控制要处理的全部核心问题的来源。**

## 6. 实验/编程作业

EECS C106A 第 1 周对应 ROS 与仿真环境的入门，建议按以下顺序实践：

1. **跑通本章 C 代码**：亲手编译运行 `robot_table.c`，改几行参数（比如把某关节改成 `PRISMATIC`），观察打印结果与球形手腕判断的变化。体会"参数表"如何忠实编码一台真实机械臂。
2. **读一台真实机器人的参数表**：在 ROS 中加载经典机械臂的 URDF（如 PUMA 560、KUKA 或 Panda），把 `<joint>` 标签的 `type` 与 `<origin>` 对应到本章 `struct Joint` 的字段，写出一张 DH 参数表。对照第 5 章内容建立"URDF 也是参数表的一种编码"的直觉。
3. **用 RViz 手动拖动关节**：在 RViz 中逐个转动关节滑块，观察末端执行器（工具坐标系）如何随链运动。把"关节角 → 末端位姿"的直觉与"配置空间 $$Q$$"的概念对应起来。
4. **加分题**：把 `struct RobotArm` 扩展为 7 自由度冗余臂，并给每个关节加一个角度限位数组（`theta_min`/`theta_max`），打印时同时输出限位。这是第 12 章运动规划预处理的标准数据形状。

## 8. 小结

本章建立了全书的三块地基：**词汇**（机器人、操作臂、关节、连杆、末端执行器、自由度、配置空间）、**分类**（操作臂/移动/仿人）与**应用版图**（制造、医疗、物流、勘探、服务）。我们预告了三条贯穿全书的公式路标：自由度公式、配置空间 $$Q = T^p \times \mathbb{R}^r$$ 与末端位姿 $$T \in SE(3)$$。MLS 第 1 章的三段引言提醒我们：机器人学的本质是"对强大生物运动控制系统的数学化复刻"，而开放运动链既是操作臂的力量源泉，也是其控制难题的根源。从下一章开始，我们将正式拿起第一件数学工具——线性代数。
