# 第 8 章 视觉对应与双视图几何

> 课程来源：EECS C106A 第 6-7 周 ｜ 关键词：特征匹配、对极几何、基础矩阵、本质矩阵、RANSAC、三角化 ｜ 预计阅读时长：~40 分钟

## 1. 导论

上一章建立了单幅图像的表象：针孔相机模型把三维世界投影到二维像素平面，Harris 角点与描述子把图像压缩成一批特征点。但单幅图像缺少尺度信息——一个点到底离相机 1 米还是 10 米，仅凭一张图无法回答。机器人要导航、抓取、避障，必须从图像里恢复**三维信息**，而恢复 3D 的第一步，是同时看两幅图像：立体视觉 (stereo vision)。本章解决"双视图"的三个连环问题：**对应**（两幅图里哪些点是同一个 3D 点的投影？）、**几何**（两幅图之间、两架相机之间的位置关系如何？）、**深度**（给定对应点，3D 点在哪？）。

对应与几何看似是两个问题，其实被一个优美的对象统一起来——**对极几何 (epipolar geometry)**。它告诉我们一个惊人的事实：即使完全不知道 3D 点在哪，两个相机之间的相对运动也会在图像平面上强制一个纯 2D 的约束：第一幅图中的点 $$x$$ 对应的点 $$x'$$ 一定落在一条由几何预先决定的直线上（对极线）。这条约束只依赖两架相机的相对位姿与内参，用一个 3 阶矩阵——**基础矩阵 (fundamental matrix)** $$F$$ 描述，写成

$$x'^T F x = 0$$

有了这个"免费"的约束，第一件事是**匹配过滤**：特征匹配产生的误匹配（野值）大多不满足对极约束，因此可以用 $$F$$ 把它们剔除；反过来，若先不知道 $$F$$，则用 **RANSAC** 在含野值的匹配中稳健地同时估计出 $$F$$ 与内点集。第二件事是**运动恢复**：从 $$F$$ 或归一化后的**本质矩阵 (essential matrix)** $$E$$ 分解出相机的旋转与平移，这正是视觉里程计、双目 SLAM 的骨架。第三件事是**三角化 (triangulation)**：给定两幅图像中的对应像素与相机投影矩阵，反求 3D 点的坐标。

本章与前后的关系清晰：第 7 章提供的特征点是本章的输入；本章输出的稀疏 3D 点云、相机位姿被第 13 章移动机器人的 SLAM 直接复用；而对极约束"运动可从纯 2D 对应恢复"的思想，与第 4 章 SE(3) 刚体变换、第 9 章雅可比的速度描述是同一套刚性运动语言在相机上的体现。读完本章，你应该能把"两张图 → 一组匹配 → 一台能估算自身运动的相机"这条流水线完整地走通。

## 2. 关键概念与记号

**齐次坐标。** 把 2D 像素点记为三维齐次向量 $$x = (u,\ v,\ 1)^T$$，实际像素坐标由前两维给出（第 3 维固定为 1）。两条平行线在齐次坐标下交于"无穷远点"，这是投影几何处理退化情形所必需的。本章约定第一幅图中的点写作 $$x$$，第二幅图中的对应点写作 $$x'$$。

**特征匹配 (feature matching)。** 用描述子（SIFT、SURF、ORB 等，见第 7 章）按最近邻在另一幅图中找候选对应。描述子距离越近越可能是同一个点。但仅仅最近邻会产生大量误匹配：图像中的重复纹理、自遮挡、视点差异都会制造"视觉上很像但不是同一个点"的假对应。Lowe 的距离比检验 (ratio test) 要求最近邻距离显著小于次近邻距离（通常阈值 0.75~0.8），能去掉相当一部分误匹配，但远不能保证纯净。**RANSAC 是处理剩余野值 (outliers) 的标准工具**，它不假定野值服从任何分布，只要求内点 (inliers) 一致地满足某个几何模型。

**对极几何的元素。** 设两架相机中心分别为 $$C$$ 与 $$C'$$，连线 $$CC'$$ 称为**基线 (baseline)**。三维点 $$X$$ 与两个相机中心确定一个平面——**对极平面 (epipolar plane)**，它裁剪两幅图像得到两条线：第一幅中的 $$l$$ 与第二幅中的 $$l'$$，统称**对极线 (epipolar line)**。关键几何事实：$$x$$ 对应的 $$x'$$ 必然落在 $$l'$$ 上，且 $$l'$$ 只由 $$X$$ 所在的射线（或对极平面）决定，不依赖 $$X$$ 在对极平面内的具体位置。基线穿出图像平面的点称为**极点 (epipole)** $$e, e'$$——它是另一个相机中心在本图像中的投影，所有对极线都汇于极点。对极几何概括为：

$$x'^T F x = 0,\qquad l' = F x,\qquad l = F^T x'$$

**基础矩阵 $$F$$。** 一个 $$3 	imes 3$$ 秩 2 矩阵（$$\det F = 0$$），联系两幅图像中对应对的像素齐次坐标。它编码了两相机的相对位姿与全部内参，自由度为 7（9 个元素，一个整体尺度，一个秩 2 约束）。若已知内参，把像素坐标"退回"到归一化相机坐标后，得到**本质矩阵** $$E = K'^T F K$$，它只编码相对运动：$$E = [t]_	imes R$$，自由度为 5（3 旋转 + 3 平移 − 1 尺度）。

**记号小结。** 像素坐标 $$\hat{x}$$、归一化坐标 $$ar{x} = K^{-1}\hat{x}$$；投影矩阵 $$P = K[R \mid t]$$；叉乘矩阵 $$[t]_	imes$$；3D 齐次点 $$X = (X, Y, Z, 1)^T$$。

## 3. 算法与公式

### 3.1 对极约束与对极线

对极约束的证明只需投影几何的一句话：$$x, x', X, C, C'$$ 共面（都在对极平面内），于是存在一个将 $$x$$ 映到 $$l'$$（即 $$x$$ 所在射线在对极平面内扫出的那条线）的映射，该映射是线性的，即 $$l' = F x$$。又因为 $$x'$$ 落在线 $$l'$$ 上，得到标量方程 $$x'^T l' = x'^T F x = 0$$。$$F$$ 的秩 2 来自所有对极线交于极点：存在非零 $$e$$ 使 $$F e = 0$$（也即 $$e$$ 在 $$F$$ 的零空间中），同理 $$e'^T F = 0$$。

**给一个真实匹配，对极约束是硬性的**：无论噪声如何，正确匹配一定（在噪声范围内）满足它。这是所有匹配过滤方法的核心依据。

### 3.2 八点算法 (Eight-Point Algorithm)

已知 $$n \geq 8$$ 组对应点 $$(x_i, x'_i)$$，要求满足 $$x'^T F x = 0$$ 的 $$F$$。把约束展开为关于 $$F$$ 九个元素的**双线性方程**：对点对 $$(x, y), (x', y')$$，有

$$x'x\,f_{11} + x'y\,f_{12} + x' f_{13} + y'x\,f_{21} + y'y\,f_{22} + y' f_{23} + x\,f_{31} + y\,f_{32} + f_{33} = 0$$

即一行 $$a_i = (x'x,\ x'y,\ x',\ y'x,\ y'y,\ y',\ x,\ y,\ 1)$$ 与未知向量 $$f = (f_{11}, \dots, f_{33})^T$$ 正交。把所有点对拼成 $$n 	imes 9$$ 矩阵 $$A$$，得到齐次线性系统

$$A f = 0$$

$$F$$ 有整体尺度自由度，故找单位向量最小化 $$\lVert A f Vert$$ 即可——这正是 $$A^T A$$ 最小特征值对应的特征向量（等价于 $$A$$ 最小奇异值的右奇异向量）。**这一步必须做归一化 (normalization)**：把两幅图的点各自平移到质心、缩放到平均距离 $$\sqrt{2}$$（即左乘相似变换 $$T, T'$$），在归一化坐标里求 $$	ilde{F}$$，再反归一化 $$F = T'^T 	ilde{F} T$$。Hartley (1997) 证明：不做归一化时八点法对噪声极敏感，误差可放大几个数量级，归一化后基本达到最优。最后施加**秩 2 约束**：对求得的 $$F$$ 做 SVD，把最小奇异值置零（投影到最接近的秩 2 矩阵），因为真实的基础矩阵必然奇异。这就是 4 节代码 (a) 实现的完整流程。

### 3.3 本质矩阵与运动恢复

已知内参 $$K, K'$$ 时，从 $$F$$ 得到 $$E = K'^T F K$$，满足 $$E = [t]_	imes R$$。$$E$$ 的奇异值必为 $$(\sigma, \sigma, 0)$$（两两相等且一个为零）。从 $$E$$ 恢复 $$R, t$$ 是经典问题：对 $$E = U \operatorname{diag}(\sigma, \sigma, 0) V^T$$，令

$$R_1 = U W V^T,\quad R_2 = U W^T V^T,\quad [t]_	imes = U Z U^T,\quad W = egin{pmatrix} 0 & -1 & 0 \ 1 & 0 & 0 \ 0 & 0 & 1 nd{pmatrix}$$

平移方向取 $$U$$ 的第三列，于是得到 4 组候选解 $$(R_1, t), (R_2, t), (R_1, -t), (R_2, -t)$$。其中只有一组满足"3D 点同时在两架相机前方"（三角化后 $$Z > 0$$，正深度约束）。实际实现里通常对 $$E$$ 施加奇异值约束（把奇异值修正为 $$(\sigma_1 + \sigma_2)/2$$ 后再分解），以补偿噪声带来的奇异值漂移。

### 3.4 RANSAC 稳健估计

RANSAC (Fischler & Bolles 1981) 的哲学：模型只需最小样本量（基础矩阵取 8 点）随机拟合，再统计有多少点与该模型一致。流程：迭代若干次，每次随机取 8 个不重复下标估计 $$F$$，对每个匹配计算到模型的"距离"，距离小于阈值的记为内点；保留内点数最多的模型，最后用全部内点重新拟合。点的"到模型距离"用一阶近似的 **Sampson 距离**，它同时度量了两个点的偏移且可微：

$$d(x, x') = rac{(x'^T F x)^2}{(F x)_1^2 + (F x)_2^2 + (F^T x')_1^2 + (F^T x')_2^2}$$

分子的零点正是对极约束；分母是约束函数关于两点的梯度的范数平方，把"代数残差"折算成像素距离。迭代次数 $$N$$ 由期望置信度 $$p$$ 与内点比例 $$w$$ 决定：单次采样全为内点的概率是 $$w^8$$，故

$$N = rac{\log(1 - p)}{\log(1 - w^8)}$$

例如 $$w = 0.5$$、$$p = 0.99$$ 时 $$N pprox 1177$$ 次。RANSAC 对野值比例高（甚至过半）的情形依然健壮，这是它成为几何估计事实标准的原因。

### 3.5 三角化 (Triangulation)

已知两相机投影矩阵 $$P, P'$$ 与对应像素 $$x, x'$$，求满足 $$x = P X,\ x' = P' X$$ 的 3D 齐次点 $$X$$。把每个像素约束写成叉积为零：$$[x]_	imes P X = 0$$（齐次向量与其叉积处处正交），对两个点共给出 4 个独立线性方程（实际上每幅图 2 个），拼成 $$4 	imes 4$$ 线性系统 $$A X = 0$$，同样用最小奇异值/最小特征值求解，再按齐次坐标归一化（除以第 4 维）。这是线性三角化 (DLT)。**注意**：三角化的精度对噪声和相机位姿敏感——基线太短、或 3D 点在相机主轴方向（两射线近似平行但相交角很小）时，深度不确定性急剧放大。更精细的做法是最小化重投影误差的非线性优化（最小化 $$\sum_i d(x_i, P_i X)^2$$），即光束法平差 (bundle adjustment) 的最简形式。

## 4. C 语言实现

本节给出两段完整、可独立编译的 C11 程序。第一段 (a) 用**归一化八点法**估计基础矩阵：构造 $$A$$ 矩阵 → 最小二乘解 → SVD 秩 2 修正，用合成双视图验证对极约束残差接近机器精度；第二段 (b) 用 **RANSAC** 在含野值、含噪声的匹配中稳健恢复 $$F$$，并演示对极线方程 $$l' = F x$$。两段都手写了对称矩阵 Jacobi 特征分解（8 点法用 $$9 	imes 9$$ 的 $$A^T A$$，秩 2 修正用 $$3 	imes 3$$ 的 $$F^T F$$），不依赖任何外部线性代数库。

### 4.1 八点法估计基础矩阵

```c
/*
 * 示例 (a): 基础矩阵 8 点法 (Eight-Point Algorithm)
 * 编译运行:  gcc -std=c11 -Wall -Wextra -o f8 f8pt.c -lm && ./f8
 *
 * 核心公式 (Hartley & Zisserman, Multiple View Geometry, ch.11):
 *   对极约束     x2^T F x1 = 0
 *   八点构造     A f = 0,  f = vec(F) (9 维), A 的第 i 行为
 *                [x2x1, x2y1, x2, y2x1, y2y1, y2, x1, y1, 1]
 *   最小二乘解   f = argmin ||A f||, 取 A^T A 最小特征值对应特征向量
 *   秩 2 约束    SVD(F) 后把最小奇异值置零再重建
 */
#include <stdio.h>
#include <math.h>

/* 3x3 矩阵 (带 struct 标签, 这样 struct Mat3 与 Mat3 是同一类型) */
typedef struct Mat3 { double m[3][3]; } Mat3;

/* 矩阵乘法 C = A * B (3x3) */
static void mat_mul3(const Mat3 *A, const Mat3 *B, Mat3 *C)
{
    Mat3 t;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) {
            t.m[i][j] = 0.0;
            for (int k = 0; k < 3; k++)
                t.m[i][j] += A->m[i][k] * B->m[k][j];
        }
    *C = t;
}

/* 对称矩阵 Jacobi 特征分解 (行主序, 显式 leading dimension ld):
 * 输入 A (n x n 对称, 就地修改), 输出特征值 w(升序) 与特征向量 V(列向量)
 * 同一函数同时处理 9x9 (A^T A) 与 3x3 (F^T F), 只是 ld 不同 */
static void jacobi_eigen(double *A, int n, int ld, double *w, double *V)
{
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            V[i * ld + j] = (i == j) ? 1.0 : 0.0;

    for (int sweep = 0; sweep < 80; sweep++) {
        double off = 0.0;                       /* 非对角元平方和 */
        for (int p = 0; p < n; p++)
            for (int q = p + 1; q < n; q++)
                off += A[p * ld + q] * A[p * ld + q];
        if (off < 1e-24) break;                 /* 已对角化 */
        for (int p = 0; p < n; p++) {
            for (int q = p + 1; q < n; q++) {
                if (fabs(A[p * ld + q]) < 1e-300) continue;
                /* 平面旋转角: 消去 A[p][q] */
                double theta = 0.5 * atan2(2.0 * A[p * ld + q],
                                           A[q * ld + q] - A[p * ld + p]);
                double c = cos(theta), s = sin(theta);
                for (int i = 0; i < n; i++) {   /* A = J^T A */
                    double aip = A[i * ld + p], aiq = A[i * ld + q];
                    A[i * ld + p] = c * aip - s * aiq;
                    A[i * ld + q] = s * aip + c * aiq;
                }
                for (int j = 0; j < n; j++) {   /* A = A J */
                    double apj = A[p * ld + j], aqj = A[q * ld + j];
                    A[p * ld + j] = c * apj - s * aqj;
                    A[q * ld + j] = s * apj + c * aqj;
                }
                for (int i = 0; i < n; i++) {   /* V = V J */
                    double vip = V[i * ld + p], viq = V[i * ld + q];
                    V[i * ld + p] = c * vip - s * viq;
                    V[i * ld + q] = s * vip + c * viq;
                }
            }
        }
    }
    for (int i = 0; i < n; i++) w[i] = A[i * ld + i];
    for (int i = 0; i < n; i++)                 /* 特征值升序 + 同步换列 */
        for (int j = i + 1; j < n; j++)
            if (w[j] < w[i]) {
                double t = w[i]; w[i] = w[j]; w[j] = t;
                for (int k = 0; k < n; k++) {
                    t = V[k * ld + i]; V[k * ld + i] = V[k * ld + j];
                    V[k * ld + j] = t;
                }
            }
}

/* 求线性系统 A f = 0 的最小二乘解: f = A^T A 最小特征值对应特征向量 */
static void null_vector(double *A, int rows, int cols, double *f)
{
    double B[9][9] = {{0}};                     /* B = A^T A (cols x cols) */
    for (int i = 0; i < cols; i++)
        for (int j = 0; j < cols; j++)
            for (int k = 0; k < rows; k++)
                B[i][j] += A[k * cols + i] * A[k * cols + j];
    double w[9], V[9][9];
    jacobi_eigen(&B[0][0], cols, cols, w, &V[0][0]);   /* w[0] 最小 */
    for (int i = 0; i < cols; i++) f[i] = V[i][0];
}

/* 通用线性估计 F: 输入 n 组对应点, 最小化 sum (x2^T F x1)^2 并施加秩 2 约束 */
static void fundamental_linear(const double pts1[][2], const double pts2[][2],
                               int n, Mat3 *F)
{
    /* 1. 平移归一化: 质心移到原点, 平均到原点距离 = sqrt(2) (Hartley 1997) */
    double cx1 = 0, cy1 = 0, cx2 = 0, cy2 = 0;
    for (int i = 0; i < n; i++) {
        cx1 += pts1[i][0]; cy1 += pts1[i][1];
        cx2 += pts2[i][0]; cy2 += pts2[i][1];
    }
    cx1 /= n; cy1 /= n; cx2 /= n; cy2 /= n;
    double s1 = 0, s2 = 0;
    for (int i = 0; i < n; i++) {
        s1 += sqrt(pow(pts1[i][0] - cx1, 2) + pow(pts1[i][1] - cy1, 2));
        s2 += sqrt(pow(pts2[i][0] - cx2, 2) + pow(pts2[i][1] - cy2, 2));
    }
    s1 = sqrt(2.0) * n / s1;
    s2 = sqrt(2.0) * n / s2;

    /* 2. 构造 A (n x 9): 每行是点对的双线性形, 展开 x2^T F x1 */
    double A[8][9];
    for (int i = 0; i < n; i++) {
        double x1 = s1 * (pts1[i][0] - cx1), y1 = s1 * (pts1[i][1] - cy1);
        double x2 = s2 * (pts2[i][0] - cx2), y2 = s2 * (pts2[i][1] - cy2);
        A[i][0] = x2 * x1;  A[i][1] = x2 * y1;  A[i][2] = x2;
        A[i][3] = y2 * x1;  A[i][4] = y2 * y1;  A[i][5] = y2;
        A[i][6] = x1;       A[i][7] = y1;       A[i][8] = 1.0;
    }

    /* 3. 最小二乘解 f = (f1..f9), 重塑为 3x3 (行优先) */
    double f[9];
    null_vector(&A[0][0], n, 9, f);
    Mat3 Fn = {{ {f[0], f[1], f[2]},
                 {f[3], f[4], f[5]},
                 {f[6], f[7], f[8]} }};

    /* 4. 反归一化: F = T2^T Fn T1, 其中 Ti = diag(s,s,1) [1 0 -c; 0 1 -c; 0 0 1] */
    Mat3 T1 = {{{s1, 0, -s1 * cx1}, {0, s1, -s1 * cy1}, {0, 0, 1}}};
    Mat3 T2 = {{{s2, 0, -s2 * cx2}, {0, s2, -s2 * cy2}, {0, 0, 1}}};
    Mat3 T2t = {{ {T2.m[0][0], T2.m[1][0], T2.m[2][0]},
                  {T2.m[0][1], T2.m[1][1], T2.m[2][1]},
                  {T2.m[0][2], T2.m[1][2], T2.m[2][2]} }};
    Mat3 FnT1, Fden;
    mat_mul3(&Fn, &T1, &FnT1);
    mat_mul3(&T2t, &FnT1, &Fden);               /* F = T2^T (Fn T1) */

    /* 5. 秩 2 约束: 对 F 做 SVD (用 F^T F 的特征分解), 最小奇异值置零 */
    Mat3 Ft = {{ {Fden.m[0][0], Fden.m[1][0], Fden.m[2][0]},
                 {Fden.m[0][1], Fden.m[1][1], Fden.m[2][1]},
                 {Fden.m[0][2], Fden.m[1][2], Fden.m[2][2]} }};
    Mat3 S;
    mat_mul3(&Ft, &Fden, &S);                   /* S = F^T F, 对称 */
    double lam[3], V[3][3];
    jacobi_eigen(&S.m[0][0], 3, 3, lam, &V[0][0]);  /* 升序: lam[0] 对应最小奇异值 */
    /* D = diag(0,1,1): 抹掉最小奇异值对应的方向, F' = F V D V^T */
    double VDV[3][3] = {{0}};
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            for (int k = 0; k < 3; k++)
                VDV[i][j] += V[i][k] * ((k == 0) ? 0.0 : 1.0) * V[j][k];
    Mat3 VDVm = {{{VDV[0][0], VDV[0][1], VDV[0][2]},
                  {VDV[1][0], VDV[1][1], VDV[1][2]},
                  {VDV[2][0], VDV[2][1], VDV[2][2]}}};
    mat_mul3(&Fden, &VDVm, F);
    /* 尺度归一化: 固定 F[2][2] = 1 消除整体缩放自由度 */
    double nrm = F->m[2][2];
    if (fabs(nrm) > 1e-12)
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++)
                F->m[i][j] /= nrm;
}

/* 八点法: 接口固定为 8 组对应点 */
void fundamental_matrix_8pt(const double pts1[8][2], const double pts2[8][2],
                            struct Mat3 *F)
{
    fundamental_linear(pts1, pts2, 8, F);
}

/* Sampson 距离: d = (x2^T F x1)^2 / ((Fx1)_1^2+(Fx1)_2^2+(F^T x2)_1^2+(F^T x2)_2^2) */
static double sampson(const double x1[2], const double x2[2], const Mat3 *F)
{
    double X1[3] = {x1[0], x1[1], 1.0};
    double X2[3] = {x2[0], x2[1], 1.0};
    double Fx[3], FTx[3];
    for (int i = 0; i < 3; i++) {
        Fx[i]  = F->m[i][0]*X1[0] + F->m[i][1]*X1[1] + F->m[i][2]*X1[2];
        FTx[i] = F->m[0][i]*X2[0] + F->m[1][i]*X2[1] + F->m[2][i]*X2[2];
    }
    double num = X2[0]*Fx[0] + X2[1]*Fx[1] + X2[2]*Fx[2];
    double den = Fx[0]*Fx[0] + Fx[1]*Fx[1] + FTx[0]*FTx[0] + FTx[1]*FTx[1];
    return num * num / (den + 1e-12);
}

/* 简单线性同余随机数发生器 (固定种子, 可复现) */
static unsigned int rng_state = 20260717u;
static double rnd01(void)
{
    rng_state = rng_state * 1664525u + 1013904223u;
    return (double)(rng_state >> 8) / 16777216.0;   /* 0~1 */
}

int main(void)
{
    /* 合成双视图: 相机1 = K[I|0], 相机2 = K[R|t], 8 个散布 3D 点
       注意点集要"充分非退化"(不共面、深度差异明显), 否则 8 点法病态 */
    double K[3][3] = {{500, 0, 320}, {0, 500, 240}, {0, 0, 1}};
    double th = 0.25, c = cos(th), s = sin(th);
    double R[3][3] = {{c, 0, s}, {0, 1, 0}, {-s, 0, c}};   /* 绕 y 轴转 0.25 rad */
    double t[3] = {-1.0, 0.15, 0.3};

    double pts1[8][2], pts2[8][2];
    for (int i = 0; i < 8; i++) {               /* 空间立方体 [ -2,2 ]^2 x [4,9] */
        double P[3] = {4.0 * rnd01() - 2.0,      /* x in [-2, 2]   */
                       4.0 * rnd01() - 2.0,      /* y in [-2, 2]   */
                       4.0 + 5.0 * rnd01()};     /* z in [4, 9]    */
        pts1[i][0] = K[0][0] * P[0] / P[2] + K[0][2];
        pts1[i][1] = K[1][1] * P[1] / P[2] + K[1][2];
        double X2[3] = {
            R[0][0]*P[0] + R[0][1]*P[1] + R[0][2]*P[2] + t[0],
            R[1][0]*P[0] + R[1][1]*P[1] + R[1][2]*P[2] + t[1],
            R[2][0]*P[0] + R[2][1]*P[1] + R[2][2]*P[2] + t[2]
        };
        pts2[i][0] = K[0][0]*X2[0]/X2[2] + K[0][2];
        pts2[i][1] = K[1][1]*X2[1]/X2[2] + K[1][2];
    }

    Mat3 F;
    fundamental_matrix_8pt(pts1, pts2, &F);

    printf("估计的基础矩阵 F (归一化到 F[2][2]=1):
");
    for (int i = 0; i < 3; i++)
        printf("  %12.4e %12.4e %12.4e
", F.m[i][0], F.m[i][1], F.m[i][2]);

    double maxr = 0.0;
    for (int i = 0; i < 8; i++) {
        double r = sampson(pts1[i], pts2[i], &F);
        if (r > maxr) maxr = r;
        printf("  点 %d: Sampson 距离 = %.3e px
", i, sqrt(r));
    }
    printf("最大 Sampson 距离: %.3e px (无噪声应接近机器精度)
", sqrt(maxr));
    return 0;
}
```

```c
/*
 * 示例 (b): RANSAC 匹配过滤 + 对极线演示
 * 编译运行:  gcc -std=c11 -Wall -Wextra -o rsa ransac.c -lm && ./rsa
 *
 * 对极几何 (Hartley & Zisserman, MVG ch.9/ch.11):
 *   对极线     l' = F x1,  对应点 x2 必落在 l' 上:  x2^T l' = 0
 *   Sampson    d(x1,x2) = (x2^T F x1)^2 / ((Fx1)_1^2+(Fx1)_2^2+(F^T x2)_1^2+(F^T x2)_2^2)
 *   RANSAC     随机采 8 点估 F -> 用 Sampson 距离筛内点 -> 保留内点最多者
 */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

typedef struct Mat3 { double m[3][3]; } Mat3;

/* ---------- 基础矩阵线性估计 (与示例 a 相同的辅助函数) ---------- */

static void mat_mul3(const Mat3 *A, const Mat3 *B, Mat3 *C)
{
    Mat3 t;
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++) {
            t.m[i][j] = 0.0;
            for (int k = 0; k < 3; k++)
                t.m[i][j] += A->m[i][k] * B->m[k][j];
        }
    *C = t;
}

static void jacobi_eigen(double *A, int n, int ld, double *w, double *V)
{
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            V[i * ld + j] = (i == j) ? 1.0 : 0.0;
    for (int sweep = 0; sweep < 80; sweep++) {
        double off = 0.0;
        for (int p = 0; p < n; p++)
            for (int q = p + 1; q < n; q++)
                off += A[p * ld + q] * A[p * ld + q];
        if (off < 1e-24) break;
        for (int p = 0; p < n; p++)
            for (int q = p + 1; q < n; q++) {
                if (fabs(A[p * ld + q]) < 1e-300) continue;
                double theta = 0.5 * atan2(2.0 * A[p * ld + q],
                                           A[q * ld + q] - A[p * ld + p]);
                double c = cos(theta), s = sin(theta);
                for (int i = 0; i < n; i++) {
                    double aip = A[i * ld + p], aiq = A[i * ld + q];
                    A[i * ld + p] = c * aip - s * aiq;
                    A[i * ld + q] = s * aip + c * aiq;
                }
                for (int j = 0; j < n; j++) {
                    double apj = A[p * ld + j], aqj = A[q * ld + j];
                    A[p * ld + j] = c * apj - s * aqj;
                    A[q * ld + j] = s * apj + c * aqj;
                }
                for (int i = 0; i < n; i++) {
                    double vip = V[i * ld + p], viq = V[i * ld + q];
                    V[i * ld + p] = c * vip - s * viq;
                    V[i * ld + q] = s * vip + c * viq;
                }
            }
    }
    for (int i = 0; i < n; i++) w[i] = A[i * ld + i];
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (w[j] < w[i]) {
                double t = w[i]; w[i] = w[j]; w[j] = t;
                for (int k = 0; k < n; k++) {
                    t = V[k * ld + i]; V[k * ld + i] = V[k * ld + j];
                    V[k * ld + j] = t;
                }
            }
}

static void null_vector(double *A, int rows, int cols, double *f)
{
    double B[9][9] = {{0}};
    for (int i = 0; i < cols; i++)
        for (int j = 0; j < cols; j++)
            for (int k = 0; k < rows; k++)
                B[i][j] += A[k * cols + i] * A[k * cols + j];
    double w[9], V[9][9];
    jacobi_eigen(&B[0][0], cols, cols, w, &V[0][0]);
    for (int i = 0; i < cols; i++) f[i] = V[i][0];
}

/* n 组对应点最小二乘估计 F (含归一化 + 秩 2 约束), n >= 8 */
static void fundamental_linear(const double pts1[][2], const double pts2[][2],
                               int n, Mat3 *F)
{
    double cx1 = 0, cy1 = 0, cx2 = 0, cy2 = 0;
    for (int i = 0; i < n; i++) {
        cx1 += pts1[i][0]; cy1 += pts1[i][1];
        cx2 += pts2[i][0]; cy2 += pts2[i][1];
    }
    cx1 /= n; cy1 /= n; cx2 /= n; cy2 /= n;
    double s1 = 0, s2 = 0;
    for (int i = 0; i < n; i++) {
        s1 += sqrt(pow(pts1[i][0] - cx1, 2) + pow(pts1[i][1] - cy1, 2));
        s2 += sqrt(pow(pts2[i][0] - cx2, 2) + pow(pts2[i][1] - cy2, 2));
    }
    s1 = sqrt(2.0) * n / s1;
    s2 = sqrt(2.0) * n / s2;

    double A[64][9];
    for (int i = 0; i < n; i++) {
        double x1 = s1 * (pts1[i][0] - cx1), y1 = s1 * (pts1[i][1] - cy1);
        double x2 = s2 * (pts2[i][0] - cx2), y2 = s2 * (pts2[i][1] - cy2);
        A[i][0] = x2 * x1;  A[i][1] = x2 * y1;  A[i][2] = x2;
        A[i][3] = y2 * x1;  A[i][4] = y2 * y1;  A[i][5] = y2;
        A[i][6] = x1;       A[i][7] = y1;       A[i][8] = 1.0;
    }
    double f[9];
    null_vector(&A[0][0], n, 9, f);
    Mat3 Fn = {{ {f[0], f[1], f[2]},
                 {f[3], f[4], f[5]},
                 {f[6], f[7], f[8]} }};
    Mat3 T1 = {{{s1, 0, -s1 * cx1}, {0, s1, -s1 * cy1}, {0, 0, 1}}};
    Mat3 T2 = {{{s2, 0, -s2 * cx2}, {0, s2, -s2 * cy2}, {0, 0, 1}}};
    Mat3 T2t = {{ {T2.m[0][0], T2.m[1][0], T2.m[2][0]},
                  {T2.m[0][1], T2.m[1][1], T2.m[2][1]},
                  {T2.m[0][2], T2.m[1][2], T2.m[2][2]} }};
    Mat3 FnT1, Fden;
    mat_mul3(&Fn, &T1, &FnT1);
    mat_mul3(&T2t, &FnT1, &Fden);               /* F = T2^T Fn T1 */

    Mat3 Ft = {{ {Fden.m[0][0], Fden.m[1][0], Fden.m[2][0]},
                 {Fden.m[0][1], Fden.m[1][1], Fden.m[2][1]},
                 {Fden.m[0][2], Fden.m[1][2], Fden.m[2][2]} }};
    Mat3 S;
    mat_mul3(&Ft, &Fden, &S);                   /* S = F^T F */
    double lam[3], V[3][3];
    jacobi_eigen(&S.m[0][0], 3, 3, lam, &V[0][0]);
    double VDV[3][3] = {{0}};
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            for (int k = 0; k < 3; k++)
                VDV[i][j] += V[i][k] * ((k == 0) ? 0.0 : 1.0) * V[j][k];
    Mat3 VDVm = {{{VDV[0][0], VDV[0][1], VDV[0][2]},
                  {VDV[1][0], VDV[1][1], VDV[1][2]},
                  {VDV[2][0], VDV[2][1], VDV[2][2]}}};
    mat_mul3(&Fden, &VDVm, F);                  /* 秩 2 修正: F' = F V D V^T */
    double nrm = F->m[2][2];
    if (fabs(nrm) > 1e-12)
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++)
                F->m[i][j] /= nrm;
}

/* ---------- Sampson 距离与对极线 ---------- */

static double sampson(const double x1[2], const double x2[2], const Mat3 *F)
{
    double X1[3] = {x1[0], x1[1], 1.0};
    double X2[3] = {x2[0], x2[1], 1.0};
    double Fx[3], FTx[3];
    for (int i = 0; i < 3; i++) {
        Fx[i]  = F->m[i][0]*X1[0] + F->m[i][1]*X1[1] + F->m[i][2]*X1[2];
        FTx[i] = F->m[0][i]*X2[0] + F->m[1][i]*X2[1] + F->m[2][i]*X2[2];
    }
    double num = X2[0]*Fx[0] + X2[1]*Fx[1] + X2[2]*Fx[2];
    double den = Fx[0]*Fx[0] + Fx[1]*Fx[1] + FTx[0]*FTx[0] + FTx[1]*FTx[1];
    return num * num / (den + 1e-12);
}

/* 对极线: 第二幅图像中的线 l2 = F x1 (齐次坐标 a,b,c: a u + b v + c = 0) */
static void epipolar_line(const Mat3 *F, const double x1[2], double l2[3])
{
    double X1[3] = {x1[0], x1[1], 1.0};
    for (int i = 0; i < 3; i++)
        l2[i] = F->m[i][0]*X1[0] + F->m[i][1]*X1[1] + F->m[i][2]*X1[2];
}

/* ---------- RANSAC: 从含野值的匹配中稳健地估计 F ---------- */

static unsigned int rng_state = 20260717u;
static double rnd01(void)
{
    rng_state = rng_state * 1664525u + 1013904223u;
    return (double)(rng_state >> 8) / 16777216.0;
}

/* 返回内点数; 输入 pts1/pts2 为长度 2n 的扁平数组 (x,y 交替) */
int ransac_fundamental(const double *pts1, const double *pts2, int n,
                       int iters, double threshold, struct Mat3 *best_F)
{
    if (n < 8) return -1;                       /* 不足 8 点无法估计 F */
    int best_count = -1;
    int *best_inl = malloc(sizeof(int) * n), *inl = malloc(sizeof(int) * n);
    if (!best_inl || !inl) { free(best_inl); free(inl); return -1; }

    for (int it = 0; it < iters; it++) {
        int cand[8];
        for (int k = 0; k < 8; k++) {           /* 采样 8 个不同下标 */
            int idx;
            do {
                idx = (int)(rnd01() * n);
                for (int j = 0; j < k; j++)
                    if (cand[j] == idx) { idx = -1; break; }
            } while (idx < 0);
            cand[k] = idx;
        }
        double s1[8][2], s2[8][2];
        for (int k = 0; k < 8; k++) {
            s1[k][0] = pts1[2 * cand[k]];     s1[k][1] = pts1[2 * cand[k] + 1];
            s2[k][0] = pts2[2 * cand[k]];     s2[k][1] = pts2[2 * cand[k] + 1];
        }
        Mat3 F;
        fundamental_linear(s1, s2, 8, &F);      /* 由 8 点估 F */

        int cnt = 0;
        for (int i = 0; i < n; i++)             /* 统计 Sampson 距离 < 阈值的内点 */
            if (sampson(&pts1[2 * i], &pts2[2 * i], &F) < threshold)
                inl[cnt++] = i;

        if (cnt > best_count) {                 /* 保留内点最多者 */
            best_count = cnt;
            for (int i = 0; i < cnt; i++) best_inl[i] = inl[i];
            *best_F = F;
        }
    }

    if (best_count >= 8) {                      /* 用全部内点重新拟合, 精度更高 */
        double (*g1)[2] = malloc(sizeof(double[2]) * best_count);
        double (*g2)[2] = malloc(sizeof(double[2]) * best_count);
        if (g1 && g2) {
            for (int i = 0; i < best_count; i++) {
                g1[i][0] = pts1[2 * best_inl[i]]; g1[i][1] = pts1[2 * best_inl[i] + 1];
                g2[i][0] = pts2[2 * best_inl[i]]; g2[i][1] = pts2[2 * best_inl[i] + 1];
            }
            fundamental_linear(g1, g2, best_count, best_F);
        }
        free(g1); free(g2);
    }
    free(best_inl);
    free(inl);
    return best_count;
}

int main(void)
{
    /* 合成 12 个真实匹配 (加 0.3px 高斯噪声), 再混入 4 个野值匹配 */
    double K[3][3] = {{500, 0, 320}, {0, 500, 240}, {0, 0, 1}};
    double th = 0.25, c = cos(th), s = sin(th);
    double R[3][3] = {{c, 0, s}, {0, 1, 0}, {-s, 0, c}};
    double t[3] = {-1.0, 0.15, 0.3};
    const int n = 16;
    double pts1[32], pts2[32];

    for (int i = 0; i < 12; i++) {
        double P[3] = {4.0 * rnd01() - 2.0, 4.0 * rnd01() - 2.0, 4.0 + 5.0 * rnd01()};
        double n1 = (rnd01() - 0.5) * 0.3, n2 = (rnd01() - 0.5) * 0.3;
        double X2[3] = {R[0][0]*P[0] + R[0][1]*P[1] + R[0][2]*P[2] + t[0],
                        R[1][0]*P[0] + R[1][1]*P[1] + R[1][2]*P[2] + t[1],
                        R[2][0]*P[0] + R[2][1]*P[1] + R[2][2]*P[2] + t[2]};
        pts1[2*i]     = K[0][0] * P[0] / P[2] + K[0][2] + n1;
        pts1[2*i + 1] = K[1][1] * P[1] / P[2] + K[1][2] + n2;
        pts2[2*i]     = K[0][0] * X2[0] / X2[2] + K[0][2] + n1;
        pts2[2*i + 1] = K[1][1] * X2[1] / X2[2] + K[1][2] + n2;
    }
    for (int i = 12; i < 16; i++) {             /* 野值: 随机像素点, 不满足对极约束 */
        pts1[2*i]     = 20.0 + 600.0 * rnd01();
        pts1[2*i + 1] = 20.0 + 440.0 * rnd01();
        pts2[2*i]     = 20.0 + 600.0 * rnd01();
        pts2[2*i + 1] = 20.0 + 440.0 * rnd01();
    }

    Mat3 F;
    int n_inl = ransac_fundamental(pts1, pts2, n, 500, 1.0, &F);
    printf("RANSAC 找到内点: %d (真实 12 个, 野值 4 个)
", n_inl);
    printf("估计的基础矩阵 F (F[2][2]=1):
");
    for (int i = 0; i < 3; i++)
        printf("  %12.4e %12.4e %12.4e
", F.m[i][0], F.m[i][1], F.m[i][2]);

    /* 对极线演示: 取第 0 个点, 画第二幅图中的对极线 l2 = F x1 */
    double x1[2] = {pts1[0], pts1[1]};
    double x2[2] = {pts2[0], pts2[1]};
    double l2[3];
    epipolar_line(&F, x1, l2);
    double a = l2[0], b = l2[1], cc = l2[2];
    double dist = fabs(a * x2[0] + b * x2[1] + cc) / sqrt(a * a + b * b);
    printf("对极线 l' = F x1 = (%.4f, %.4f, %.4f)  [方程 %.4f u + %.4f v + %.4f = 0]
",
           a, b, cc, a, b, cc);
    printf("对应点 x2 = (%.2f, %.2f) 到 l' 的距离 = %.3f px (应接近噪声水平)
",
           x2[0], x2[1], dist);
    return 0;
}
```

## 5. 教材/论文精读：多视图几何经典参考

**教材精读——Hartley & Zisserman《Multiple View Geometry in Computer Vision》**（第 9-12 章）是多视图几何的"圣经"，本章内容几乎全部出自该书。第 9 章给出对极几何与基础矩阵的完整推导：从"空间点、两相机中心共面"这一几何事实出发，依次引出对极平面、对极线、极点，并证明 $$F$$ 是秩 2、7 自由度的线性映射；第 10 章用三焦点张量把结论推广到三视图；第 11 章系统讲解基础矩阵的估计——八点法、最小化代数误差与几何误差的区别、以及归一化的必要性；第 12 章专讲结构恢复（三角化）与相机标定的简化估计。书中反复强调一个贯穿全部视觉几何的原则：**代数误差（让残差为 0 的线性方法）方便但受噪声扭曲，几何误差（真实重投影距离）正确但需要非线性优化**。读本章时对照 MVG 第 9、11 章，能理解我们为什么先做线性解再做秩 2 修正、为什么 RANSAC 只筛选内点而最终拟合要换到全部内点上。

**经典论文一——Hartley (1997), "In Defence of the Eight-Point Algorithm"**。八点法 1981 年由 Longuet-Higgins 提出，因对噪声敏感而一度被冷落。Hartley 指出问题不在算法而在**坐标表示**：直接用像素坐标构造的 $$A$$ 矩阵条件数极差（各列量纲从 $$10^0$$ 到 $$10^6$$ 不等），最小特征值解被数值误差淹没。他给出的修复出乎意料地简单——把每幅图各自平移到质心、缩放至平均距离 $$\sqrt{2}$$，再做同样估计、反归一化——便能让八点法达到与更复杂的非线性算法可比的精度。这篇论文的意义在于确立了"归一化"作为数值稳健视觉算法的第一性前提，也示范了一个重要的方法论：**先检查问题的条件数，再谈算法**。我们 4.1 节代码严格照此实现。

**经典论文二——Fischler & Bolles (1981), "Random Sample Consensus: A Paradigm for Model Fitting with Applications to Image Analysis and Automatography"**。这篇开创性论文提出 RANSAC，直指当时模型拟合方法（最小二乘及其变体）的共同软肋：野值按高斯假设被"平均"掉，一个离群点就能把拟合结果带偏。RANSAC 的思路是反其道而行——用最少样本随机试探，用**一致性**而非**最小残差**来评判模型，于是对野值比例可以高达 50% 以上仍稳健。文中用相机标定（估计变换矩阵）的实例验证，并讨论了最小样本数、置信度与迭代次数的关系（即我们 3.4 节的 $$N$$ 公式）。论文的持久影响在于它确立了一个通用范式：任何"多数服从一致模型"的估计问题（基础矩阵、单应矩阵、PnP 位姿）都可以套用。

## 6. 实验/编程作业

对应 C106A 第 6-7 周内容，建议做三个渐进的实验。

**实验一：自写基础矩阵与对极线（无库实现）。** 用 4.1 节的代码对两幅同一场景的图像（可以是机器人相机拍摄的相邻两帧，或左右目图像）估计 $$F$$，把内点匹配逐对画在第二幅图上并叠加对极线 $$l' = F x$$，肉眼检查对应点是否落在线附近。把第一幅图的特征点横坐标整体平移 50 像素再估计，观察 $$F$$ 是否仍满足约束——这是检验对归一化理解的好方法。

**实验二：RANSAC 匹配过滤。** 用特征检测与描述子匹配（SIFT/ORB，第 7 章内容）得到含大量误匹配的原始对应集，直接跑最小二乘估计 $$F$$ 并统计对极残差；再换成 4.2 节的 RANSAC，比较过滤前后内点比例与估计出的 $$F$$ 的质量（如对极残差的中位数、内点的一致性）。体会"含野值的最小二乘必败，RANSAC 稳健"这一核心结论。**必做**：尝试把阈值从 1px 调到 3px，观察内点数和估计精度的变化，理解阈值是权衡"召回"与"精度"的超参数。

**实验三：从双目到稀疏 3D 重建。** 已知或标定两相机内参（或用近似焦距），计算 $$E = K^T F K$$，按 3.3 节分解出 $$R, t$$ 并施加正深度约束选出唯一解，再用 3.5 节的 DLT 三角化把内点重建为稀疏 3D 点云，最后把点云与相机位姿可视化。这是视觉里程计/双目 SLAM（第 13 章）的最小闭环。若时间允许，再实现一版最小化重投影误差的优化（梯度下降即可），与纯线性三角化对比精度。

## 8. 小结

本章把"两幅图像"变成"相机运动 + 三维结构"。对极几何是这一切的中心：它用秩 2 的基础矩阵 $$F$$ 把对应点约束到一条线上，$$x'^T F x = 0$$，不依赖任何 3D 信息。八点法是最基本的估计手段，但必须配合 Hartley 归一化与秩 2 SVD 修正才能稳健；特征匹配的野值则交给 RANSAC 处理，用 Sampson 距离度量点到模型的偏离，最终用内点重新拟合。知道 $$F$$ 之后，内参已知时用本质矩阵 $$E = [t]_	imes R$$ 恢复旋转平移，再以三角化重建 3D 点，就构成了从原始像素到相机位姿与稀疏点云的完整闭环。下一章回到运动侧，用雅可比矩阵描述速度；而本章估计出的相机运动，正是后续动力学、规划与 SLAM 共同依赖的"感知层输入"。
