# 机器人学导论：从刚性运动到控制

> 本书编译自 **UC Berkeley EECS C106A/206A: Introduction to Robotics** (Fall 2023, Prof. Koushil Sreenath & Prof. Shankar Sastry)
> — [课程主页](https://ucb-ee106.github.io/eecs106a-fa23site/)

## 为什么写这本书

机器人学是现代科技最动人的交叉点——数学、力学、控制、感知与人工智能在这里交汇。加州伯克利的 EECS C106A 是"机器人学导论"的经典课程，
其核心教材 Murray/Li/Sastry《A Mathematical Introduction to Robotic Manipulation》(MLS) 以严谨的旋量理论著称。

本书以 **C106A 课程 + MLS 教材**为骨架，从刚性运动讲起，覆盖运动学、视觉、动力学、控制与规划五大主题，
**用 C 语言把旋转矩阵、四元数、雅可比、PID 全部写成可编译可运行的代码**。

## 怎么读

- 新手：按顺序读第 I 部分 → 第 II 部分 → 第 III 部分。
- 有数学基础：重点读第 3-4 章（SO(3)/SE(3)），这是全书的基石。
- 只关心控制：直接看第 10-11 章。
