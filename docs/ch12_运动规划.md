# 第 12 章 运动规划

> 课程来源：EECS C106A 第 12-13 周 ｜ 关键词：配置空间、RRT/RRT*、PRM、人工势场、A* 规划、避障 ｜ 预计阅读时长：~40 分钟

## 1. 导论

前面各章回答了"机器人在某一时刻处于什么位形"（正运动学、逆运动学、雅可比）以及"如何把机器人驱动到位形并维持它"（动力学与控制）的问题。本章要回答一个更高层的问题：**给定位形空间中的起点与终点，以及布满障碍物的环境，如何计算出一条无碰撞的可行路径？** 这个问题就是运动规划（Motion Planning, MP），它是把"运动学能力"兑现为"执行任务"的桥梁。

运动规划无处不在：机械臂在狭窄工位上抓取零件、移动机器人在仓库里穿行、自动驾驶汽车在车流中变道、多指手在抓取时重新摆放手指（MLS 第 8 章讨论的 finger repositioning 本质就是一个受约束的运动规划问题）。对任意维数的连续空间，纯粹用解析方法求解是不可能的，因此现代算法几乎都建立在**采样**与**图搜索**两条主线上：本章介绍的快速扩展随机树（Rapidly-exploring Random Tree, RRT）、概率路线图（Probabilistic Roadmap, PRM）属于采样类；A* 与人工势场分别属于离散图搜索与连续势能梯度类。

与前一章的控制问题不同，运动规划通常只关心"走哪条路"，轨迹跟踪（trajectory tracking）等时间参数化任务留到下一章与移动机器人一起讨论。我们把规划器当作一个黑盒：给它环境描述与起点、终点，它还回一条由位形序列组成的路径；至于机器人是否受非完整约束（如汽车不能侧滑），则由 MLS 第 8 章的理论刻画，规划输出必须与之兼容。

从完备性看，规划算法可以排成一个谱系。精确方法（单元分解、可见图）在低维下完备甚至最优，但高维下组合爆炸；势场法完备性最弱，可能陷入局部极小；A* 在离散栅格上是**分辨率完备**的（网格足够细时保证找到解）；PRM 与 RRT 满足**概率完备性**（样本足够多时以概率 1 找到解，RRT* 还渐近最优）。工程选型必须理解这一谱系：动态环境适合在线重规划，静态高维场景适合离线路由图，窄通道问题则需要专门设计采样分布才能可靠求解。

## 2. 关键概念与记号

**配置空间（Configuration Space, C-space）** 是本章最重要的概念。机器人每个关节的取值构成一个广义坐标 $$q = (q_1, \dots, q_n)$$，所有可能的 $$q$$ 的集合就是配置空间 $$Q$$。对 $$n$$ 关节机械臂，$$Q = T^n$$（$$n$$ 维环面）；对平面上的移动机器人，$$Q = SE(2)$$；对空间中的刚体，$$Q = SE(3)$$。正运动学映射把位形映到工作空间：$$g_{st}: Q \to SE(3)$$。

把环境中的障碍物"搬到"配置空间：那些会使机器人与障碍物碰撞的位形构成**障碍位形空间** $$Q_{obs}$$，其余为**自由空间** $$Q_{free} = Q \setminus Q_{obs}$$。关键直觉是：**工作空间中的机器人变成一个配置空间中的"点"**，机器人的避障问题转化为单个点在自由空间中的运动问题。这是 Lozano-Pérez 与 Wesley（1979）奠定的范式，也是整个采样规划领域的基础。

**规划问题的形式化**：给定 $$q_{init}, q_{goal} \in Q_{free}$$，求一条连续映射 $$\tau: [0,1] \to Q_{free}$$ 满足 $$\tau(0) = q_{init}$$，$$\tau(1) = q_{goal}$$。当机器人受 Pfaffian 约束 $$A(q)\dot{q} = 0$$ 约束（如汽车、滚动圆盘，见 MLS 第 7-8 章）时，还要求路径沿程都满足该速度约束，这类问题称为非完整运动规划。

**度量**：在 $$Q_{free}$$ 中定义距离以便"找最近邻"。对机械臂常用加权欧氏范数 $$d(q, q') = \lVert q - q' \rVert$$；对 SE(2)/SE(3) 需要用平移与旋转混合度量。**局部规划器**（local planner）检验两个位形之间的连通性（例如直线段是否完全落在自由空间内），它是采样算法的基本构件。

举一个低维例子体会"C 空间降维"的威力：半径为 $$\rho$$ 的平面圆盘机器人，其避障问题等价于把工作空间所有障碍物按半径 $$\rho$$ 膨胀之后，让**圆心**（一个二维点）在膨胀后的自由区域中运动。一旦引入朝向，位形变为 $$(x, y, \theta)$$，障碍物在每个 $$\theta$$ 切片上都不一样，配置空间随之升维。这解释了为什么三维以上的 C 空间几乎不可能显式构造——采样法只依赖碰撞检测黑盒，从而绕开了显式构造的困难。

**相关概念**：占用栅格（Occupancy Grid）把工作空间离散为网格并标记占用状态，供 A* 等栅格搜索使用；避障（Obstacle Avoidance）一般指与路径规划配套的碰撞检测与绕行手段。

## 3. 算法与公式

### 3.1 人工势场

**思想**：把目标点当作引力源，把障碍物当作斥力源，在配置空间上构造标量势场 $$U(q) = U_{att}(q) + U_{rep}(q)$$，然后沿其负梯度方向运动。

引力势取二次型

$$U_{att}(q) = \frac{1}{2} k_{att} \lVert q - q_{goal} \rVert^2,$$

斥力势只作用于影响半径 $$\rho_0$$ 内：

$$U_{rep}(q) = \begin{cases} \dfrac{1}{2} k_{rep} \left( \dfrac{1}{\rho(q)} - \dfrac{1}{\rho_0} \right)^2, & \rho(q) \le \rho_0,\\[2mm] 0, & \rho(q) > \rho_0, \end{cases}$$

其中 $$\rho(q)$$ 是位形 $$q$$ 到最近障碍物的距离。合力为

$$\mathbf{F}(q) = -\nabla U(q) = -\nabla U_{att}(q) - \nabla U_{rep}(q).$$

势场法简单、可实时，在局部避障中极其常用（Khatib 1986 将其用于机械臂实时避障），但它**天然存在局部极小**：当引力与斥力在某个自由位形处恰好抵消时，梯度下降会困住。这也是它在课程中常与采样法对比、作为"完备性失败"反面教材的原因。

### 3.2 A*：占用栅格上的离散搜索

把连续空间离散成栅格，每个栅格单元是节点，机器人只能 4 连通或 8 连通地移动。A* 在开放集上按估价函数

$$f(n) = g(n) + h(n)$$

扩展节点，其中 $$g(n)$$ 是从起点到节点 $$n$$ 的实际代价，$$h(n)$$ 是到目标的启发式估计。8 连通下可用欧氏启发式

$$h(n) = \lVert p_n - p_{goal} \rVert,$$

当启发式**可采纳**（admissible，不高于真实代价）时 A* 返回最优解。A* 由 Hart、Nilsson 与 Raphael（1968）提出，其关键是按 $$f$$ 维护一个优先级队列，每次弹出 $$f$$ 最小的节点，并对已扩展节点作封闭标记。

### 3.3 PRM：概率路线图

PRM（Kavraki, Švestka, Latombe, Overmars 1996）分两阶段：

```
学习阶段：
 1. 反复在 Q_free 中均匀随机采样位形，加入节点集 V
 2. 对每个节点 v，用局部规划器尝试连接其 k 个近邻，
    无碰撞的边 (v, w) 加入边集 E，构成路线图 G = (V, E)
查询阶段：
 3. 把 q_init 与 q_goal 分别用局部规划器连入路线图
 4. 在 G 上用 Dijkstra / A* 求最短路径
```

PRM 适合**静态环境中多次查询**的场景：昂贵的采样与连线（learning）只做一次，之后每次查询只需两次连接加一次图搜索。它的理论保证是**概率完备性**：当采样数趋于无穷时，路线图以概率 1 捕获自由空间各连通分量的连通性（对满足某种"好路况"假设的环境，能以高概率在有限样本内成功）。

### 3.4 RRT 与 RRT*

RRT（LaValle 1998）从 $$q_{init}$$ 出发增量式生长一棵树：

```
输入：q_init, q_goal
1. 树 T ← { q_init }
2. 重复：
   a. 在 Q_free 中随机采样 q_rand（可带目标偏向）
   b. q_near = argmin_{v ∈ T} ‖v - q_rand‖
   c. 从 q_near 朝 q_rand 步进距离 δ 得到 q_new
   d. 若 q_new ∈ Q_free 且局部路径 (q_near, q_new) 无碰撞，把 q_new 加入 T
   e. 若 ‖q_new - q_goal‖ < ε，回溯输出路径
```

RRT 的两个关键性质是：**Voronoi 偏向**——树中靠近未探索区域的节点拥有更大的 Voronoi 区域，更容易被选为 $$q_{near}$$，从而被拉向新空间，因此树能快速铺满自由空间；**简单**——不需要任何"把系统从一点精确驱动到另一点"的能力，只需能朝一个方向步进，这让它天然适配带动力学与非完整约束的系统（MLS 第 8 章正需要这种性质）。RRT 概率完备，但不保证最优。

**RRT\***（Karaman & Frazzoli 2011）在 RRT 上加了两步：**重新接线**（rewire）——新节点加入后，检查邻域内其他节点，若经由新节点到达它们代价更低则改接父指针；以及持续进行路径渐进优化。RRT* 保持概率完备性，并满足**渐进最优性**：随着迭代次数增加，返回路径代价以概率 1 收敛到最优。

### 3.5 非完整运动规划（MLS 第 8 章）

对受 Pfaffian 约束 $$A(q)\dot{q} = 0$$ 的系统，可行速度被限制在分布 $$\Delta = \mathrm{span}\{g_1, \dots, g_m\}$$ 内，其中 $$A(q)g_j(q) = 0$$。MLS 的核心结论是：能否在任意两点间转向，取决于**可控性李代数**的秩。若 $$\Delta$$ 非对合（非完整），重复沿 $$g_1$$ 与 $$g_2$$ 的小段"前进-横移-后退-横移"可以产生纯李括号方向的运动

$$[g_1, g_2](q) = \frac{\partial g_2}{\partial q} g_1(q) - \frac{\partial g_1}{\partial q} g_2(q),$$

从而"凭空"得到分布以外的位移。汽车模型（MLS 例 7.5）的 PFaffian 约束可化为控制系统

$$\dot{q} = \begin{pmatrix} \cos\theta \\ \sin\theta \\ \frac{1}{l} \tan\phi \\ 0 \end{pmatrix} u_1 + \begin{pmatrix} 0 \\ 0 \\ 0 \\ 1 \end{pmatrix} u_2,$$

其李括号方向是侧向位移——这正是"倒车入库"式之字机动能实现的数学依据。MLS 第 8 章进一步给出用**整频率正弦输入**转向一阶可控系统（Brockett 系统、链式系统）的方法：正弦输入在状态空间的闭曲线产生李括号方向上的净位移，从而把规划问题转为一个可积的代数问题。

## 4. C 语言实现

下面给出两个可直接编译运行的规划器。第一个是二维平面上的 RRT，圆形障碍物的碰撞判定即 $$\lVert p - c \rVert < r$$；第二个是占用栅格上的 A*，用欧氏启发式 $$h = \lVert p - g \rVert$$ 与手写二叉堆实现。

**程序一：RRT 路径规划**（随机采样 → 最近邻 → 朝样本步进 → 碰撞检测 → 入树 → 连到目标 → 回溯输出路径）：

```c
/* ============================================================
 * ch12_rrt.c —— 快速扩展随机树（RRT）二维路径规划
 * 编译：gcc -std=c11 -Wall -Wextra ch12_rrt.c -lm -o rrt
 * 环境为 [0,10] x [0,10]，含三个圆形障碍物
 * ============================================================ */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <time.h>

#define MAX_NODES 4000
#define STEP      0.5     /* 每次向随机样本步进的长度 */
#define GOAL_TOL  0.3     /* 与目标距离小于该值即视为到达 */
#define MAX_ITER  3000
#define N_OBST    3

/* 圆形障碍物：圆心 (x, y)、半径 r */
typedef struct { double x, y, r; } Obstacle;
/* RRT 树节点：位置 + 父节点下标 */
typedef struct { double x, y; int parent; } RRTNode;

static const Obstacle obs[N_OBST] = {
    {5.0, 5.0, 1.2},
    {2.0, 7.5, 1.0},
    {8.0, 2.5, 1.0}
};

/* 点 (x,y) 是否落在障碍物内：\lVert p - c \rVert < r */
static int in_collision(double x, double y)
{
    for (int i = 0; i < N_OBST; i++) {
        double dx = x - obs[i].x, dy = y - obs[i].y;
        if (dx*dx + dy*dy < obs[i].r*obs[i].r)
            return 1;
    }
    return 0;
}

/* 线段 (ax,ay)-(bx,by) 是否穿过某个障碍物（最近点投影法） */
static int segment_blocked(double ax, double ay, double bx, double by)
{
    double vx = bx - ax, vy = by - ay;
    double vlen2 = vx*vx + vy*vy;
    for (int i = 0; i < N_OBST; i++) {
        double wx = obs[i].x - ax, wy = obs[i].y - ay;
        double t = (vlen2 > 1e-12) ? (wx*vx + wy*vy) / vlen2 : 0.0;
        if (t < 0.0) t = 0.0;
        if (t > 1.0) t = 1.0;
        double px = ax + t*vx, py = ay + t*vy;
        double dx = px - obs[i].x, dy = py - obs[i].y;
        if (dx*dx + dy*dy < obs[i].r*obs[i].r)
            return 1;
    }
    return 0;
}

/* 返回树中离 (x,y) 最近的节点下标 */
static int nearest(const RRTNode *tree, int n, double x, double y)
{
    int best = 0;
    double best_d = 1e300;
    for (int i = 0; i < n; i++) {
        double dx = tree[i].x - x, dy = tree[i].y - y;
        double d = dx*dx + dy*dy;
        if (d < best_d) { best_d = d; best = i; }
    }
    return best;
}

/* 扩展一步：采样随机点 -> 最近邻 -> 朝样本步进 STEP -> 碰撞检查 -> 入树。
 * 若新节点靠近目标点则返回 1。 */
static int extend(RRTNode *tree, int *n, double gx, double gy)
{
    double rx, ry;
    if (rand() % 10 < 2) { rx = gx; ry = gy; }   /* 目标偏向采样，加速收敛 */
    else {
        rx = 10.0 * (rand() / (double)RAND_MAX); /* 均匀采样 [0,10]^2 */
        ry = 10.0 * (rand() / (double)RAND_MAX);
    }

    int nn = nearest(tree, *n, rx, ry);
    double dx = rx - tree[nn].x, dy = ry - tree[nn].y;
    double dist = sqrt(dx*dx + dy*dy);
    if (dist < 1e-9) return 0;

    double s = (dist < STEP) ? 1.0 : STEP / dist;
    double nx = tree[nn].x + s*dx;
    double ny = tree[nn].y + s*dy;

    if (in_collision(nx, ny)) return 0;
    if (segment_blocked(tree[nn].x, tree[nn].y, nx, ny)) return 0;

    tree[*n].x = nx; tree[*n].y = ny; tree[*n].parent = nn;
    (*n)++;

    double dg = sqrt((nx - gx)*(nx - gx) + (ny - gy)*(ny - gy));
    return dg < GOAL_TOL;
}

int main(void)
{
    const double sx = 0.5, sy = 0.5;   /* 起点 */
    const double gx = 9.5, gy = 9.5;   /* 目标点 */

    RRTNode tree[MAX_NODES];
    tree[0].x = sx; tree[0].y = sy; tree[0].parent = -1;
    int n = 1;

    srand((unsigned)time(NULL));
    int reached = 0, goal_node = -1;
    for (int iter = 0; iter < MAX_ITER && n < MAX_NODES; iter++) {
        if (extend(tree, &n, gx, gy)) {
            reached = 1;
            goal_node = n - 1;
            break;
        }
    }

    if (!reached) {
        printf("规划失败：%d 次迭代后树中有 %d 个节点\n", MAX_ITER, n);
        return 1;
    }

    /* 从目标附近节点沿父指针回溯到根，得到路径（逆序存入数组） */
    int path_idx[MAX_NODES], len = 0;
    for (int i = goal_node; i != -1; i = tree[i].parent)
        path_idx[len++] = i;

    printf("找到路径：树节点 %d 个，路径航点 %d 个\n", n, len);
    for (int k = len - 1; k >= 0; k--)
        printf("(%.3f, %.3f)\n", tree[path_idx[k]].x, tree[path_idx[k]].y);
    printf("(%.3f, %.3f) 目标\n", gx, gy);
    return 0;
}
```

RRT 的可扩展方向：把二维坐标换成关节角向量即可规划机械臂；把最近邻从线性扫描换成 KD-tree 可显著提速；把"单棵树"换成"双向 RRT"（同时从起点与终点生长两棵树，朝对方生长）收敛快数倍；加上 rewiring 就是 RRT*。

**程序二：占用栅格上的 A\***（8 连通、欧氏启发式、手写二叉堆优先队列）：

```c
/* ============================================================
 * ch12_astar.c —— 占用栅格上的 A* 最短路径规划
 * 编译：gcc -std=c11 -Wall -Wextra ch12_astar.c -lm -o astar
 * 8 连通移动，对角代价 sqrt(2)，欧氏启发式 h = \lVert p - g \rVert
 * ============================================================ */
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define W 16
#define H 12
#define SQRT2 1.4142135623730951   /* 对角移动的代价 */

/* 占用栅格：'#' 为障碍，'.' 为自由 */
static const char grid[H][W] = {
    "................",
    "...####.........",
    "...#............",
    "...#...####.....",
    "...#...#........",
    "...#...#........",
    "...#...#........",
    "...#..####......",
    "...#............",
    "...#............",
    "...###########..",
    "................",
};

static double gbest[H][W], fbest[H][W];   /* g 代价与 f = g + h */
static int parent[H][W], closed[H][W];    /* 父指针与封闭标记 */

static const int dr[8] = {-1,-1,-1, 0, 0, 1, 1, 1};
static const int dc[8] = {-1, 0, 1,-1, 1,-1, 0, 1};

/* ---------- 手写最小二叉堆（按 fbest 排序） ---------- */
static int heap[W*H], hsize;

static void heap_push(int idx)
{
    int i = hsize++;
    heap[i] = idx;
    while (i > 0) {                         /* 上浮 */
        int p = (i - 1) / 2;
        if (fbest[heap[p]] <= fbest[heap[i]]) break;
        int t = heap[p]; heap[p] = heap[i]; heap[i] = t;
        i = p;
    }
}

static int heap_pop(void)
{
    int top = heap[0];
    int last = heap[--hsize];
    if (hsize > 0) {                        /* 下沉 */
        heap[0] = last;
        int i = 0;
        for (;;) {
            int l = 2*i + 1, r = 2*i + 2, m = i;
            if (l < hsize && fbest[heap[l]] < fbest[heap[m]]) m = l;
            if (r < hsize && fbest[heap[r]] < fbest[heap[m]]) m = r;
            if (m == i) break;
            int t = heap[i]; heap[i] = heap[m]; heap[m] = t;
            i = m;
        }
    }
    return top;
}

/* 欧氏启发式 h = \lVert p_n - p_goal \rVert */
static double heuristic(int r, int c, int gr, int gc)
{
    int ddr = gr - r, ddc = gc - c;
    return sqrt((double)(ddr*ddr + ddc*ddc));
}

/* 沿 parent 链回溯路径并输出 */
static void reconstruct(int sr, int sc, int gr, int gc)
{
    int pr[W*H], pc[W*H], len = 0;
    int r = gr, c = gc;
    while (!(r == sr && c == sc)) {
        pr[len] = r; pc[len] = c; len++;
        int idx = parent[r][c];
        r = idx / W; c = idx % W;
    }
    printf("路径格数（含起终点）=%d，累计代价 %.3f\n", len + 1, gbest[gr][gc]);
    printf("(%d,%d) 起点\n", sr, sc);
    for (int i = len - 1; i >= 0; i--)
        printf("(%d,%d)\n", pr[i], pc[i]);
}

int main(void)
{
    const int sr = 0, sc = 0, gr = H - 1, gc = W - 1;  /* 左上 -> 右下 */

    for (int r = 0; r < H; r++)
        for (int c = 0; c < W; c++) {
            gbest[r][c] = 1e300;
            fbest[r][c] = 1e300;
            parent[r][c] = -1;
            closed[r][c] = 0;
        }

    gbest[sr][sc] = 0.0;
    fbest[sr][sc] = heuristic(sr, sc, gr, gc);
    heap_push(sr*W + sc);

    int found = 0;
    while (hsize > 0) {
        int cur = heap_pop();               /* 弹出 f 最小的节点 */
        int r = cur / W, c = cur % W;
        if (closed[r][c]) continue;         /* 重复入堆的过期条目跳过 */
        closed[r][c] = 1;
        if (r == gr && c == gc) { found = 1; break; }

        for (int k = 0; k < 8; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= H || nc < 0 || nc >= W) continue;
            if (grid[nr][nc] == '#') continue;
            if (closed[nr][nc]) continue;
            /* 对角移动禁止“穿墙角”：要求相邻两格也自由 */
            if (dr[k] != 0 && dc[k] != 0 &&
                (grid[r][nc] == '#' || grid[nr][c] == '#')) continue;

            double step = (dr[k] != 0 && dc[k] != 0) ? SQRT2 : 1.0;
            double ng = gbest[r][c] + step;
            if (ng < gbest[nr][nc]) {       /* 松弛：发现更短的到达方式 */
                gbest[nr][nc] = ng;
                parent[nr][nc] = cur;
                fbest[nr][nc] = ng + heuristic(nr, nc, gr, gc);
                heap_push(nr*W + nc);       /* 允许重复入堆，pop 时去重 */
            }
        }
    }

    if (found) reconstruct(sr, sc, gr, gc);
    else       printf("未找到可行路径\n");
    return 0;
}
```

A* 的要点全部在估价与数据结构上：启发式越接近真实代价，扩展的节点越少；二叉堆保证每次弹出最小 $$f$$ 的代价是 $$O(\log N)$$；对角移动检查相邻两格，避免"从墙角斜穿过去"这类不合法的捷径。

## 5. 教材/论文精读

**MLS 第 8 章：非完整运动规划。** Murray/Li/Sastry 的教材早于现代采样法（1994），它走的是另一条路：对受 Pfaffian 约束的系统，把"找可行轨迹"对偶为"对控制系统 $$q = g_1(q)u_1 + \dots + g_m(q)u_m$$ 转向（steering）"。第 7 章用李括号与 Frobenius 定理刻画了可控性：若可控性李代数满秩（Chow 定理），则任意两点之间可达。第 8 章在此基础上给出构造性转向方法：对一阶可控的 Brockett 系统（增长向量 (2,3)），**整频率正弦输入**恰好是最优控制（由变分法推出输入是频率为 λ 的正弦），闭环曲线产生李括号方向上的净位移；对高阶系统则先转换到**链式形式**（chained form）再用正弦积分。值得强调的是，Brockett 系统 (8.2) 的正弦输入在最小二乘控制代价意义下就是最优的，这条"正弦产生李括号运动"的线索贯穿整个第 8 章，并再次出现在手指重定位（finger repositioning）的几何相位算法中——通过调节沿特定环路的输入相位差，手指在物体表面的接触角被精确调整。启示：约束越"非完整"，越需要专门的几何直觉，而 RRT 这类采样法之所以被非完整系统广泛采用，正因为它只需要"沿可行方向步进"，天然规避了精确转向的困难。

**LaValle（1998）RRT。** "Rapidly-Exploring Random Trees: A New Tool for Path Planning"（TR 98-11，Iowa State）引入了 RRT 数据结构。其动机是：PRM 连接随机配置对需要局部规划器能把两点精确接起来，而这在带动力学约束时几乎和设计非线性控制器一样难；RRT 反其道而行，只需"驱动系统稍微朝一个随机点靠近"，不做点到点收敛。报告证明了 Voronoi 偏向性（树的扩展强烈偏向未探索区域）、均匀覆盖性（顶点分布趋近采样分布）、概率完备性，并报告在最多 12 自由度的全向/非完整/运动动力问题上均适用。它的"简单、少启发式、树恒连通、无需转向能力"这些性质使它成为规划领域的常青树，后来催生了 RRT*、双向 RRT、DRRT（动态）等一大批变体，LaValle 与 Kuffner 的 ICRA 2000 论文还获得首个 ICRA 里程碑奖。

**Kavraki, Švestka, Latombe, Overmars（1996）PRM。** "Probabilistic Roadmaps for Path Planning in High-Dimensional Configuration Spaces"（IEEE T-RO 12(4): 566-580）把规划拆成"离线学习 + 在线查询"：学习阶段随机采样自由位形并用局部规划器连成路线图，查询阶段把起终点连入路线图再搜图。相比势场法，PRM 没有局部极小；相比精确单元分解，它不需要显式构造障碍物（只需碰撞检测黑盒），因而能扩展到高维。论文给出概率完备性论证：在满足"宽通道"（expansive 类）假设的环境里，样本足够多时路线图以高概率抓住自由空间的拓扑连接。它是**多查询**场景（如焊接工位反复规划不同路径）的默认选择。与之互补的 RRT*（Karaman & Frazzoli 2011, IJRR 30(7): 846-894）补上了采样法的最优性短板，成为现代规划器（OMPL 等）的标准组件。

## 6. 实验/编程作业

EECS C106A 第 12-13 周对应两类练习，可参考如下设计：

- **作业一（RRT 与 RRT*）**：在仿真中给机械臂（如 2-3 关节）或差速小车实现 RRT，障碍物用凸多边形/圆盘。先让最近邻用线性扫描跑通，再换成 KD-tree 或栅格哈希提速；对比"纯均匀采样"与"目标偏向采样"的收敛速度。进阶：实现 RRT* 的 rewiring，统计路径代价随迭代次数的收敛曲线，验证渐进最优性。
- **作业二（A* 与势场）**：把真实环境的传感器数据（激光雷达/深度相机）转成占用栅格，用本章的 A* 在栅格上规划全局路径；再用人工势场做局部避障，把它套在全局路径附近作为平滑器。要求在同一张地图上对比 A* 的 4 连通与 8 连通路径长度，并设计实验展示势场法的局部极小陷阱。
- **避障闭环**：把规划器输出接到第 11 章的 PID 轨迹跟踪上，构成"规划 → 跟踪"完整流水线；在机器人实物/仿真中验证规划路径确实可被跟踪且不碰撞。这正好衔接下一章移动机器人的内容。
- **选做（非完整规划）**：把 RRT 的"步进"替换为汽车转向模型（MLS 例 7.5 的式 (7.14)），用恒定控制输入做短时积分产生新状态；在绕桩地图上比较其与全向 RRT 的成功率，直观体会李括号方向（侧向位移）如何通过之字机动实现。

## 8. 小结

本章把"机器人如何到达目标"形式化为配置空间中的无碰撞路径问题，介绍了四大类方法：人工势场（连续梯度法，简单但局部极小）、A*（占用栅格上的最优离散搜索）、PRM（多查询场景的概率完备路线图）、RRT/RRT*（单查询、无需转向能力、渐进最优的采样树）。MLS 第 8 章补充了非完整约束下的几何转向理论，说明采样法为何能自然适配受约束系统。本章给出的 RRT 与 A* 两个 C 实现覆盖了采样、最近邻、碰撞检测、启发式搜索与优先级队列这些规划的核心构件，是后续把规划结果交给控制与移动机器人执行的基础。
