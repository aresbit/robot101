# 机器人学导论：从刚性运动到控制

> 编译自 **UC Berkeley EECS C106A/206A: Introduction to Robotics** (Fall 2023, Prof. Koushil Sreenath & Prof. Shankar Sastry)
> — [课程主页](https://ucb-ee106.github.io/eecs106a-fa23site/)

本书以 C106A 课程 + Murray/Li/Sastry《A Mathematical Introduction to Robotic Manipulation》(MLS) 为骨架，从刚性运动讲起，覆盖运动学、视觉、动力学、控制与规划五大主题，共 14 章。

## 目录

| 部分 | 章节 |
|------|------|
| **第 I 部分：刚体运动与数学基础** | 1. 机器人学导论 · 2. 线性代数与数学基础 · 3. 旋转运动与 SO(3) · 4. 刚性体变换与 SE(3) |
| **第 II 部分：运动学·动力学·控制·规划** | 5. 正运动学 · 6. 逆运动学 · 7. 计算机视觉基础 · 8. 视觉对应与双视图几何 · 9. 速度与雅可比 · 10. 动力学 · 11. 控制 · 12. 运动规划 |
| **第 III 部分：移动机器人与前沿** | 13. 移动机器人 · 14. 前沿与展望 |
